# DSA Practice — RisingBrain Sheet
Java solutions following the pattern-wise RisingBrain sheet (https://www.risingbrain.org/sheet).

## Folder structure
```
src/
  arrays/
    twopointer/     ← P01–P20 Java stubs + HTML study guides + generator
    slidingwindow/  ← coming next
    prefixsum/
    kadane/
  strings/
  binarysearch/
  stack/
  linkedlist/
  tree/
  graph/
  dp/
```

Each technique folder contains:
- `P##_ProblemName.java`  — practice stub (TODO + hints + test cases)
- `P##_ProblemName.html`  — study guide (layman explanation, visual, full solution, complexity)
- `00_Masterclass.html`   — overview of the technique with all 5 pattern types
- `generate_guides.py`    — re-run to regenerate all HTMLs

## How to use the study guides (save as PDF)
1. Open any `.html` file in your browser (right-click → Open With → Browser)
2. Press **Ctrl + P** → **Save as PDF**
3. Start with `00_Masterclass.html` — it explains all pattern types and links every problem

## How to run a Java file in VS Code
1. Open any `.java` file
2. Click **Run** above the `main` method
   (requires Extension Pack for Java installed)
