GraphsBFS

Graphs · BFS — Masterclass

Queue-based traversal of graphs (or implicit state spaces) that finds shortest paths in unweighted edges. Multi-source BFS unlocks "nearest X" problems.

Jargon

Multi-source BFS
Seed the queue with ALL "starting" cells, not just one. Useful for "distance to nearest X" problems.
State Space
Nodes can be more than coordinates — board configurations (sliding puzzle), digit strings (open lock), (row, col, k-remaining) tuples.
Layer-by-layer
Process by current queue size; increment depth between layers.
0-1 BFS
Deque-based BFS when edges are weighted 0 or 1; cheaper than Dijkstra.

Template

Queue<int[]> q = new ArrayDeque<>();
q.offer(new int[]{sr, sc});
visited[sr][sc] = true;
int dist = 0;
while (!q.isEmpty()) {
    int sz = q.size();
    for (int i = 0; i < sz; i++) {
        int[] c = q.poll();
        if (isTarget(c)) return dist;
        for (int[] n : neighbours(c))
            if (valid(n) && !visited[n[0]][n[1]]) {
                visited[n[0]][n[1]] = true;
                q.offer(n);
            }
    }
    dist++;
}
return -1;
