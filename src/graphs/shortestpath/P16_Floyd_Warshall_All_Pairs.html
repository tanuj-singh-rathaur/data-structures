P16 — Floyd-Warshall All-Pairs

Medium

Pattern

for (int k = 0; k < n; k++)
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        d[i][j] = Math.min(d[i][j], d[i][k] + d[k][j]);
// dp interpretation: dist using only vertices {0..k} as intermediaries.
Insight: Outer loop on k is mandatory — it represents "the set of intermediates I'm allowed to use is growing."
