25.4 Shortest Path — Masterclass

Shortest-path problems answer: "what is the minimum total weight to get from A to B?" The algorithm you reach for depends on edge weights and the question shape: unit weights → BFS; non-negative → Dijkstra; negative allowed → Bellman-Ford; all-pairs → Floyd-Warshall; 0/1 weights → 0-1 BFS (deque).

Jargon Buster

Relaxation
If dist[u] + w(u,v) < dist[v], update dist[v]. Heart of every SP algorithm.
Greedy invariant (Dijkstra)
Once you pop a node with smallest tentative distance, that distance is final — provided all weights are non-negative.
Negative cycle
A cycle whose edges sum to a negative value. Makes shortest path undefined; Bellman-Ford detects it on the V-th relaxation pass.
0-1 BFS
BFS with a deque: push-front for weight-0 edges, push-back for weight-1 edges. Runs in O(V+E).
Minimax path
"Minimise the maximum edge weight on the path" — Dijkstra still works with max instead of +.

Java — Dijkstra Template

int[] dist = new int[n]; Arrays.fill(dist, Integer.MAX_VALUE);
dist[src] = 0;
PriorityQueue<int[]> pq = new PriorityQueue<>((a,b)->a[1]-b[1]);
pq.offer(new int[]{src, 0});
while (!pq.isEmpty()) {
    int[] cur = pq.poll(); int u = cur[0], d = cur[1];
    if (d > dist[u]) continue;            // stale entry
    for (int[] e : adj.get(u)) {           // e = {v, w}
        int nd = d + e[1];
        if (nd < dist[e[0]]) { dist[e[0]] = nd; pq.offer(new int[]{e[0], nd}); }
    }
}

Java — Bellman-Ford Template

int[] dist = new int[n]; Arrays.fill(dist, Integer.MAX_VALUE); dist[src] = 0;
for (int i = 0; i < n - 1; i++)
    for (int[] e : edges)                  // e = {u, v, w}
        if (dist[e[0]] != Integer.MAX_VALUE && dist[e[0]] + e[2] < dist[e[1]])
            dist[e[1]] = dist[e[0]] + e[2];
// One more pass; if any update occurs ⇒ negative cycle exists.

Java — Floyd-Warshall Template

int[][] d = new int[n][n];                 // init: 0 on diag, w on edges, INF else
for (int k = 0; k < n; k++)
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        if (d[i][k] + d[k][j] < d[i][j]) d[i][j] = d[i][k] + d[k][j];
