P13 — Reachable Nodes in Subdivided Graph

Hard • LC #882

Pattern

// Run Dijkstra on the COMPACT graph; remaining = M - dist[u].
// For each edge u-v with cnt subdivisions: usable from u = min(remaining_u, cnt),
//   usable from v = min(remaining_v, cnt); answer adds min(cnt, usable_u + usable_v).
// Plus the count of compact nodes with dist ≤ M.
Insight: Treat each edge as a corridor of subdivision-nodes; nodes reachable from either end are counted, capped by the corridor length.
