P18 — Remove Max Number of Edges

Hard • LC #1579

Pattern

// DSU alice, bob. Phase 1: type-3 edges — union in BOTH.
// Phase 2: type-1 edges union in alice. Phase 3: type-2 edges union in bob.
// Count edges that were "needed" (union returned true); answer = total - needed.
// Final check: both alice.components == 1 and bob.components == 1.
Insight: Process type-3 first — every shared edge benefits both, so it's never inferior to two separate edges.
