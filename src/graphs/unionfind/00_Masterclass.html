25.5 Union-Find (DSU) — Masterclass

Union-Find (Disjoint Set Union, DSU) maintains a partition of elements into disjoint sets while supporting two operations: find(x) (which set?) and union(x, y) (merge sets). With path compression + union-by-rank, both operations run in effectively O(α(n)) — practically constant time.

Jargon Buster

DSU / Union-Find
Same thing — Disjoint Set Union. A forest where each tree represents one set; root is the canonical label.
Path compression
During find, point every visited node directly to the root. Flattens the tree.
Union by rank/size
When merging, hang the shorter tree under the taller one. Keeps heights small.
α(n)
Inverse Ackermann — grows so slowly it's bounded by 5 for any practical n.
Weighted Union-Find
Each node stores a value relative to its parent (e.g., ratio, offset). Maintain that value through path compression.

Java — Standard DSU

class DSU {
    int[] parent, rank;
    int components;
    DSU(int n) {
        parent = new int[n]; rank = new int[n]; components = n;
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    int find(int x) {
        while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }
        return x;
    }
    boolean union(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (rank[ra] < rank[rb]) { int t = ra; ra = rb; rb = t; }
        parent[rb] = ra;
        if (rank[ra] == rank[rb]) rank[ra]++;
        components--;
        return true;
    }
}

When to reach for DSU

  • Connectivity questions: "Are these two in the same group?" / "How many groups?"
  • Dynamic edge insertions (offline can also handle deletions via reverse-time tricks)
  • MST via Kruskal — sort edges, union if disjoint
  • Grouping by equivalence (== relations, swap groups, account merging)
  • Cycle detection in undirected graphs (union returns false ⇒ cycle)
