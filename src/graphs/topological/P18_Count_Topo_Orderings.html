P18 — Count Topological Orderings

Hard

Pattern (Bitmask DP)

// dp[mask] = number of topo orders covering exactly the nodes in mask.
// Transition: for each v ∉ mask with all predecessors ⊂ mask, dp[mask | (1<<v)] += dp[mask].
// Answer = dp[(1<<n) - 1]. O(2ⁿ · n).
Insight: Mask records exactly "which nodes have been placed" — perfect for n ≤ 20.
