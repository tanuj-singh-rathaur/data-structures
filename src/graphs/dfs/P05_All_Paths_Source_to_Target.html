P05 — All Paths Source to Target

Medium • LC #797

Java

void dfs(int u, int n, int[][] g, List<Integer> path, List<List<Integer>> res) {
    if (u == n - 1) { res.add(new ArrayList<>(path)); return; }
    for (int v : g[u]) {
        path.add(v);
        dfs(v, n, g, path, res);
        path.remove(path.size() - 1);
    }
}
Insight: DAG ⇒ no visited check needed; path itself prevents revisit.
