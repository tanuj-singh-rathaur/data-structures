Graphs · DFS — Masterclass

Depth-first traversal of graphs solves connectivity, cycle detection, bipartiteness, articulation points, SCCs, and topological order.

Jargon

3-Colour DFS
White (unvisited), gray (on recursion stack), black (done). Back-edge to gray ⇒ cycle in directed graphs.
disc[u] / low[u]
Tarjan's discovery time and lowest reachable disc. Foundation of bridges, articulation, SCC.
Tree Edge / Back Edge
Tree edge = first visit. Back edge = goes to ancestor (cycle indicator).
Component
Maximal set of mutually reachable nodes. DFS sweep counts components.

Template

boolean[] visited = new boolean[n];
void dfs(int u) {
    visited[u] = true;
    for (int v : graph[u]) if (!visited[v]) dfs(v);
}
// Iterate all nodes; each unvisited starts a new component.
