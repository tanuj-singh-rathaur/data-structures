P16 — Critical Connections (Bridges)

Hard • LC #1192

Pattern (Tarjan)

// disc[u] = DFS discovery time; low[u] = min disc reachable.
// On DFS edge u→v: dfs(v); low[u] = min(low[u], low[v]); if low[v] > disc[u] ⇒ u-v is a bridge.
// Back-edges to ancestors lower low[u].
Insight: A bridge has no alternative path — its removal disconnects the component.
