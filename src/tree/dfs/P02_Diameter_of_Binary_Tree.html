P02 — Diameter of Binary Tree

Easy • LC #543

Java

int best;
public int diameterOfBinaryTree(TreeNode r) { best=0; depth(r); return best; }
int depth(TreeNode n) {
    if (n==null) return 0;
    int L=depth(n.left), R=depth(n.right);
    best = Math.max(best, L+R);
    return 1 + Math.max(L, R);
}
Insight: Local return = max single side; global update = through-node total.
