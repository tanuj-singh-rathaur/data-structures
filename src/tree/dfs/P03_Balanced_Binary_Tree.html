P03 — Balanced Binary Tree

Easy • LC #110

Java

public boolean isBalanced(TreeNode r) { return h(r) != -1; }
int h(TreeNode n) {
    if (n==null) return 0;
    int L=h(n.left); if (L==-1) return -1;
    int R=h(n.right); if (R==-1) return -1;
    if (Math.abs(L-R)>1) return -1;
    return 1 + Math.max(L,R);
}
Insight: Sentinel -1 short-circuits the upstream once any imbalance is detected.
