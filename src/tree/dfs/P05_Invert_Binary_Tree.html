P05 — Invert Binary Tree

Easy • LC #226

Java

public TreeNode invertTree(TreeNode r) {
    if (r==null) return null;
    TreeNode l=invertTree(r.left), R=invertTree(r.right);
    r.left=R; r.right=l;
    return r;
}
Insight: Three-line solution famously asked at Google — recursion does the swap.
