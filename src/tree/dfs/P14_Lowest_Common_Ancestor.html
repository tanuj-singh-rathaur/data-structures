P14 — Lowest Common Ancestor

Medium • LC #236

Java

public TreeNode lowestCommonAncestor(TreeNode r, TreeNode p, TreeNode q) {
    if (r==null || r==p || r==q) return r;
    TreeNode L = lowestCommonAncestor(r.left, p, q);
    TreeNode R = lowestCommonAncestor(r.right, p, q);
    if (L!=null && R!=null) return r;
    return L!=null ? L : R;
}
Insight: If p and q are found in DIFFERENT subtrees of n, n is the LCA.
