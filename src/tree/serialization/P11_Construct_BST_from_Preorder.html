P11 — Construct BST from Preorder

Medium • LC #1008

Java

int i = 0;
TreeNode build(int[] pre, int bound) {
    if (i == pre.length || pre[i] > bound) return null;
    TreeNode n = new TreeNode(pre[i++]);
    n.left = build(pre, n.val);
    n.right = build(pre, bound);
    return n;
}
// call build(preorder, Integer.MAX_VALUE)
Insight: Upper-bound propagation: left subtree bounded by parent's value, right by parent's bound.
