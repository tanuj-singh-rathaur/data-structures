TreeLCA

Tree · LCA — Masterclass

Lowest Common Ancestor problems: find the deepest node ancestral to two (or more) targets. Used in path queries, distance computations, and tree algorithms.

Jargon

LCA
Lowest Common Ancestor — deepest node in the tree that has both p and q in its subtree.
Path Query
Distance, sum, or property along the unique path between two nodes.
Binary Lifting
Sparse table: up[u][k] = 2^k-th ancestor of u. Preprocess O(n log n), query O(log n).
Euler Tour + RMQ
O(n log n) preprocessing, O(1) per query via range-min on depth.

Template (post-order LCA)

TreeNode lca(TreeNode r, TreeNode p, TreeNode q) {
    if (r == null || r == p || r == q) return r;
    TreeNode L = lca(r.left, p, q);
    TreeNode R = lca(r.right, p, q);
    if (L != null && R != null) return r;
    return L != null ? L : R;
}
