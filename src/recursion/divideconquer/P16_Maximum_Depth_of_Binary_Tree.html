P16 — Maximum Depth of Binary Tree

Easy • LC #104 • Pattern: depth(root) = 1 + max(depth(left), depth(right))

📝 The Problem

Return the maximum depth (number of nodes on the longest root-to-leaf path) of a binary tree.

📚 Jargon Buster

Depth (LeetCode)
Node count along the longest root-to-leaf path. Empty tree ⇒ 0.

🌟 In Layman's Terms

Depth of an empty tree is 0. Otherwise, 1 + the larger of the two children's depths.

⚡ The Aha Moment

The base D&C pattern for trees: combine = +1 over max of children.

🔧 Algorithm

  1. If root == null ⇒ 0.
  2. Else ⇒ 1 + max(depth(left), depth(right)).

☕ Java Solution

public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}

⏳ Complexity

Time
O(n)
Space
O(h)

📈 D&C Pattern

Tree D&C Template: Generalises to "max path sum", "diameter", "longest univalue path" — all combine child answers at the current node.
Key Insight: Tree problems almost always boil down to a single combine rule per node — define that, and the recursion writes itself.
