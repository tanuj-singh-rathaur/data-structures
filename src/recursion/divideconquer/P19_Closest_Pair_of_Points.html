P19 — Closest Pair of Points

Hard • CLRS classic • Pattern: Sort by x → Recurse → 7-Point Strip

📝 The Problem

Given n 2D points, find the minimum Euclidean distance between any pair in O(n log n).

📚 Jargon Buster

Strip
Points within d of the split x-line, where d = min(leftMin, rightMin).
7-Point Lemma
Within a sorted-by-y strip, you only need to compare each point with up to 7 successors — closer than that and they'd violate the local minimum.

🌟 In Layman's Terms

Sort by x. Split in half. Find min distance in each half recursively. Then scan a thin vertical band around the split line, sorted by y, comparing each point only against the next 7.

⚡ The Aha Moment

Without the strip step you'd miss cross-half pairs. The 7-point bound keeps the strip scan linear.

🔧 Algorithm

  1. Sort points by x.
  2. Recurse left half and right half ⇒ d = min(left, right).
  3. Filter points within d of split x; sort by y; pairwise compare next 7 only.

☕ Java Solution (sketch)

public double closestPair(double[][] pts) {
    java.util.Arrays.sort(pts, (a, b) -> Double.compare(a[0], b[0]));
    return solve(pts, 0, pts.length - 1);
}
private double solve(double[][] p, int lo, int hi) {
    if (hi - lo < 3) return bruteForce(p, lo, hi);
    int mid = lo + (hi - lo) / 2;
    double midX = p[mid][0];
    double d = Math.min(solve(p, lo, mid), solve(p, mid + 1, hi));
    // Build strip of points within d of midX, sort by y, scan with 7-window
    return Math.min(d, stripBest(p, lo, hi, midX, d));
}

⏳ Complexity

Time
O(n log n)
Space
O(n)

📈 D&C Pattern

D&C + Bounded Strip: A geometric problem that's not solvable in O(n log n) without the strip-scan combine.
Key Insight: Bounded comparison count (7) is a geometric invariant — points can't pack closer than d without violating "min so far."
