P15 — Convert Sorted Array to BST

Easy • LC #108 • Pattern: Middle Element Becomes Root

📝 The Problem

Given a sorted array, build a height-balanced BST.

📚 Jargon Buster

Height-Balanced
Heights of left and right subtrees of every node differ by at most 1.

🌟 In Layman's Terms

Pick the middle as root; recurse on left half for left subtree and right half for right subtree. By construction, each subtree's size differs by at most 1 ⇒ balanced.

⚡ The Aha Moment

Sorted order + middle-as-root gives both BST property and balance for free.

🔧 Algorithm

  1. build(lo, hi): if lo > hi ⇒ null.
  2. mid = (lo + hi) / 2; root = nums[mid]; recurse on each half.

☕ Java Solution

public TreeNode sortedArrayToBST(int[] nums) {
    return build(nums, 0, nums.length - 1);
}
private TreeNode build(int[] a, int lo, int hi) {
    if (lo > hi) return null;
    int mid = lo + (hi - lo) / 2;
    TreeNode root = new TreeNode(a[mid]);
    root.left  = build(a, lo, mid - 1);
    root.right = build(a, mid + 1, hi);
    return root;
}

⏳ Complexity

Time
O(n)
Space
O(log n) stack

📈 D&C Pattern

Middle-as-Root: The cleanest example of D&C constructing a structure rather than computing a value.
Key Insight: Any sorted source can produce a balanced BST in O(n); this idea also works for sorted linked lists with slow/fast pointers.
