P07 — Kth Largest Element

Medium • LC #215 • Pattern: Quickselect: Partition + Recurse Single Side

📝 The Problem

Return the kth largest element (1-indexed). Expected O(n).

📚 Jargon Buster

Quickselect
Quicksort that only recurses into the side containing the target index.
Target Index
kth largest ⇒ index n − k in ascending order.

🌟 In Layman's Terms

Pick a pivot, partition the array. The pivot ends up at its final sorted position. If that index matches what we want, done. Otherwise recurse into the relevant side.

⚡ The Aha Moment

Recursion depth halves on average (only one side) ⇒ T(n) = T(n/2) + O(n) = O(n).

🔧 Algorithm

  1. Target = n − k. Randomise input order to avoid worst case.
  2. Partition; if pivotPos == target ⇒ return. Else recurse one side.

☕ Java Solution

public int findKthLargest(int[] nums, int k) {
    java.util.Random rnd = new java.util.Random();
    int lo = 0, hi = nums.length - 1, target = nums.length - k;
    while (lo <= hi) {
        int p = partition(nums, lo, hi, rnd);
        if (p == target) return nums[p];
        if (p < target) lo = p + 1;
        else            hi = p - 1;
    }
    return -1;
}
private int partition(int[] a, int lo, int hi, java.util.Random rnd) {
    int pivotIdx = lo + rnd.nextInt(hi - lo + 1);
    int pivot = a[pivotIdx]; swap(a, pivotIdx, hi);
    int store = lo;
    for (int i = lo; i < hi; i++) if (a[i] < pivot) swap(a, i, store++);
    swap(a, store, hi);
    return store;
}
private void swap(int[] a, int i, int j) { int t = a[i]; a[i] = a[j]; a[j] = t; }

⏳ Complexity

Time
O(n) avg / O(n²) worst
Space
O(1)

📈 D&C Pattern

Partition + Single-Side Recurse: The same pattern solves "kth smallest", median-of-medians, and weighted selection.
Key Insight: If you only need one slot of the sorted order, never fully sort.
