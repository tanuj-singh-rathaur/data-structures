Recursion · Divide & Conquer — Masterclass

Split a problem into smaller independent subproblems, solve them recursively, then combine.

📝 What Is Divide & Conquer?

Three steps: Divide (split into smaller subproblems), Conquer (solve each recursively), Combine (merge results). The recurrence is typically T(n) = a · T(n/b) + f(n) where the Master Theorem governs complexity.

📚 Jargon Buster

Base Case
The smallest problem you can solve directly without recursing.
Recurrence Relation
Equation expressing T(n) in terms of T of smaller inputs.
Combine Step
Work done to merge child results — often the dominant cost (e.g., O(n) merge).
Master Theorem
Cookbook for T(n) = a·T(n/b) + f(n). Gives O(n log n), O(n), O(n²), etc.
Quickselect
Divide & conquer variant where you recurse on ONE side only ⇒ expected O(n).
Sentinel Return
Special value (e.g., −1) propagated upward to short-circuit on failure.

🎯 When to use Divide & Conquer

  • Sorting or selection on large arrays (merge sort, quicksort, quickselect).
  • Tree construction or traversal where each node's answer depends on its children.
  • Counting cross-pair structures (inversions, reverse pairs) using the merge step.
  • Geometry (closest pair, convex hull) where a "strip / cross-mid" combine works.
  • Interval DP framed recursively (Burst Balloons, Different Ways to Add Parens).

🏭 The 5 Sub-Patterns

1. Split-Recurse-Merge (Sort)

Half + half + linear combine.

T(n) = 2T(n/2) + O(n)

Merge Sort, Sort List, Count Inversions, Reverse Pairs

2. Partition-Recurse (Select)

Pivot, recurse on one side.

T(n) = T(n/2) + O(n) avg

Quick Sort, Kth Largest (Quickselect)

3. Halve-Exponent / Binary Split

Logarithmic recursion depth.

T(n) = T(n/2) + O(1)

Pow(x, n), Beautiful Array, Convert Sorted Array to BST

4. Recurse-Both-Subtrees (Tree)

Each node combines its children's answers.

f(node) = combine(f(left), f(right))

Max Depth, Balanced Tree, Construct Tree (Pre/In, In/Post), Majority D&C, Max Subarray, Skyline

5. Interval Divide (Pick Pivot k)

For each split point k, recurse left/right and combine.

O(n³) with memo

Burst Balloons, Different Ways to Add Parens, Largest Rectangle (D&C), Closest Pair

⚙️ Universal Templates

Split-Recurse-Merge:

void solve(int[] a, int lo, int hi) {
    if (lo >= hi) return;             // base
    int mid = lo + (hi - lo) / 2;
    solve(a, lo, mid);                // conquer left
    solve(a, mid + 1, hi);             // conquer right
    merge(a, lo, mid, hi);             // combine
}

Partition-Recurse (Quickselect):

int select(int[] a, int lo, int hi, int k) {
    if (lo == hi) return a[lo];
    int p = partition(a, lo, hi);
    if (p == k) return a[p];
    return p < k ? select(a, p + 1, hi, k) : select(a, lo, p - 1, k);
}

Tree D&C:

int dfs(Node n) {
    if (n == null) return 0;          // base
    int L = dfs(n.left), R = dfs(n.right);
    return combine(n.val, L, R);
}
