P04 — Different Ways to Add Parentheses

Medium • LC #241 • Pattern: Split on Each Operator + Memo

📝 The Problem

Given an expression of digits and operators, return all possible results from inserting parentheses in any valid way.

📚 Jargon Buster

Operator as Pivot
Each operator i splits the expression into a left-sub-expression and a right-sub-expression.
Cross Product
For each left value × each right value, apply the operator to produce one result.

🌟 In Layman's Terms

For each operator, imagine evaluating "everything to the left" and "everything to the right" as independent sub-problems, then combine results pairwise.

⚡ The Aha Moment

Same substring may be computed by many parent calls — memoise by substring (or by index range).

🔧 Algorithm

  1. If the string is a pure number, return [parsed].
  2. For each operator: recurse left, recurse right, combine cross-product.
  3. Memoise by substring.

☕ Java Solution

private Map<String, List<Integer>> memo = new HashMap<>();
public List<Integer> diffWaysToCompute(String s) {
    if (memo.containsKey(s)) return memo.get(s);
    List<Integer> res = new ArrayList<>();
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (c == '+' || c == '-' || c == '*') {
            for (int L : diffWaysToCompute(s.substring(0, i)))
                for (int R : diffWaysToCompute(s.substring(i + 1)))
                    res.add(c == '+' ? L + R : c == '-' ? L - R : L * R);
        }
    }
    if (res.isEmpty()) res.add(Integer.parseInt(s));
    memo.put(s, res);
    return res;
}

⏳ Complexity

Time
Catalan-bounded; memoised polynomial
Space
O(memo · output)

📈 D&C Pattern

Interval Pivot: "Try every split point inside an interval" pattern reappears in Burst Balloons, Matrix Chain, Boolean Parens.
Key Insight: When all combinations matter (not just one), the cross-product step is unavoidable but cheap if children are memoised.
