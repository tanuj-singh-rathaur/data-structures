P05 — Maximum Subarray (D&C Variant)

Medium • LC #53 • Pattern: max = max(left, right, crossingMid)

📝 The Problem

Return the maximum sum of any contiguous subarray.

📚 Jargon Buster

Crossing Sum
Max sum of a subarray that strictly spans the midpoint = best suffix of left + best prefix of right.

🌟 In Layman's Terms

Split in half. The answer is either entirely in the left half, entirely in the right half, or spans the middle. Compute each, take the max.

⚡ The Aha Moment

The crossing case can be found in O(n) by walking outward from the midpoint — that's the "combine" step.

🔧 Algorithm

  1. Base: single element ⇒ return it.
  2. Recurse left and right halves; compute crossing.
  3. Return max of the three.

☕ Java Solution

public int maxSubArray(int[] nums) { return dq(nums, 0, nums.length - 1); }
private int dq(int[] a, int lo, int hi) {
    if (lo == hi) return a[lo];
    int mid = lo + (hi - lo) / 2;
    int L = dq(a, lo, mid), R = dq(a, mid + 1, hi);
    int leftSum = Integer.MIN_VALUE, sum = 0;
    for (int i = mid; i >= lo; i--) { sum += a[i]; leftSum = Math.max(leftSum, sum); }
    int rightSum = Integer.MIN_VALUE; sum = 0;
    for (int i = mid + 1; i <= hi; i++) { sum += a[i]; rightSum = Math.max(rightSum, sum); }
    return Math.max(Math.max(L, R), leftSum + rightSum);
}

⏳ Complexity

Time
O(n log n)
Space
O(log n)

📈 D&C Pattern

Three-Way Combine: Whenever a span can lie left, right, or straddle, the D&C combine adds the crossing case.
Key Insight: Kadane's algorithm is O(n) — the D&C version is mainly didactic, but the cross-mid idea generalises to other problems (e.g., maximum rectangle).
