P02 — Find All Anagrams in a String

Medium • LC #438 • Pattern: Fixed Window + Frequency Match

📝 The Problem

Return all starting indices where a permutation of p appears as a substring of s.

Example: s = "cbaebabacd", p = "abc" → [0, 6]

📚 Jargon Buster

Anagram
Same characters with the same counts, in any order.
Matches counter
Number of distinct letters whose count in the window equals the count in p. When it equals 26 (or |alphabet|), they match.
Why a counter beats array equality
Comparing two 26-slot arrays per slide is O(26). Tracking a single integer (matches) makes it O(1).

🌟 In Layman's Terms

Keep a fixed window of size |p|. Maintain a count of how many letters currently match p exactly. When the window matches, record the start index.

⚡ The Aha Moment

The matches integer only needs to flip when a count crosses the required value — either becoming equal or leaving equal. That's the O(1) trick.

🔧 Algorithm

  1. Build need[26] from p. Compute initial matches = # of letters where need[i] == 0.
  2. Slide fixed window of size |p|. Update window[c] on add/remove; update matches on transitions.
  3. If matches == 26, push R - |p| + 1.

☕ Java Solution

public List<Integer> findAnagrams(String s, String p) {
    List<Integer> res = new ArrayList<>();
    if (p.length() > s.length()) return res;
    int[] need = new int[26], win = new int[26];
    for (char c : p.toCharArray()) need[c - 'a']++;
    int matches = 0;
    for (int i = 0; i < 26; i++) if (need[i] == 0) matches++;
    int K = p.length();
    for (int R = 0; R < s.length(); R++) {
        int c = s.charAt(R) - 'a';
        win[c]++;
        if (win[c] == need[c]) matches++;
        else if (win[c] == need[c] + 1) matches--;
        if (R >= K) {
            int lc = s.charAt(R - K) - 'a';
            win[lc]--;
            if (win[lc] == need[lc]) matches++;
            else if (win[lc] == need[lc] - 1) matches--;
        }
        if (matches == 26) res.add(R - K + 1);
    }
    return res;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Sliding Window Pattern

Fixed Window + Frequency Match: Same machinery as Permutation in String (P03) but collect every match instead of returning on the first.
Key Insight: The boundary transitions (count just hit / just left required value) are the only events that move the matches counter. Everything else is no-op.
