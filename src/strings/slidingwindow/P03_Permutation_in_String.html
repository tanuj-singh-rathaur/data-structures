P03 — Permutation in String

Medium • LC #567 • Pattern: Fixed Window + Frequency Match

📝 The Problem

Does s2 contain any permutation of s1 as a substring? Return true/false.

Example: s1 = "ab", s2 = "eidbaooo" → true

📚 Jargon Buster

Permutation = anagram
Same multiset of characters. Frequency arrays must match.
Fixed window
Size = |s1|. Slide over s2 in single-character steps.
Return on first hit
Unlike P02 (find all), we just need a yes/no, so we can short-circuit.

🌟 In Layman's Terms

Imagine sliding a stencil of size |s1| across s2. At each position check: do the letter counts inside the stencil match s1's letter counts? If yes anywhere, return true.

⚡ The Aha Moment

Same template as Anagrams (P02). The only change: return true on the first matches==26 instead of collecting indices.

🔧 Algorithm

  1. Same as P02; return true when matches == 26 (or |alphabet|).

☕ Java Solution

public boolean checkInclusion(String s1, String s2) {
    if (s1.length() > s2.length()) return false;
    int[] need = new int[26], win = new int[26];
    for (char c : s1.toCharArray()) need[c - 'a']++;
    int matches = 0;
    for (int i = 0; i < 26; i++) if (need[i] == 0) matches++;
    int K = s1.length();
    for (int R = 0; R < s2.length(); R++) {
        int c = s2.charAt(R) - 'a';
        win[c]++;
        if (win[c] == need[c]) matches++;
        else if (win[c] == need[c] + 1) matches--;
        if (R >= K) {
            int lc = s2.charAt(R - K) - 'a';
            win[lc]--;
            if (win[lc] == need[lc]) matches++;
            else if (win[lc] == need[lc] - 1) matches--;
        }
        if (matches == 26) return true;
    }
    return false;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Sliding Window Pattern

Fixed Window + Frequency Match: P02 and P03 share the same engine. "Find all" vs "exists" just changes the return convention.
Key Insight: Re-using the same algorithm across "find all" and "find any" problems is the mark of a well-internalized template.
