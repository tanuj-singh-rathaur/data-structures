P15 — Maximum Erasure Value

Medium • LC #1695 • Pattern: Longest Distinct Subarray + Sum Tracking

📝 The Problem

Given nums (positive), return the maximum sum of a subarray with all distinct elements.

Example: [4,2,4,5,6] → 17 (subarray [2,4,5,6])

📚 Jargon Buster

All distinct
No value appears more than once inside the window.
HashSet trick
Set of values currently inside the window. On duplicate, shrink L removing values until the duplicate is gone.
Running sum
Track the window sum alongside; update on add/remove.

🌟 In Layman's Terms

Same as "longest substring without repeating" but with integers and we track a sum, not just a length. Slide window, kick out duplicates from the left, watch the max sum.

⚡ The Aha Moment

Maintain BOTH a HashSet (distinct check) AND a running sum. Same shape as the longest-substring template — just a different metric to track.

🔧 Algorithm

  1. seen = HashSet, L = 0, sum = 0, best = 0.
  2. For R: while seen contains nums[R]: seen.remove(nums[L]); sum -= nums[L]; L++. seen.add(nums[R]); sum += nums[R].
  3. best = max(best, sum).

☕ Java Solution

public int maximumUniqueSubarray(int[] nums) {
    Set<Integer> seen = new HashSet<>();
    int L = 0, sum = 0, best = 0;
    for (int R = 0; R < nums.length; R++) {
        while (seen.contains(nums[R])) {
            seen.remove(nums[L]);
            sum -= nums[L];
            L++;
        }
        seen.add(nums[R]);
        sum += nums[R];
        best = Math.max(best, sum);
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(n)

📈 Sliding Window Pattern

Variable Window + HashSet: Same shape as P01 but tracking a sum. The duplicate-removal loop is the only nontrivial step.
Key Insight: Two parallel pieces of state (HashSet + running sum) update in lockstep. Add together on R-shift, remove together on L-shift.
