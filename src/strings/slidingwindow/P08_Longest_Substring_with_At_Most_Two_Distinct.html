P08 — Longest Substring with At Most Two Distinct Characters

Medium • LC #159 • Pattern: At-Most-K with K=2

📝 The Problem

Return the length of the longest substring containing at most 2 distinct characters.

Example: "ccaabbb" → 5

📚 Jargon Buster

K = 2 special case
This is P04 (At-Most-K Distinct) hard-coded to K=2. Same template.
Stepping stone
Often asked before P04 to ease people into the generic at-most-K pattern.

🌟 In Layman's Terms

Slide a window; if it ever holds more than 2 distinct letters, shrink from the left until you're back to 2. Track the max length.

⚡ The Aha Moment

Generic templates eat specific problems. The at-most-K skeleton with K=2 substituted in solves this in three lines.

🔧 Algorithm

  1. Same as P04 with K=2.

☕ Java Solution

public int lengthOfLongestSubstringTwoDistinct(String s) {
    Map<Character, Integer> count = new HashMap<>();
    int L = 0, best = 0;
    for (int R = 0; R < s.length(); R++) {
        count.merge(s.charAt(R), 1, Integer::sum);
        while (count.size() > 2) {
            char lc = s.charAt(L);
            count.merge(lc, -1, Integer::sum);
            if (count.get(lc) == 0) count.remove(lc);
            L++;
        }
        best = Math.max(best, R - L + 1);
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Sliding Window Pattern

At-Most-K Distinct (K=2): The "fixed-K instance" of P04. Same code, different value.
