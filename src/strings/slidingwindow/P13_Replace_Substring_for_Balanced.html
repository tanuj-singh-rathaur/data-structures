P13 — Replace the Substring for Balanced String

Medium • LC #1234 • Pattern: Shrink-to-Min Window with Outside Counts

📝 The Problem

String s of length n uses only 'Q', 'W', 'E', 'R'. Balanced = each letter occurs exactly n/4 times. Return the minimum length substring you can replace to make s balanced.

Example: "QQWE" → 1 (replace one Q with R)

📚 Jargon Buster

Outside counts
The counts of Q, W, E, R outside the candidate window (the part we're NOT replacing).
Validity
Outside counts of every letter must be ≤ n/4 — the rest can come from the replaced window.
Shrink-to-min
Standard pattern for "find smallest window satisfying property." Shrink L while valid, recording each smaller-but-still-valid length.

🌟 In Layman's Terms

Look for a window to "rewrite." The rest of the string (outside the window) must already obey the n/4 cap for every letter. Find the smallest such window.

⚡ The Aha Moment

Don't think about "what to put in the window." Think about whether what's OUTSIDE the window is already legal. If yes, you can always fix the inside.

🔧 Algorithm

  1. cnt[4] = total counts of QWER in s. need = n/4.
  2. Slide window; decrement cnt for chars entering the window.
  3. While outside is valid (all cnt ≤ need): record window length; cnt[s[L]]++, L++.

☕ Java Solution

public int balancedString(String s) {
    int n = s.length(), need = n / 4;
    int[] cnt = new int[128];
    for (char c : s.toCharArray()) cnt[c]++;
    int L = 0, best = n;
    for (int R = 0; R < n; R++) {
        cnt[s.charAt(R)]--;
        while (L < n && cnt['Q'] <= need && cnt['W'] <= need
               && cnt['E'] <= need && cnt['R'] <= need) {
            best = Math.min(best, R - L + 1);
            cnt[s.charAt(L)]++;
            L++;
        }
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Sliding Window Pattern

Complement Window (Shrink-to-Min): Reframe "what to put in the window" as "what's outside must already be balanced." Then the standard shrink-to-min template solves it.
Key Insight: The reframe is the whole trick. Once you realize you only need to validate the outside, the inside becomes irrelevant.
