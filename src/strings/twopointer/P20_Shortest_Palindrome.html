P20 — Shortest Palindrome

Hard • LC #214 • Pattern: Longest Palindrome Prefix + Reverse Tail

📝 The Problem

Convert s to a palindrome by adding the fewest characters in front. Return the resulting shortest palindrome.

Example: "aacecaaa" → "aaacecaaa"

📚 Jargon Buster

Palindrome prefix
The longest prefix of s that is itself a palindrome. Whatever's after that prefix needs a mirror added in front.
Two-pointer check (naive)
Find the largest k such that s[0..k-1] is a palindrome. Then prepend reverse(s[k..end]). Naive search is O(n²); KMP-based search is O(n).
KMP variant
Build the failure function of s + '#' + reverse(s) — the final value tells you the length of the longest palindrome prefix in linear time.

🌟 In Layman's Terms

Find the longest piece at the START of the string that already reads the same forwards and backwards. Whatever's after that piece needs to be mirrored and stuck on the front. That's the minimum addition.

⚡ The Aha Moment

The minimum prepend equals the suffix-tail that lies after the longest palindromic prefix. Finding that palindrome prefix is the whole job.

🔧 Algorithm

  1. Find the largest k such that s[0..k-1] is a palindrome (naive: two-pointer check decreasing k; fast: KMP).
  2. Return reverse(s[k..]) + s.

☕ Java Solution (Naive — clear, O(n²))

public String shortestPalindrome(String s) {
    int n = s.length();
    for (int k = n; k >= 0; k--) {
        if (isPalin(s, 0, k - 1)) {
            String tail = s.substring(k);
            return new StringBuilder(tail).reverse().append(s).toString();
        }
    }
    return s;
}
private boolean isPalin(String s, int L, int R) {
    while (L < R) {
        if (s.charAt(L) != s.charAt(R)) return false;
        L++; R--;
    }
    return true;
}

For O(n), use the KMP failure function on s + '#' + reverse(s).

⏳ Complexity

Time (naive)
O(n²)
Time (KMP)
O(n)
Space
O(n)

📈 Two Pointer Pattern

Palindrome Anchor: The two-pointer is-palindrome check is the building block; the outer search tries decreasing prefix lengths. KMP upgrades the search to linear time.
Key Insight: Don't try every possible prepend — you only need to find one number, the length of the longest palindrome prefix.
