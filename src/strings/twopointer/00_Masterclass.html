💡 What Is Two Pointer on Strings? (Layman's Explanation)

Same idea as arrays, but the “cells” are characters. Place two fingers on a string and let them walk: toward each other (palindrome check), away from a center (palindromic substring expansion), or in lockstep across two strings (is this a subsequence of that?).

The win is the same: instead of nested loops (O(n²)), each pointer crosses the string at most once — O(n).

📚 Jargon Buster (Confusing Terms Explained)

Palindrome
A string that reads the same forwards and backwards: "racecar", "abba".
Substring vs Subsequence
Substring = contiguous slice. Subsequence = pick chars in order but can skip. "act" is a subsequence of "cactus", not a substring.
In-place
Modify the input directly without allocating a new string. Java strings are immutable — use char[] or StringBuilder.
Two pointers vs Two indices
Same thing. The "pointer" terminology is a convention; in Java these are just int L, int R.
Expand around center
A palindrome-finding trick. Plant a center on every index (and between every pair) and walk two pointers outward while characters keep matching.
Token / Word boundary
The transitions between groups of characters (e.g., between spaces). Multi-pointer tricks parse one token at a time.
Anchor vs Probe
Used in strStr-style problems. The anchor (i) marks a candidate start; the probe (j) walks the needle to verify.
Vertical scan
Walk one character position across multiple strings at once (used in Longest Common Prefix).

🔎 When Should You Use Two Pointer on Strings?

  • Checking palindromes (forward equals reverse).
  • Reversing a string or its parts in place.
  • Comparing two strings character by character.
  • Matching subsequence or prefix.
  • Finding the longest palindromic substring (expand around center).
  • Walking two strings simultaneously with different rules per side.

📈 The 5 Types of String Two Pointer — Full Breakdown

① Opposite Ends (Palindrome / Reverse)

What it is: One pointer at index 0, one at index n−1. Compare and move inward.

Recognize it when:

  • "Is this a palindrome?"
  • Reverse all or part of a string in place
  • Skip non-letters or non-alphanumerics while checking symmetry

The decision rule:

  • If s[L] == s[R]: L++, R--
  • If they differ: return false (or try skipping one side for "valid palindrome II")
Worked Example: Valid Palindrome — "A man, a plan, a canal: Panama"
Filtered to "amanaplanacanalpanama", compare from both ends
Start
[ama…ama]
L=0, R=n−1. Match ✓. Move both.
Loop
continue matching inward
Every step matches; pointers meet → true
Code Template: 
int L = 0, R = s.length() - 1;
while (L < R) {
    if (s.charAt(L) != s.charAt(R)) return false;
    L++; R--;
}
return true;

② Expand Around Center (Palindromic Substrings)

What it is: Place a center on every index (odd-length palindromes) AND between every adjacent pair (even-length palindromes). From each center, walk two pointers outward as long as the characters match.

Recognize it when:

  • "Longest palindromic substring"
  • "Count palindromic substrings"
  • Brute force is O(n³) (try every substring + check palindrome)

The decision rule:

  • For each i: expand center=i (odd) and center=(i, i+1) (even)
  • While L ≥ 0, R < n, s[L]==s[R]: L--, R++
  • Record longest length / increment count per successful expansion
Worked Example: Longest Palindromic Substring — "babad"
Center at index 2 ('b' in "ba**b**ad")
Init
babad
L=R=2 (center='b')
Step
babad
L=1, R=3. s[L]=='a', s[R]=='a' ✓
Step
babad
L=0, R=4. 'b' vs 'd' ✗ — stop. Palindrome = "aba" (length 3)
Code Template: 
for (int i = 0; i < n; i++) {
    expand(s, i, i);     // odd-length center
    expand(s, i, i + 1); // even-length center
}
void expand(String s, int L, int R) {
    while (L >= 0 && R < s.length() && s.charAt(L) == s.charAt(R)) {
        L--; R++;
    }
    // s[L+1..R-1] is the palindrome
}

③ Same Direction, Two Inputs (Subseq / Merge / Compare)

What it is: One pointer per string. Both walk forward. Advancement rules differ per problem: advance one on match, advance both alternately, etc.

Recognize it when:

  • "Is s a subsequence of t?"
  • Merging two strings alternately
  • Long-pressed name / typo verification
  • Comparing version strings token by token

The decision rule:

  • Walk i over A and j over B
  • On match: do something + advance one or both
  • Termination: i or j hits end
Worked Example: Is Subsequence — s = "abc", t = "ahbgdc"
i over s, j over t; advance i only on match
j=0
t[0]='a' == s[0]='a' ✓
i=1, j=1
j=1
t[1]='h' != s[1]='b'
just j++
j=2
t[2]='b' == s[1]='b' ✓
i=2, j=3
j=3..5
skip g, d; t[5]='c' == s[2]='c' ✓
i=3 == s.length() → true
Code Template: 
int i = 0, j = 0;
while (i < s.length() && j < t.length()) {
    if (s.charAt(i) == t.charAt(j)) i++;
    j++;
}
return i == s.length();

④ Slow + Fast (In-Place Compression)

What it is: Two pointers in the same direction: slow is the write head, fast is the scanner. Same idea as “Move Zeroes” on arrays but on a char[].

Recognize it when:

  • Compress runs of identical chars in place
  • Remove certain characters in place
  • Output must overwrite the input

The decision rule:

  • fast walks every character
  • slow only advances when a finalized chunk is written
  • Return slow at the end — it's the new length
Worked Example: String Compression — "aaabbc" → "a3b2c1" in place (when run ≥ 2; else just the char)
slow = write head, fast = scanner
Run 'a'
fast finds 3 a's
write 'a' then "3", slow moves past both
Run 'b'
fast finds 2 b's
write 'b' then "2"
Run 'c'
1 'c'
write 'c' only (count of 1 omitted in this variant)
Code Template: 
int slow = 0, fast = 0;
while (fast < n) {
    char c = chars[fast];
    int run = 0;
    while (fast < n && chars[fast] == c) { fast++; run++; }
    chars[slow++] = c;
    if (run > 1) for (char d : Integer.toString(run).toCharArray()) chars[slow++] = d;
}
return slow;

⑤ Two-Pass / Vertical Scan

What it is: Sometimes the "pointer" sweeps the same string twice (once forward, once backward), or sweeps the same index across several strings at once. Both fall under "specialized two-pointer."

Recognize it when:

  • Each index needs info from both sides (Shortest Distance to Character)
  • Compare characters at the same position across multiple inputs (Longest Common Prefix)

The decision rule:

  • For two-pass: forward sweep tracks one side; backward sweep tracks the other; combine
  • For vertical scan: outer loop = column index; inner loop = string index; stop at the first mismatch
Worked Example: Shortest Distance to Character — s = "loveleetcode", c = 'e'
Pass 1 (left→right): distance to last seen 'e' on the left
Sweep
track prev = index of last 'e' (init −∞)
res[i] = i − prev
Pass 2 (right→left): distance to next 'e' on the right
Sweep
track prev (init +∞)
res[i] = min(res[i], prev − i)
Code Template: 
int[] res = new int[n];
int prev = -n;
for (int i = 0; i < n; i++) {
    if (s.charAt(i) == c) prev = i;
    res[i] = i - prev;
}
prev = 2 * n;
for (int i = n - 1; i >= 0; i--) {
    if (s.charAt(i) == c) prev = i;
    res[i] = Math.min(res[i], prev - i);
}
