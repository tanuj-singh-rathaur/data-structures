P08 — Reverse Only Letters

Easy • LC #917 • Pattern: Opposite Ends + Skip Non-Letters

📝 The Problem

Reverse only the letters of s; all non-letter characters keep their positions.

Example: "a-bC-dEf-ghIj" → "j-Ih-gfE-dCba"

📚 Jargon Buster

Letter
Character.isLetter(c) — ASCII A-Z or a-z (per problem constraints).
Selective swap
Same pattern as Reverse Vowels: pointers move inward; swap only when both are on letters; skip non-letters with one-side advancement.

🌟 In Layman's Terms

Pointers converge from both ends. Non-letter? Skip with one pointer. Both letters? Swap and step inward.

⚡ The Aha Moment

Identical to Reverse Vowels (P02) with a different "is target character" predicate.

🔧 Algorithm

  1. Two pointers L, R. While L < R: skip non-letters; swap; advance.

☕ Java Solution

public String reverseOnlyLetters(String s) {
    char[] a = s.toCharArray();
    int L = 0, R = a.length - 1;
    while (L < R) {
        while (L < R && !Character.isLetter(a[L])) L++;
        while (L < R && !Character.isLetter(a[R])) R--;
        char t = a[L]; a[L] = a[R]; a[R] = t;
        L++; R--;
    }
    return new String(a);
}

⏳ Complexity

Time
O(n)
Space
O(n) for char[]

📈 Two Pointer Pattern

Opposite Ends + Selective Swap: Family of P01 (palindrome), P02 (vowels), P08 (letters). All vary only by the predicate that decides "what counts."
Key Insight: One template, many predicates. Master the skeleton and these "reverse only X" problems become 5-line tweaks.
