P03 — Valid Palindrome II

Easy • LC #680 • Pattern: Opposite Ends + One Skip

📝 The Problem

Return true if you can make s a palindrome by deleting at most one character.

Example: "abca" → true (remove 'b' or 'c')

📚 Jargon Buster

One-deletion palindrome
The string is one edit away from being a palindrome.
Helper sub-check
When the two pointers disagree, we try skipping the left character OR the right character and check if the remaining slice is a palindrome.
Greedy disambiguation
Either the left or right pointer must be the "bad" one. Both candidates must be tested.

🌟 In Layman's Terms

Walk inward from both ends. The instant you spot a mismatch, you have two choices: delete the left char or delete the right char. Check both substrings with a vanilla palindrome test; succeed if either works.

⚡ The Aha Moment

You don't have to backtrack from earlier matches. The first mismatch is the only place a deletion could matter, so check exactly two candidate substrings.

🔧 Algorithm

  1. Walk L and R. On mismatch, return isPalin(s, L+1, R) || isPalin(s, L, R-1).
  2. If pointers meet without mismatch: true.

☕ Java Solution

public boolean validPalindrome(String s) {
    int L = 0, R = s.length() - 1;
    while (L < R) {
        if (s.charAt(L) != s.charAt(R)) {
            return isPalin(s, L + 1, R) || isPalin(s, L, R - 1);
        }
        L++; R--;
    }
    return true;
}
private boolean isPalin(String s, int L, int R) {
    while (L < R) {
        if (s.charAt(L) != s.charAt(R)) return false;
        L++; R--;
    }
    return true;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Two Pointer Pattern

Opposite Ends + One Retry: Standard palindrome check with a single allowed "rewind" branching into two sub-checks at the first mismatch.
Key Insight: The two pre-mismatch sides are already palindromic mirrors. So you only need to test the inner remainder — the skip choice is binary.
