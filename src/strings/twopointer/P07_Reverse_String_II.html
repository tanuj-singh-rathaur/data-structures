P07 — Reverse String II

Easy • LC #541 • Pattern: Walk in 2k Chunks; Reverse First k

📝 The Problem

Given a string s and integer k, reverse the first k characters in every 2k-chunk. If fewer than k remain, reverse all of them. If between k and 2k remain, reverse the first k and leave the rest.

Example: s = "abcdefg", k = 2 → "bacdfeg"

📚 Jargon Buster

Chunked iteration
Walk indices in steps of 2k: 0, 2k, 4k, …
Bounded reverse
At each chunk start i, reverse s[i..min(i+k, n)−1]. The min handles the "fewer than k remain" case.

🌟 In Layman's Terms

Imagine the string is broken into 2k-sized chunks. In each chunk, flip the first k characters. The leftover chunk at the end follows the same rule with whatever's left.

⚡ The Aha Moment

The clever min(i + k, n) takes care of every edge case (length not divisible by 2k) without a separate branch.

🔧 Algorithm

  1. For i = 0; i < n; i += 2k: reverse s[i .. min(i+k, n)-1] in place on a char[].

☕ Java Solution

public String reverseStr(String s, int k) {
    char[] a = s.toCharArray();
    int n = a.length;
    for (int i = 0; i < n; i += 2 * k) {
        int L = i, R = Math.min(i + k, n) - 1;
        while (L < R) { char t = a[L]; a[L] = a[R]; a[R] = t; L++; R--; }
    }
    return new String(a);
}

⏳ Complexity

Time
O(n)
Space
O(n) for char[]

📈 Two Pointer Pattern

Block Reverse: The base Reverse String operation applied to fixed-size chunks. min handles the partial trailing chunk cleanly.
Key Insight: Stride by 2k, reverse only the first k. The clever bound at min(i + k, n) eats both "fewer than k" and "between k and 2k" edge cases without an if-statement.
