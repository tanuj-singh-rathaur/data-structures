P11 — Merge Strings Alternately

Easy • LC #1768 • Pattern: Two Pointers + Flush Leftover

📝 The Problem

Given two strings word1 and word2, merge them by alternating one character from each (start with word1). If one runs out, append the rest of the other.

Example: "abc", "pqr" → "apbqcr"

📚 Jargon Buster

Alternating merge
Char from A, then B, then A, then B, …
Flush leftover
After one string runs out, dump the entire remainder of the other.

🌟 In Layman's Terms

Two stacks of letter cards (word1 and word2). Lay them down alternately: card from pile A, then pile B, repeat. When one pile is empty, slap the rest of the other on top.

⚡ The Aha Moment

One pointer per string lets you advance independently. The leftover flush is two lines — no special-case logic needed.

🔧 Algorithm

  1. i = j = 0. While i < |w1| AND j < |w2|: append w1[i++], then w2[j++].
  2. Append the rest of whichever still has characters.

☕ Java Solution

public String mergeAlternately(String w1, String w2) {
    StringBuilder sb = new StringBuilder();
    int i = 0, j = 0;
    while (i < w1.length() && j < w2.length()) {
        sb.append(w1.charAt(i++));
        sb.append(w2.charAt(j++));
    }
    if (i < w1.length()) sb.append(w1.substring(i));
    if (j < w2.length()) sb.append(w2.substring(j));
    return sb.toString();
}

⏳ Complexity

Time
O(|w1| + |w2|)
Space
O(|w1| + |w2|)

📈 Two Pointer Pattern

Same Direction (2 Inputs): The textbook "two-pointer over two sequences" merge. Advancement order is the only thing that varies between problems.
Key Insight: Don't try to handle leftover inside the main loop. A separate flush at the end is cleaner and easier to reason about.
