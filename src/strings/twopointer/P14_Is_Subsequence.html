P14 — Is Subsequence

Easy • LC #392 • Pattern: Advance-on-Match

📝 The Problem

Return true if s is a subsequence of t (you can delete some chars of t without changing order to get s).

Example: s = "abc", t = "ahbgdc" → true

📚 Jargon Buster

Subsequence
Pick characters from t in order; skipping is allowed; reordering is not.
Advance-on-match
Walk j over t every step. Advance i over s only when characters match.
Success
i == s.length() at the end means every char of s was matched in order.

🌟 In Layman's Terms

Walk through t. Hold a pointer to "the next character of s I still need." Each time t shows you that character, tick it off (advance i). If i finishes, s was a subsequence.

⚡ The Aha Moment

The greedy “take the first occurrence” is optimal. There's no benefit to skipping an earlier match.

🔧 Algorithm

  1. i = j = 0. While j < |t| AND i < |s|: if s[i] == t[j], i++. Always j++.
  2. Return i == |s|.

☕ Java Solution

public boolean isSubsequence(String s, String t) {
    int i = 0, j = 0;
    while (i < s.length() && j < t.length()) {
        if (s.charAt(i) == t.charAt(j)) i++;
        j++;
    }
    return i == s.length();
}

⏳ Complexity

Time
O(|s| + |t|)
Space
O(1)

📈 Two Pointer Pattern

Advance-on-Match: Pointer j scans the "supply" (t). Pointer i advances over the "demand" (s) only on match. The simplest 2-input pattern there is.
Key Insight: Greedy matching works because subsequence order is fixed. Taking a later match never helps — it can only fail to.
