P05 — Palindromic Substrings

Medium • LC #647 • Pattern: Expand Around Center (Counting)

📝 The Problem

Count the number of palindromic substrings in s. Substrings at different positions count as different even if they look identical.

Example: "aaa" → 6 ("a","a","a","aa","aa","aaa")

📚 Jargon Buster

Counting variant
Same expand-around-center machinery as P04 — just increment a counter at every successful expansion step instead of tracking the max.
Every step is one palindrome
Each time the expansion succeeds, you've discovered a new (longer) palindrome centered at this point.

🌟 In Layman's Terms

Same expand-from-center trick. Every time the expansion grows, you've found a new palindrome; tally it. Don't reset between centers.

⚡ The Aha Moment

Counting and finding-the-longest both use the exact same exploration. Replace the "track best" step with "increment count" and you're done.

🔧 Algorithm

  1. For each i: expand around (i, i) and (i, i+1).
  2. Each successful step (matching pair) increments the count by 1.

☕ Java Solution

private int count = 0;
public int countSubstrings(String s) {
    for (int i = 0; i < s.length(); i++) {
        expand(s, i, i);
        expand(s, i, i + 1);
    }
    return count;
}
private void expand(String s, int L, int R) {
    while (L >= 0 && R < s.length() && s.charAt(L) == s.charAt(R)) {
        count++;
        L--; R++;
    }
}

⏳ Complexity

Time
O(n²)
Space
O(1)

📈 Two Pointer Pattern

Expand-Around-Center (Counting): Same template as P04 with a counter instead of a max-length tracker.
Key Insight: A successful step in the expansion is a palindrome discovery. Increment immediately — don't wait for the expansion to stop.
