P15 — Backspace String Compare

Easy • LC #844 • Pattern: Right-to-Left + Skip Counter

📝 The Problem

Two strings; '#' means “backspace.” Return true if both produce the same final string. O(1) extra space preferred.

Example: s = "ab#c", t = "ad#c" → true (both become "ac")

📚 Jargon Buster

Backspace
The # consumes the previous (non-#) effective character. Multiple backspaces eat multiple chars.
Skip counter
Right-to-left, track how many "pending backspaces" to apply. Increment on #, decrement on a real char (and skip that char if there's a pending backspace).
Why right-to-left
Going forward means undoing characters you've already accepted — awkward. Going backward, you naturally know which characters survive.

🌟 In Layman's Terms

Walk both strings backward. Track how many "I owe a delete" tokens you've accumulated on each side. When you reach a real character with no pending deletes, that's an effective character — compare it across sides.

⚡ The Aha Moment

Right-to-left lets you skip exactly the characters that would have been deleted, without ever building the actual output strings.

🔧 Algorithm

  1. i = |s|-1, j = |t|-1. Loop: walk each pointer left, consuming '#'s and skipping the right number of real chars.
  2. Compare the two surviving chars (or check both ran out).

☕ Java Solution

public boolean backspaceCompare(String s, String t) {
    int i = s.length() - 1, j = t.length() - 1;
    while (i >= 0 || j >= 0) {
        i = nextValid(s, i);
        j = nextValid(t, j);
        char ci = i >= 0 ? s.charAt(i) : 0;
        char cj = j >= 0 ? t.charAt(j) : 0;
        if (ci != cj) return false;
        i--; j--;
    }
    return true;
}
private int nextValid(String s, int i) {
    int skip = 0;
    while (i >= 0 && (s.charAt(i) == '#' || skip > 0)) {
        if (s.charAt(i) == '#') skip++;
        else skip--;
        i--;
    }
    return i;
}

⏳ Complexity

Time
O(|s| + |t|)
Space
O(1)

📈 Two Pointer Pattern

Right-to-Left + Skip Counter: Walking backwards converts “backspace” from a state-mutating action into a stateless skip count.
Key Insight: Direction choice matters. The same problem becomes O(1) space when scanned right-to-left because the deletion semantics align with the walk.
