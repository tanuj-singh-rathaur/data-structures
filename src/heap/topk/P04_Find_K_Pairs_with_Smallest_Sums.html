P04 — Find K Pairs with Smallest Sums

Medium • LC #373

Pattern

// Min-heap of (sum, i, j). Start with (a[0]+b[0], 0, 0). Pop k times.
// When popping (i, j): push (i+1, j) and (i, j+1) using visited-set to avoid dups.
Insight: Implicit sorted matrix walk — Dijkstra-style frontier exploration.
