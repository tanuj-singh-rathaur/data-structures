P09 — Additive Number

Medium • LC #306 • Pick first two operand lengths

Problem

Is num an additive sequence? a + b = c, b + c = d, ...

Pattern

Decide lengths for the first two operands (i, j). The rest is deterministic — verify a + b matches the prefix at position i + j, then slide.

Java

public boolean isAdditiveNumber(String num) {
    int n = num.length();
    for (int i = 1; i <= n / 2; i++) {
        if (num.charAt(0) == '0' && i > 1) break;
        for (int j = 1; Math.max(i, j) <= n - i - j; j++) {
            if (num.charAt(i) == '0' && j > 1) break;
            if (check(num, i, j)) return true;
        }
    }
    return false;
}
boolean check(String num, int i, int j) {
    long a = Long.parseLong(num.substring(0, i)), b = Long.parseLong(num.substring(i, i + j));
    int start = i + j;
    while (start < num.length()) {
        long sum = a + b;
        String s = Long.toString(sum);
        if (!num.startsWith(s, start)) return false;
        a = b; b = sum; start += s.length();
    }
    return true;
}

Complexity

O(n³) worst.

Insight: Two-decisions-then-verify is much cheaper than choosing each operand's length recursively.
