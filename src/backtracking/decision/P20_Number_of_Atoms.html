P20 — Number of Atoms

Hard • LC #726 • Recursive parser

Problem

Parse a chemical formula (with nested groups) and return atom counts in canonical form.

Pattern

Recursive descent: decide if next token is '(', ')', a digit, or a letter. Groups recurse and multiply by trailing number.

Java

private int i;
private String f;
public String countOfAtoms(String formula) {
    i = 0; f = formula;
    Map<String, Integer> m = parse();
    StringBuilder sb = new StringBuilder();
    for (var e : new TreeMap<>(m).entrySet()) {
        sb.append(e.getKey());
        if (e.getValue() > 1) sb.append(e.getValue());
    }
    return sb.toString();
}
Map<String, Integer> parse() {
    Map<String, Integer> map = new HashMap<>();
    while (i < f.length() && f.charAt(i) != ')') {
        if (f.charAt(i) == '(') {
            i++;
            Map<String, Integer> sub = parse();
            i++;  // skip ')'
            int mult = readNum();
            for (var e : sub.entrySet()) map.merge(e.getKey(), e.getValue() * mult, Integer::sum);
        } else {
            String name = readName();
            int cnt = readNum();
            map.merge(name, cnt, Integer::sum);
        }
    }
    return map;
}
String readName() {
    int s = i++;
    while (i < f.length() && Character.isLowerCase(f.charAt(i))) i++;
    return f.substring(s, i);
}
int readNum() {
    if (i >= f.length() || !Character.isDigit(f.charAt(i))) return 1;
    int s = i;
    while (i < f.length() && Character.isDigit(f.charAt(i))) i++;
    return Integer.parseInt(f.substring(s, i));
}

Complexity

O(n²) for repeated merges; can be O(n) with stack-based parsing.

Insight: Recursive descent shows up wherever the grammar is balanced parens.
