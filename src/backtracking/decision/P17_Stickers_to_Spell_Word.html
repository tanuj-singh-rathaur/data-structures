P17 — Stickers to Spell Word

Hard • LC #691 • Bitmask state + memo

Problem

Minimum number of stickers to spell target (or -1).

Pattern

State = bitmask of which target letters are still needed (or covered). Try each sticker; consume its letters; recurse. Memoise by state.

Java

Map<Integer, Integer> memo = new HashMap<>();
public int minStickers(String[] stickers, String target) {
    int n = target.length();
    int res = dfs(stickers, target, 0, n);
    return res >= 1 << 30 ? -1 : res;
}
int dfs(String[] st, String tgt, int mask, int n) {
    if (mask == (1 << n) - 1) return 0;
    if (memo.containsKey(mask)) return memo.get(mask);
    int best = 1 << 30;
    for (String s : st) {
        int next = mask;
        int[] cnt = new int[26]; for (char c : s.toCharArray()) cnt[c-'a']++;
        for (int i = 0; i < n; i++) {
            char c = tgt.charAt(i);
            if ((mask & (1 << i)) == 0 && cnt[c-'a'] > 0) { next |= 1 << i; cnt[c-'a']--; }
        }
        if (next != mask) best = Math.min(best, 1 + dfs(st, tgt, next, n));
    }
    memo.put(mask, best);
    return best;
}

Complexity

O(2ⁿ · S · n) — state space × work per state.

Insight: Bitmask over target letters makes memoisation tractable.
