P04 — Remove Invalid Parentheses

Hard • LC #301 • Keep/Skip each char with minimum removals

Problem

Remove the MINIMUM number of parens to make s valid; return all unique results.

Pattern

Two-pass count: how many '(' and ')' must be removed. DFS keep/skip each '(' or ')'. Sort-skip-dedup-at-level avoids duplicates.

Java (BFS variant)

public List<String> removeInvalidParentheses(String s) {
    Set<String> visited = new HashSet<>(); visited.add(s);
    Queue<String> q = new ArrayDeque<>(); q.add(s);
    List<String> res = new ArrayList<>();
    boolean found = false;
    while (!q.isEmpty()) {
        int sz = q.size();
        for (int k=0;k<sz;k++) {
            String cur = q.poll();
            if (valid(cur)) { res.add(cur); found = true; }
            if (found) continue;
            for (int i=0;i<cur.length();i++) {
                char c = cur.charAt(i);
                if (c != '(' && c != ')') continue;
                String nx = cur.substring(0,i) + cur.substring(i+1);
                if (visited.add(nx)) q.add(nx);
            }
        }
        if (found) break;
    }
    return res;
}

Complexity

O(2ⁿ) worst.

Insight: BFS by removal count guarantees minimum removals on first valid layer.
