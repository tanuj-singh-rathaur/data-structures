P12 — Concatenated Words

Hard • LC #472 • Split into 2+ dict words

Problem

Return all words from the input that can be formed by concatenating 2+ other words from the same list.

Pattern

For each candidate word, DP "wordBreak"-style with the dictionary minus itself. Use Word Break I as a subroutine.

Java

public List<String> findAllConcatenatedWordsInADict(String[] words) {
    Set<String> set = new HashSet<>(Arrays.asList(words));
    List<String> res = new ArrayList<>();
    for (String w : words) {
        set.remove(w);
        if (canForm(w, set)) res.add(w);
        set.add(w);
    }
    return res;
}
boolean canForm(String w, Set<String> dict) {
    if (dict.isEmpty()) return false;
    int n = w.length();
    boolean[] dp = new boolean[n + 1]; dp[0] = true;
    for (int i = 1; i <= n; i++)
        for (int j = 0; j < i && !dp[i]; j++)
            if (dp[j] && dict.contains(w.substring(j, i))) dp[i] = true;
    return dp[n];
}

Complexity

O(N · L²).

Insight: Excluding the word being tested forces ≥ 2 pieces (no trivial self-match).
