P05 — Decode Ways

Medium • LC #91 • Take 1 or 2 digits

Problem

"A"=1, ..., "Z"=26. Count ways to decode a digit string.

Pattern

At each i: try 1 digit (if 1-9) and try 2 digits (if 10-26). Memoise by i — overlapping subproblems make this DP.

Java (DP)

public int numDecodings(String s) {
    int n = s.length();
    int[] dp = new int[n + 1]; dp[n] = 1;
    for (int i = n - 1; i >= 0; i--) {
        if (s.charAt(i) == '0') { dp[i] = 0; continue; }
        dp[i] = dp[i + 1];
        if (i + 1 < n) {
            int v = Integer.parseInt(s.substring(i, i + 2));
            if (v <= 26) dp[i] += dp[i + 2];
        }
    }
    return dp[0];
}

Complexity

O(n) time, O(n) space (O(1) with rolling vars).

Insight: '0' has no decoding on its own — combine with the previous digit or fail.
