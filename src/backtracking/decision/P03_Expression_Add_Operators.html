P03 — Expression Add Operators

Hard • LC #282 • Insert +, -, × between digits

Problem

Insert + - × (no parens) into a digit string so the expression equals target. Return all such expressions.

Pattern

At each position pick the next operand's LENGTH (1, 2, …; no leading zeros), then pick an operator. Track running total and "previous" operand to handle multiplication precedence.

Java

void dfs(String n, int i, long total, long prev, String expr, long target, List<String> res) {
    if (i == n.length()) { if (total == target) res.add(expr); return; }
    for (int j = i+1; j <= n.length(); j++) {
        if (j-i > 1 && n.charAt(i) == '0') break;
        long cur = Long.parseLong(n.substring(i, j));
        if (i == 0) dfs(n, j, cur, cur, "" + cur, target, res);
        else {
            dfs(n, j, total + cur, cur, expr + "+" + cur, target, res);
            dfs(n, j, total - cur, -cur, expr + "-" + cur, target, res);
            dfs(n, j, total - prev + prev * cur, prev * cur, expr + "*" + cur, target, res);
        }
    }
}

Complexity

O(4ⁿ) bounded by 3 operators × n positions.

Insight: Track "prev" to undo it when multiplying — that's how × overrides the previous + or - precedence.
