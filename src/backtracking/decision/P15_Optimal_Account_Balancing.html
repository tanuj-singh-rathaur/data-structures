P15 — Optimal Account Balancing

Hard • LC #465 • Settle nonzero balances

Problem

Minimum transactions to settle a set of net balances (some positive, some negative).

Pattern

Compute net balance per person. Drop zeros. DFS: pick the first nonzero, settle it against every other nonzero of opposite sign; recurse; backtrack.

Java

public int minTransfers(int[][] tx) {
    Map<Integer, Integer> bal = new HashMap<>();
    for (int[] t : tx) { bal.merge(t[0], -t[2], Integer::sum); bal.merge(t[1], t[2], Integer::sum); }
    List<Integer> debts = new ArrayList<>();
    for (int v : bal.values()) if (v != 0) debts.add(v);
    return dfs(debts, 0);
}
int dfs(List<Integer> d, int i) {
    while (i < d.size() && d.get(i) == 0) i++;
    if (i == d.size()) return 0;
    int min = Integer.MAX_VALUE;
    for (int j = i + 1; j < d.size(); j++) {
        if (d.get(j) * d.get(i) < 0) {
            d.set(j, d.get(j) + d.get(i));
            min = Math.min(min, 1 + dfs(d, i + 1));
            d.set(j, d.get(j) - d.get(i));
        }
    }
    return min;
}

Complexity

O(n!) worst.

Insight: Skip same-sign matches; only opposite-sign settlements reduce nonzero count.
