P07 — Partition to K Equal Sum Subsets

Medium • LC #698 • Bucket assignment

Problem

Partition nums into k subsets with equal sum.

Pattern

Sort descending. Try to place each number into each of k buckets (skip if it overflows). The "empty-bucket symmetry prune" cuts huge subtrees: if a bucket is currently empty and our placement failed, no further bucket will succeed either.

Java

public boolean canPartitionKSubsets(int[] nums, int k) {
    int sum = 0; for (int x : nums) sum += x;
    if (sum % k != 0) return false;
    int target = sum / k;
    Arrays.sort(nums);
    if (nums[nums.length - 1] > target) return false;
    return dfs(nums, nums.length - 1, new int[k], target);
}
boolean dfs(int[] nums, int i, int[] buckets, int target) {
    if (i < 0) return true;
    for (int b = 0; b < buckets.length; b++) {
        if (buckets[b] + nums[i] > target) continue;
        if (b > 0 && buckets[b] == buckets[b - 1]) continue;
        buckets[b] += nums[i];
        if (dfs(nums, i - 1, buckets, target)) return true;
        buckets[b] -= nums[i];
        if (buckets[b] == 0) break;
    }
    return false;
}

Complexity

O(kⁿ) worst with strong pruning.

Insight: Symmetry prune ("equal bucket" + "empty bucket") is what makes this practical.
