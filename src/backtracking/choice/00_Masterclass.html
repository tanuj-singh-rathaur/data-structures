Backtracking · Choice — Masterclass

Enumerate all valid arrangements by making a choice, recursing, and then undoing the choice ("backtrack").

📝 What Is Choice-Based Backtracking?

At each step you face a finite set of choices. Try one, recurse, then undo it and try the next. The decision tree's leaves are the full solutions. Pruning cuts off entire subtrees once you can prove they won't yield valid results.

📚 Jargon Buster

State
The partial solution built so far (path, used set, sum, etc.). Modified before recursion, undone after.
Choice
One of several options available at the current step. Each choice spawns a recursive branch.
Backtrack
Undo the most recent choice before trying the next ("for-loop body: do/recurse/undo").
Prune
Skip a branch you can prove won't lead to a valid solution (sum too large, used too many, sorted-array dedup).
Dedup-at-Level
Skip duplicate values among siblings at the same depth — typically by sorting + comparing to previous.
Used-Set / Visited
Boolean array tracking which inputs are currently in the path. Essential for permutations.

🎯 When to use Choice-Based Backtracking

  • Enumerate ALL valid arrangements (subsets, combinations, permutations, partitions).
  • Find ONE arrangement satisfying constraints (N-Queens, Sudoku).
  • Count without listing (Beautiful Arrangement, Letter Tile Possibilities) — but DP often wins here.
  • Brute search bounded by aggressive pruning.

🏭 The 5 Sub-Patterns

1. Include/Exclude per Element

Each element joins the path or doesn't.

dfs(i): path.add; dfs(i+1); path.remove; dfs(i+1)

Subsets, Subsets II

2. Pick from Start Index

Loop over candidates from a moving start.

for j in [start..n]: pick j, recurse(j or j+1)

Combinations, Combination Sum I/II/III, Increasing Subsequences

3. Permutations (Used-Set)

Any unused element, in any order.

for j in [0..n]: if !used[j]: used; dfs; unused

Permutations, Permutations II, Letter Tile Possibilities, Beautiful Arrangement, Next Permutation

4. Split a String / Range

Choose where to cut next.

for end in [start..n]: if valid(start..end): recurse(end+1)

Palindrome Partitioning, Restore IP Addresses, Letter Combinations, Letter Case Permutation, Generate Parentheses

5. Constraint Grid Search

Place pieces; abort branch if conflict.

Sets/masks for row/col/diag/box

N-Queens, Sudoku Solver, All Paths Source→Target

⚙️ Universal Templates

Include / Exclude:

void dfs(int i, List<Integer> path) {
    if (i == nums.length) { result.add(new ArrayList<>(path)); return; }
    dfs(i + 1, path);                 // exclude
    path.add(nums[i]);                // include
    dfs(i + 1, path);
    path.remove(path.size() - 1);
}

Pick from Start Index:

void dfs(int start, List<Integer> path) {
    result.add(new ArrayList<>(path));   // every node is a subset
    for (int j = start; j < nums.length; j++) {
        if (j > start && nums[j] == nums[j-1]) continue;  // dedup
        path.add(nums[j]);
        dfs(j + 1, path);
        path.remove(path.size() - 1);
    }
}

Permutations:

void dfs(boolean[] used, List<Integer> path) {
    if (path.size() == nums.length) { result.add(new ArrayList<>(path)); return; }
    for (int j = 0; j < nums.length; j++) {
        if (used[j]) continue;
        if (j > 0 && nums[j] == nums[j-1] && !used[j-1]) continue;  // dedup
        used[j] = true; path.add(nums[j]);
        dfs(used, path);
        used[j] = false; path.remove(path.size() - 1);
    }
}
