P05 — Permutations

Medium • LC #46 • Pattern: Used-Set, Loop All Indices

📝 The Problem

Return all permutations of distinct integers nums (n! results).

📚 Jargon Buster

Used-Set
Boolean array marking which indices are currently in the path.
Loop Over All
Unlike combinations, every position considers every UNUSED index — ordering matters.

🌟 In Layman's Terms

At each depth, try every unused number. Mark it used, recurse, then unmark.

⚡ The Aha Moment

No "start" parameter — we always look at all indices because ordering matters.

🔧 Algorithm

  1. dfs(used[], path): if path.size == n ⇒ record.
  2. For j = 0..n−1: if used[j] continue; pick; recurse; unpick.

☕ Java Solution

public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    dfs(nums, new boolean[nums.length], new ArrayList<>(), res);
    return res;
}
private void dfs(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }
    for (int j = 0; j < nums.length; j++) {
        if (used[j]) continue;
        used[j] = true; path.add(nums[j]);
        dfs(nums, used, path, res);
        used[j] = false; path.remove(path.size() - 1);
    }
}

⏳ Complexity

Time
O(n! · n)
Space
O(n)

📈 Choice Pattern

Used-Set Skeleton: The default permutation template — used array + loop over all indices.
Key Insight: An in-place "swap and recurse" variant avoids the path list but is less readable; the used-set version generalises better to duplicates.
