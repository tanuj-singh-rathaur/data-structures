P06 — Permutations II

Medium • LC #47 • Pattern: Sort + Skip Same Value When Previous Unused

📝 The Problem

Return all unique permutations of nums (which may contain duplicates).

📚 Jargon Buster

!used[j-1] Rule
Among equal values, only fill the slot from the EARLIEST unused — break the tie deterministically.

🌟 In Layman's Terms

Sort. Standard permutation with used[]. At each step, skip nums[j] if it equals nums[j−1] and nums[j−1] is currently unused (meaning the duplicate was already placed in the same slot earlier).

⚡ The Aha Moment

"!used[j−1]" is the canonical dedup; "used[j−1]" also works but requires careful reasoning.

🔧 Algorithm

  1. Sort nums.
  2. dfs: loop j; if used[j] continue; if j > 0 && nums[j] == nums[j−1] && !used[j−1] continue.

☕ Java Solution

public List<List<Integer>> permuteUnique(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> res = new ArrayList<>();
    dfs(nums, new boolean[nums.length], new ArrayList<>(), res);
    return res;
}
private void dfs(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }
    for (int j = 0; j < nums.length; j++) {
        if (used[j]) continue;
        if (j > 0 && nums[j] == nums[j - 1] && !used[j - 1]) continue;
        used[j] = true; path.add(nums[j]);
        dfs(nums, used, path, res);
        used[j] = false; path.remove(path.size() - 1);
    }
}

⏳ Complexity

Time
O(n! · n) worst
Space
O(n)

📈 Choice Pattern

Permutation Dedup: The !used[j-1] check is a one-line addition that handles the entire duplicate problem.
Key Insight: Sorting is what makes "equal previous element" semantically meaningful — without it, the dedup check is wrong.
