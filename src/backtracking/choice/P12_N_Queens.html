P12 — N-Queens

Hard • LC #51 • Pattern: Place One Queen Per Row + Column/Diagonal Sets

📝 The Problem

Place n queens on an n×n board so no two attack each other. Return all distinct solutions.

📚 Jargon Buster

Diagonal Encoding
Cell (r, c) lies on diagonal r − c (top-left to bottom-right) and anti-diagonal r + c (top-right to bottom-left).
Conflict Sets
Three Sets<Integer> for columns, diagonals, and anti-diagonals — O(1) attack check.

🌟 In Layman's Terms

Row by row, try each column. Reject if any of the three sets already contains the conflict. Add to sets, recurse, then remove.

⚡ The Aha Moment

Forcing one queen per row removes row conflicts automatically; we only check the three remaining attack lines.

🔧 Algorithm

  1. dfs(row, cols, diag, anti): if row == n ⇒ record placement.
  2. For c in 0..n−1: if cols/diag/anti contains conflict ⇒ skip; else add, recurse, remove.

☕ Java Solution

public List<List<String>> solveNQueens(int n) {
    List<List<String>> res = new ArrayList<>();
    int[] queens = new int[n];
    dfs(0, n, queens, new HashSet<>(), new HashSet<>(), new HashSet<>(), res);
    return res;
}
private void dfs(int r, int n, int[] q, Set<Integer> cols, Set<Integer> diag, Set<Integer> anti, List<List<String>> res) {
    if (r == n) { res.add(build(q, n)); return; }
    for (int c = 0; c < n; c++) {
        if (cols.contains(c) || diag.contains(r - c) || anti.contains(r + c)) continue;
        q[r] = c;
        cols.add(c); diag.add(r - c); anti.add(r + c);
        dfs(r + 1, n, q, cols, diag, anti, res);
        cols.remove(c); diag.remove(r - c); anti.remove(r + c);
    }
}
private List<String> build(int[] q, int n) {
    List<String> b = new ArrayList<>();
    for (int r = 0; r < n; r++) {
        char[] row = new char[n];
        java.util.Arrays.fill(row, '.');
        row[q[r]] = 'Q';
        b.add(new String(row));
    }
    return b;
}
