P11 — Next Permutation

Medium • LC #31 • Pattern: Find Pivot from Right + Swap + Reverse Suffix

📝 The Problem

Rearrange nums into the next lexicographically greater permutation. If impossible, return the lowest possible (sorted ascending). Must be in-place.

📚 Jargon Buster

Pivot
The rightmost index i with nums[i] < nums[i+1] — the first ascending pair from the right.
Swap Target
The smallest element to the right of pivot that's still > nums[pivot].
Reverse Suffix
After the swap, the suffix is descending; reversing it minimises it.

🌟 In Layman's Terms

Walk right-to-left, find the first dip. Swap that dip with the smallest larger value in the tail. Then reverse the tail to make it ascending.

⚡ The Aha Moment

This is NOT pure backtracking — it's a known algorithm. Listed under choice because it operates over the permutation lattice.

🔧 Algorithm

  1. i = largest index with nums[i] < nums[i+1] (if none, reverse all and return).
  2. j = largest index > i with nums[j] > nums[i].
  3. Swap nums[i], nums[j]; reverse nums[i+1..].

☕ Java Solution

public void nextPermutation(int[] nums) {
    int n = nums.length, i = n - 2;
    while (i >= 0 && nums[i] >= nums[i + 1]) i--;
    if (i >= 0) {
        int j = n - 1;
        while (nums[j] <= nums[i]) j--;
        swap(nums, i, j);
    }
    reverse(nums, i + 1, n - 1);
}
private void swap(int[] a, int i, int j) { int t = a[i]; a[i] = a[j]; a[j] = t; }
private void reverse(int[] a, int lo, int hi) {
    while (lo < hi) { swap(a, lo++, hi--); }
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Choice Pattern

Successor in Permutation Lattice: Not backtracking, but operates on the same permutation space. Worth knowing because it's the building block for iterating permutations without recursion.
Key Insight: The minimum increment is the suffix's lex-min — that's why we reverse the (already descending) tail.
