P20 — Spiral Matrix

Medium • LC #54 • Direction cycle with shrinking bounds

Pattern

Maintain top, bottom, left, right boundaries. Walk right→down→left→up; shrink the just-walked boundary. Stop when boundaries cross.

Java

public List<Integer> spiralOrder(int[][] m) {
    List<Integer> res = new ArrayList<>();
    int t=0, b=m.length-1, l=0, r=m[0].length-1;
    while (t<=b && l<=r) {
        for (int c=l;c<=r;c++) res.add(m[t][c]); t++;
        for (int rr=t;rr<=b;rr++) res.add(m[rr][r]); r--;
        if (t<=b) for (int c=r;c>=l;c--) res.add(m[b][c]); b--;
        if (l<=r) for (int rr=b;rr>=t;rr--) res.add(m[rr][l]); l++;
    }
    return res;
}
Insight: Two extra "if" guards prevent re-walking the last row/col on degenerate strips.
