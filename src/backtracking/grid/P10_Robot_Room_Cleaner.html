P10 — Robot Room Cleaner

Hard • LC #489 • DFS with relative coordinates

Pattern

Maintain virtual (row, col, direction). On each call, clean current cell, mark visited. For each of 4 directions: move, recurse, undo by turning 180° + moving + turning 180°.

Java

int[] dr = {-1,0,1,0}, dc = {0,1,0,-1};
Set<String> seen = new HashSet<>();
public void cleanRoom(Robot r) { dfs(r, 0, 0, 0); }
void dfs(Robot r, int row, int col, int dir) {
    String key = row + "," + col;
    if (!seen.add(key)) return;
    r.clean();
    for (int i = 0; i < 4; i++) {
        int nd = (dir + i) % 4;
        int nr = row + dr[nd], nc = col + dc[nd];
        if (r.move()) {
            dfs(r, nr, nc, nd);
            r.turnRight(); r.turnRight(); r.move(); r.turnRight(); r.turnRight();
        }
        r.turnRight();
    }
}
Insight: The robot has no GPS; we track positions ourselves using a HashSet of "r,c" keys.
