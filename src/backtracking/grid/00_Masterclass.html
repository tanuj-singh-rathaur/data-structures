BacktrackingGrid

Backtracking · Grid — Masterclass

DFS through a 2D grid: pick a direction, mark visited, recurse, then unmark. Pruning by boundary, obstacles, and visited-set keeps it tractable.

📚 Jargon Buster

4-Connectivity
Adjacent cells: up, down, left, right. Most grid problems use this.
8-Connectivity
Adjacent including diagonals. Shortest Path in Binary Matrix, Robot Cleaner.
In-Place Visited
Mutate the cell ('#' for char, -1 for int) to mark visited; restore on backtrack — saves an extra array.
Flood Fill
DFS/BFS that marks all reachable cells from a source.
Reverse DFS
Start from the border to mark cells that escape; useful for "surrounded" problems.

🏭 The 5 Sub-Patterns

1. Path with Goal

Find or count a path matching some pattern.

Word Search, Word Search II, Path with Max Gold, Unique Paths III, Rat in a Maze

2. Flood Fill / Connected Component

Mark all reachable cells.

Number of Islands, Max Area, Closed Islands, Distinct Islands, Surrounded Regions, Pacific Atlantic

3. Cell-Filler Constraint

Fill grid respecting per-cell rules.

Sudoku Solver (Grid), Generate Maze

4. Memoised Grid DFS

Cache cell answers when subproblem-shape is independent.

Longest Increasing Path, Cherry Pickup

5. Shortest Path / Slide

BFS or DFS with custom move rules.

Shortest Path Binary Matrix, The Maze, Walls and Gates, Spiral Matrix, Robot Cleaner

⚙️ Universal Template

int[] dr = {-1, 1, 0, 0}, dc = {0, 0, -1, 1};
void dfs(int[][] g, int r, int c, ...) {
    if (r < 0 || c < 0 || r >= m || c >= n || !valid(g, r, c)) return;
    int saved = g[r][c]; g[r][c] = VISITED;
    for (int d = 0; d < 4; d++) dfs(g, r + dr[d], c + dc[d], ...);
    g[r][c] = saved;
}
