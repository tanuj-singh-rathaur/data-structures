P05 — Word Search

Medium • LC #79 • Grid DFS, in-place visited

Pattern

DFS from each cell that matches word[0]. Mark visited with '#'; restore on backtrack.

Java

public boolean exist(char[][] b, String w) {
    for (int r=0;r<b.length;r++) for (int c=0;c<b[0].length;c++)
        if (dfs(b,r,c,w,0)) return true;
    return false;
}
boolean dfs(char[][] b, int r, int c, String w, int i) {
    if (i == w.length()) return true;
    if (r<0||c<0||r>=b.length||c>=b[0].length||b[r][c] != w.charAt(i)) return false;
    char t = b[r][c]; b[r][c] = '#';
    boolean ok = dfs(b,r+1,c,w,i+1)||dfs(b,r-1,c,w,i+1)||dfs(b,r,c+1,w,i+1)||dfs(b,r,c-1,w,i+1);
    b[r][c] = t;
    return ok;
}
Insight: Letter mismatch check first lets the function short-circuit before recursing.
