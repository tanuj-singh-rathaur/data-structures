P02 — Sudoku Solver

Hard • LC #37 • Cell-by-cell DFS with row/col/box bitmasks. See constraint variant for full code.

Pattern

Walk cells in reading order. At each empty cell, try digits 1-9 that don't conflict (row/col/3×3 box). Use bit ops for O(1) checks.
