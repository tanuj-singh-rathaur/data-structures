P09 — Pacific Atlantic Water Flow

Medium • LC #417 • Reverse DFS from both oceans

Pattern

From top/left borders walk to cells whose height ≥ current (reverse uphill from Pacific). Same for bottom/right (Atlantic). Cells in both sets answer.

Java

public List<List<Integer>> pacificAtlantic(int[][] h) {
    int m=h.length, n=h[0].length;
    boolean[][] p = new boolean[m][n], a = new boolean[m][n];
    for (int r=0;r<m;r++) { dfs(h,r,0,p,Integer.MIN_VALUE); dfs(h,r,n-1,a,Integer.MIN_VALUE); }
    for (int c=0;c<n;c++) { dfs(h,0,c,p,Integer.MIN_VALUE); dfs(h,m-1,c,a,Integer.MIN_VALUE); }
    List<List<Integer>> res = new ArrayList<>();
    for (int r=0;r<m;r++) for (int c=0;c<n;c++) if (p[r][c]&&a[r][c]) res.add(List.of(r,c));
    return res;
}
void dfs(int[][] h, int r, int c, boolean[][] v, int prev) {
    if (r<0||c<0||r>=h.length||c>=h[0].length||v[r][c]||h[r][c]<prev) return;
    v[r][c]=true;
    dfs(h,r+1,c,v,h[r][c]); dfs(h,r-1,c,v,h[r][c]); dfs(h,r,c+1,v,h[r][c]); dfs(h,r,c-1,v,h[r][c]);
}
Insight: Reverse-flow lets each ocean's walks visit each cell at most once each.
