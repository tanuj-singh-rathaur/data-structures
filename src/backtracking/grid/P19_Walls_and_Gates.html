P19 — Walls and Gates

Medium • LC #286 • Multi-source BFS

Pattern

Enqueue ALL gates initially. BFS outward; each cell's distance is its order of discovery.

Java

public void wallsAndGates(int[][] r) {
    int m=r.length, n=r[0].length;
    Queue<int[]> q = new ArrayDeque<>();
    for (int i=0;i<m;i++) for (int j=0;j<n;j++) if (r[i][j]==0) q.offer(new int[]{i,j});
    int[][] d = {{0,1},{0,-1},{1,0},{-1,0}};
    while (!q.isEmpty()) {
        int[] c = q.poll();
        for (int[] e : d) {
            int nr=c[0]+e[0], nc=c[1]+e[1];
            if (nr>=0 && nr<m && nc>=0 && nc<n && r[nr][nc] == Integer.MAX_VALUE) {
                r[nr][nc] = r[c[0]][c[1]] + 1;
                q.offer(new int[]{nr,nc});
            }
        }
    }
}
Insight: Multi-source BFS computes the distance to the NEAREST gate in O(mn) — single pass.
