P03 — Word Search II

Hard • LC #212 • Trie + grid DFS

Pattern

Build a trie of all words. DFS each cell; at each step advance via the trie. When a node marks a word, collect it. Trie prunes paths whose prefix isn't a word prefix.

Java

class Node { Node[] kids = new Node[26]; String word; }
public List<String> findWords(char[][] b, String[] words) {
    Node root = new Node();
    for (String w : words) {
        Node n = root;
        for (char c : w.toCharArray()) { if (n.kids[c-'a']==null) n.kids[c-'a'] = new Node(); n = n.kids[c-'a']; }
        n.word = w;
    }
    List<String> res = new ArrayList<>();
    for (int r=0;r<b.length;r++) for (int c=0;c<b[0].length;c++) dfs(b, r, c, root, res);
    return res;
}
void dfs(char[][] b, int r, int c, Node n, List<String> res) {
    char ch = b[r][c];
    if (ch=='#' || n.kids[ch-'a']==null) return;
    Node nx = n.kids[ch-'a'];
    if (nx.word != null) { res.add(nx.word); nx.word = null; }
    b[r][c] = '#';
    if (r>0) dfs(b, r-1, c, nx, res);
    if (r<b.length-1) dfs(b, r+1, c, nx, res);
    if (c>0) dfs(b, r, c-1, nx, res);
    if (c<b[0].length-1) dfs(b, r, c+1, nx, res);
    b[r][c] = ch;
}
Insight: Clearing word once recorded prevents duplicates without a HashSet.
