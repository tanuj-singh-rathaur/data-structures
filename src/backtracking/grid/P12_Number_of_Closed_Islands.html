P12 — Number of Closed Islands

Medium • LC #1254 • Island that doesn't touch the border

Pattern

Pre-sink any '0' land connected to the border (treat as ocean). Then count remaining island components.

Java

public int closedIsland(int[][] g) {
    int m=g.length, n=g[0].length;
    for (int r=0;r<m;r++) { sink(g,r,0); sink(g,r,n-1); }
    for (int c=0;c<n;c++) { sink(g,0,c); sink(g,m-1,c); }
    int count = 0;
    for (int r=1;r<m-1;r++) for (int c=1;c<n-1;c++) if (g[r][c]==0) { count++; sink(g, r, c); }
    return count;
}
void sink(int[][] g, int r, int c) {
    if (r<0||c<0||r>=g.length||c>=g[0].length||g[r][c]!=0) return;
    g[r][c]=1;
    sink(g,r+1,c); sink(g,r-1,c); sink(g,r,c+1); sink(g,r,c-1);
}
Insight: Border preprocessing turns "is closed" into "exists at all" — a much simpler post-condition.
