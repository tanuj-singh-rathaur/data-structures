P13 — Longest Increasing Path in a Matrix

Hard • LC #329 • Memoised grid DFS

Pattern

Strict-increase paths can't loop ⇒ no visited needed. DFS each cell, memoise length. O(mn).

Java

private int[][] memo;
public int longestIncreasingPath(int[][] m) {
    int rows=m.length, cols=m[0].length, best=0;
    memo = new int[rows][cols];
    for (int r=0;r<rows;r++) for (int c=0;c<cols;c++) best = Math.max(best, dfs(m, r, c));
    return best;
}
int dfs(int[][] m, int r, int c) {
    if (memo[r][c] > 0) return memo[r][c];
    int len = 1;
    int[][] d = {{1,0},{-1,0},{0,1},{0,-1}};
    for (int[] e : d) {
        int nr=r+e[0], nc=c+e[1];
        if (nr>=0 && nr<m.length && nc>=0 && nc<m[0].length && m[nr][nc] > m[r][c])
            len = Math.max(len, 1 + dfs(m, nr, nc));
    }
    return memo[r][c] = len;
}
Insight: Strict monotonicity = DAG; topological recursion = memoised DFS.
