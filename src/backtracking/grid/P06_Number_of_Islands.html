P06 — Number of Islands

Medium • LC #200 • Flood fill

Pattern

For each unvisited '1', count it as an island and flood-fill its connected component to mark visited.

Java

public int numIslands(char[][] g) {
    int n = 0;
    for (int r=0;r<g.length;r++) for (int c=0;c<g[0].length;c++)
        if (g[r][c]=='1') { n++; fill(g, r, c); }
    return n;
}
void fill(char[][] g, int r, int c) {
    if (r<0||c<0||r>=g.length||c>=g[0].length||g[r][c]!='1') return;
    g[r][c]='0';
    fill(g,r+1,c); fill(g,r-1,c); fill(g,r,c+1); fill(g,r,c-1);
}
Insight: No need to restore — once an island is counted, its cells stay marked.
