P14 — Number of Distinct Islands

Medium • LC #694 • Canonical shape signature

Pattern

During DFS, record a "shape string" by encoding the direction taken at each step (D/U/L/R) plus a backtrack marker (B). Same shape ⇒ same string.

Java

public int numDistinctIslands(int[][] g) {
    Set<String> shapes = new HashSet<>();
    for (int r=0;r<g.length;r++) for (int c=0;c<g[0].length;c++) {
        if (g[r][c] == 1) {
            StringBuilder s = new StringBuilder();
            dfs(g, r, c, s, 'O'); // origin
            shapes.add(s.toString());
        }
    }
    return shapes.size();
}
void dfs(int[][] g, int r, int c, StringBuilder s, char dir) {
    if (r<0||c<0||r>=g.length||c>=g[0].length||g[r][c]!=1) return;
    s.append(dir); g[r][c] = 0;
    dfs(g,r+1,c,s,'D'); dfs(g,r-1,c,s,'U'); dfs(g,r,c+1,s,'R'); dfs(g,r,c-1,s,'L');
    s.append('B');
}
Insight: Backtrack marker disambiguates shapes that share a prefix.
