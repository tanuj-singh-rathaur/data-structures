P04 — Sudoku Solver

Hard • LC #37 • Row/Col/Box bitmasks

Pattern

Bitmask per row, column, and 3×3 box. At each empty cell try digits not in used = rows[r] | cols[c] | boxes[(r/3)*3+c/3].

Java

int[] rows=new int[9], cols=new int[9], boxes=new int[9];
boolean solve(char[][] b, int r, int c) {
    if (r==9) return true;
    int nr=c==8?r+1:r, nc=c==8?0:c+1;
    if (b[r][c]!='.') return solve(b,nr,nc);
    int used = rows[r]|cols[c]|boxes[(r/3)*3+c/3];
    for (int d=1;d<=9;d++) {
        if ((used & (1<<d))!=0) continue;
        b[r][c]=(char)('0'+d); flip(r,c,d);
        if (solve(b,nr,nc)) return true;
        b[r][c]='.'; flip(r,c,d);
    }
    return false;
}
Insight: MRV heuristic (pick cell with fewest options first) speeds this up dramatically on hard puzzles.
