P10 — Maximum Compatibility Score Sum

Medium • LC #1947 • Assign mentors to students

Pattern

Precompute score[student][mentor]. Try every permutation of mentor assignments — at most 8! = 40320. Use used[] mask while DFS-ing students.

Java

int best = 0;
public int maxCompatibilitySum(int[][] s, int[][] m) {
    int n = s.length;
    int[][] sc = new int[n][n];
    for (int i=0;i<n;i++) for (int j=0;j<n;j++) for (int k=0;k<s[0].length;k++)
        if (s[i][k]==m[j][k]) sc[i][j]++;
    dfs(sc, 0, new boolean[n], 0);
    return best;
}
void dfs(int[][] sc, int i, boolean[] used, int sum) {
    if (i == sc.length) { best = Math.max(best, sum); return; }
    for (int j = 0; j < sc.length; j++) {
        if (used[j]) continue;
        used[j] = true;
        dfs(sc, i+1, used, sum + sc[i][j]);
        used[j] = false;
    }
}
Insight: Bitmask DP solves this in O(2ⁿ·n) for larger n.
