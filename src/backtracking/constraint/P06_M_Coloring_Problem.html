P06 — M-Coloring Problem

Hard • Classic graph coloring

Pattern

Assign one of m colors to each vertex; reject if any neighbour shares the same color. Order matters — color by descending degree to fail fast.

Java

boolean dfs(int v, int n, int m, int[][] g, int[] color) {
    if (v == n) return true;
    for (int c = 1; c <= m; c++) {
        boolean ok = true;
        for (int u = 0; u < n; u++) if (g[v][u] == 1 && color[u] == c) { ok = false; break; }
        if (!ok) continue;
        color[v] = c;
        if (dfs(v+1, n, m, g, color)) return true;
        color[v] = 0;
    }
    return false;
}
Insight: Greedy alone (Welsh-Powell) finds a valid m; backtracking needed to certify minimum m (chromatic number).
