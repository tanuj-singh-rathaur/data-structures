P02 — N-Queens

Hard • LC #51 • Row + 3 conflict sets

Pattern

Place one queen per row. Track columns, diagonals (r−c), anti-diagonals (r+c) in HashSets (or int bitmasks). O(1) conflict check.

Java

void dfs(int r, int n, int[] q, Set<Integer> c, Set<Integer> d, Set<Integer> a, List<List<String>> res) {
    if (r==n) { res.add(build(q,n)); return; }
    for (int x=0; x<n; x++) {
        if (c.contains(x)||d.contains(r-x)||a.contains(r+x)) continue;
        q[r]=x; c.add(x); d.add(r-x); a.add(r+x);
        dfs(r+1,n,q,c,d,a,res);
        c.remove(x); d.remove(r-x); a.remove(r+x);
    }
}
Insight: r−c is unique per ↘ diagonal; r+c per ↙ — that's the conflict-set encoding.
