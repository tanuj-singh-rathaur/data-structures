P17 — Minimum Incompatibility

Hard • LC #1681 • Subset DP over bitmask

Pattern

For each subset of size n/k with distinct elements, precompute (max − min). Bitmask DP: dp[mask] = min total incompatibility to fill the subsets indicated by mask.

Java (sketch)

int n = nums.length, sz = n/k;
int[] cost = new int[1<<n];
Arrays.fill(cost, -1);
for (int m = 0; m < (1<<n); m++) {
    if (Integer.bitCount(m) != sz) continue;
    boolean dup = false; int min=20, max=-1; Set<Integer> s = new HashSet<>();
    for (int i=0;i<n;i++) if ((m>>i & 1)==1) {
        if (!s.add(nums[i])) { dup=true; break; }
        min = Math.min(min, nums[i]); max = Math.max(max, nums[i]);
    }
    if (!dup) cost[m] = max - min;
}
int[] dp = new int[1<<n];
Arrays.fill(dp, Integer.MAX_VALUE);
dp[0] = 0;
for (int m = 0; m < (1<<n); m++) {
    if (dp[m] == Integer.MAX_VALUE) continue;
    int rem = ((1<<n) - 1) & ~m;
    for (int sub = rem; sub > 0; sub = (sub-1) & rem)
        if (cost[sub] != -1) dp[m|sub] = Math.min(dp[m|sub], dp[m] + cost[sub]);
}
return dp[(1<<n)-1];
Insight: Precomputing per-subset cost avoids re-walking the subset inside the DP loop.
