P16 — Restore the Array

Hard • LC #1416 • Split with bound k

Pattern

dp[i] = ways to split s[i..]. For each i, try lengths 1..floor(log10(k))+1 such that s[i..i+len] ≤ k and no leading zero. Sum dp[i+len].

Java

private int[] memo;
private final int MOD = 1_000_000_007;
public int numberOfArrays(String s, int k) {
    memo = new int[s.length() + 1];
    Arrays.fill(memo, -1);
    return dfs(s, 0, k);
}
int dfs(String s, int i, int k) {
    if (i == s.length()) return 1;
    if (s.charAt(i) == '0') return 0;
    if (memo[i] != -1) return memo[i];
    long total = 0, num = 0;
    for (int j = i; j < s.length(); j++) {
        num = num * 10 + (s.charAt(j) - '0');
        if (num > k) break;
        total = (total + dfs(s, j + 1, k)) % MOD;
    }
    return memo[i] = (int) total;
}
Insight: Memoising over the start index turns 2ⁿ paths into O(n · log k).
