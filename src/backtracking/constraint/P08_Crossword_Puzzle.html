P08 — Crossword Puzzle

Hard • Fit words into slots

Pattern

Identify slots (horizontal/vertical runs of '-'). For each slot, try each unused word of matching length; before placing, verify existing letters at the intersection match.

Java (sketch)

boolean solve(char[][] g, List<Slot> slots, int i, String[] words, boolean[] used) {
    if (i == slots.size()) return true;
    Slot s = slots.get(i);
    for (int w = 0; w < words.length; w++) {
        if (used[w] || words[w].length() != s.length) continue;
        if (!fits(g, s, words[w])) continue;
        char[] saved = place(g, s, words[w]);
        used[w] = true;
        if (solve(g, slots, i+1, words, used)) return true;
        used[w] = false;
        restore(g, s, saved);
    }
    return false;
}
Insight: Letter-conflict check before placement prunes most invalid trials.
