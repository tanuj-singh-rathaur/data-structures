P05 — Verbal Arithmetic Puzzle

Hard • LC #1307 • Bijection char ↔ digit

Pattern

Process columns from right (units up). Track carry. Each letter binds to a unique digit; first letter of any multi-digit word can't be 0.

Java (skeleton)

boolean dfs(int col, int row, int carry, Map<Character,Integer> map, boolean[] usedDigit) {
    if (col == maxLen) return carry == 0;
    if (row == words.length) {
        // verify column equation against result word
        ...
    }
    char c = letterAt(words[row], col);
    if (map.containsKey(c)) return dfs(col, row+1, carry+map.get(c), map, usedDigit);
    for (int d=0; d<=9; d++) {
        if (usedDigit[d]) continue;
        if (d==0 && isLead(c)) continue;
        map.put(c,d); usedDigit[d]=true;
        if (dfs(col,row+1,carry+d,map,usedDigit)) return true;
        map.remove(c); usedDigit[d]=false;
    }
    return false;
}
Insight: Column-major DFS lets you propagate the carry rather than enumerate all bindings up front.
