P14 — Number of Ways to Wear Hats

Hard • LC #1434 • Iterate over hats, not people

Pattern

Up to 40 hats but only ≤ 10 people. Flip the iteration: for each hat, decide which person (or none) wears it. State = bitmask of people who already have a hat.

Java

public int numberWays(List<List<Integer>> hats) {
    int MOD = 1_000_000_007, n = hats.size();
    List<List<Integer>> h2p = new ArrayList<>();
    for (int i=0;i<=40;i++) h2p.add(new ArrayList<>());
    for (int p=0;p<n;p++) for (int h : hats.get(p)) h2p.get(h).add(p);
    int[][] dp = new int[41][1 << n]; dp[0][0] = 1;
    for (int h=1;h<=40;h++)
        for (int m=0;m<(1<<n);m++) {
            dp[h][m] = dp[h-1][m];
            for (int p : h2p.get(h))
                if ((m & (1<<p)) != 0)
                    dp[h][m] = (dp[h][m] + dp[h-1][m ^ (1<<p)]) % MOD;
        }
    return dp[40][(1<<n) - 1];
}
Insight: Flipping the iteration domain (people → hats) shrinks the bitmask state space from 2⁴⁰ to 2¹⁰.
