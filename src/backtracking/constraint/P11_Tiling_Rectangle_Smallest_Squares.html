P11 — Tiling a Rectangle with Fewest Squares

Hard • LC #1240 • Height profile

Pattern

Maintain a height profile (one per column). At each step find the leftmost lowest column and try every square size from large to small that fits.

Java (sketch)

int best;
public int tilingRectangle(int n, int m) {
    best = n*m;
    dfs(new int[m], n, m, 0);
    return best;
}
void dfs(int[] h, int n, int m, int count) {
    if (count >= best) return;
    int minH = n; int idx = -1;
    for (int i=0;i<m;i++) if (h[i] < minH) { minH = h[i]; idx = i; }
    if (minH == n) { best = Math.min(best, count); return; }
    int end = idx;
    while (end < m && h[end] == minH && end - idx + 1 + minH <= n) end++;
    for (int len = end - idx; len >= 1; len--) {
        int saved = h[idx];
        for (int k = idx; k < idx + len; k++) h[k] += len;
        dfs(h, n, m, count + 1);
        for (int k = idx; k < idx + len; k++) h[k] = saved;
    }
}
Insight: Without best-so-far pruning, the search explodes; track it globally.
