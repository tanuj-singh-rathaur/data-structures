P14 — Toss Strange Coins

Medium • LC #1230

Pattern

double[] dp = new double[target + 1]; dp[0] = 1.0;
for (double p : prob)
    for (int k = target; k >= 0; k--)
        dp[k] = dp[k] * (1 - p) + (k > 0 ? dp[k-1] * p : 0);
return dp[target];
Insight: Same shape as 0/1 count DP — but the "+= 1 way" becomes "× prob of head" and "× prob of tail".
