P03 — Coin Change (Min Coins)

Medium • LC #322

Java

int[] dp = new int[amount + 1];
Arrays.fill(dp, amount + 1); dp[0] = 0;
for (int c : coins)
    for (int a = c; a <= amount; a++)
        dp[a] = Math.min(dp[a], dp[a - c] + 1);
return dp[amount] > amount ? -1 : dp[amount];
Insight: Sentinel amount + 1 is "impossible" — bigger than any real answer (since the worst real answer uses 1-coins only).
