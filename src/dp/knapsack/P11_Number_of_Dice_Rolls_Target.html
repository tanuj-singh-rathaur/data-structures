P11 — Number of Dice Rolls With Target Sum

Medium • LC #1155

Java

int[][] dp = new int[n + 1][target + 1]; dp[0][0] = 1;
for (int d = 1; d <= n; d++)
  for (int t = 1; t <= target; t++)
    for (int face = 1; face <= k && face <= t; face++)
        dp[d][t] = (dp[d][t] + dp[d-1][t-face]) % MOD;
return dp[n][target];
Insight: Each die contributes a face in [1,k]; ordering matters because dice are distinguishable.
