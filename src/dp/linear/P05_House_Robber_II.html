P05 — House Robber II (circular)

Medium • LC #213

Java

// max(rob(0..n-2), rob(1..n-1)) — eliminate the circular conflict.
return Math.max(robLinear(nums, 0, n-2), robLinear(nums, 1, n-1));
Insight: First and last houses are adjacent ⇒ both can't be picked. Try two disjoint windows; the best of the two wins.
