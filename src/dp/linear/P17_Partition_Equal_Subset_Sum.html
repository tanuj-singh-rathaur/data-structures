P17 — Partition Equal Subset Sum

Medium • LC #416

Java

int sum = 0; for (int x : nums) sum += x;
if ((sum & 1) == 1) return false;
int t = sum / 2;
boolean[] dp = new boolean[t + 1]; dp[0] = true;
for (int x : nums)
    for (int s = t; s >= x; s--)
        dp[s] |= dp[s - x];
return dp[t];
Insight: "Can I reach exactly sum/2?" is classic 0/1 subset-sum. Iterate s descending to keep it 0/1 (each item used at most once).
