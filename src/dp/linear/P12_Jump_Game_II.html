P12 — Jump Game II (Min Jumps)

Medium • LC #45

Java

int jumps = 0, end = 0, far = 0;
for (int i = 0; i < n - 1; i++) {
    far = Math.max(far, i + nums[i]);
    if (i == end) { jumps++; end = far; }
}
return jumps;
Insight: Treat each "current jump's farthest reach" as a BFS level. We commit to a jump whenever the level boundary is crossed.
