P19 — Knight Probability in Chessboard

Medium • LC #688

Pattern

// dp[k][r][c] = probability of being on (r,c) after k moves.
// dp[0][r0][c0] = 1.
// Each step: distribute 1/8 of dp[k-1][r][c] to each of 8 knight neighbours (in-board only).
// Answer = Σ dp[K][r][c] over all on-board cells.
Insight: Probability mass is conserved on-board only — knight moves that fall off the board "evaporate."
