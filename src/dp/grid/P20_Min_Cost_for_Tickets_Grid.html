P20 — Number of Paths with Max Score

Hard • LC #1301

Pattern

// Reverse DP from 'S' at bottom-right; moves are up/left/diag-up-left.
// State: (maxScore[r][c], count[r][c]) MOD 1e9+7.
// On 'X' ⇒ both 0. Combine 3 predecessors: keep larger score; if tie, sum counts.
Insight: Joint DP over a tuple (best, ways) is the standard way to count optimal paths without enumerating them.
