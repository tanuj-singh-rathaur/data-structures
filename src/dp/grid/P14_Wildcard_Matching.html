P14 — Wildcard Matching

Hard • LC #44

Pattern

// dp[0][0] = true; dp[0][j] = dp[0][j-1] when p[j-1] == '*'.
// For ?, or s[i-1]==p[j-1]: dp[i][j] = dp[i-1][j-1].
// For * : dp[i][j] = dp[i-1][j]   (consume a char)
//                 || dp[i][j-1]   (consume zero chars)
Insight: '*' has two flavours: "extend this star to eat one more char" or "close this star and move on" — OR them together.
