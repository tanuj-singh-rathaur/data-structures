P07 — Dungeon Game

Hard • LC #174

Pattern (reverse DP)

// dp[i][j] = minimum HP needed entering (i,j) to reach goal.
// Iterate bottom-right to top-left:
//   need = min(dp[i+1][j], dp[i][j+1]) - grid[i][j];
//   dp[i][j] = Math.max(1, need);
Insight: Forward DP can't handle the "HP must stay ≥ 1 at every step" coupling — reverse DP from the goal makes the constraint local.
