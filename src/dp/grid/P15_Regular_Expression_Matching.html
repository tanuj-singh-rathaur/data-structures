// p[j-1] == '*' means "0 or more of p[j-2]":
//   zero: dp[i][j] = dp[i][j-2]
//   one+: dp[i][j] |= dp[i-1][j] when (p[j-2]=='.' || p[j-2]==s[i-1])
// Else: dp[i][j] = dp[i-1][j-1] when (p[j-1]=='.' || p[j-1]==s[i-1])
Insight: '*' attaches to the previous pattern char — handle them as a pair, not independently.
