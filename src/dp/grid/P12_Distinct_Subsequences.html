P12 — Distinct Subsequences

Hard • LC #115

Java

// dp[i][j] = #ways s[0..i-1] forms t[0..j-1].
// dp[i][0] = 1 (empty t).
if (s.charAt(i-1) == t.charAt(j-1))
    dp[i][j] = dp[i-1][j-1] + dp[i-1][j];   // use s[i-1] or skip it
else
    dp[i][j] = dp[i-1][j];                  // skip s[i-1]
Insight: When chars match, two independent ways add up: "use this s char as the match" OR "skip it and match later."
