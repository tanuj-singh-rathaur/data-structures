P04 — Triangle Minimum Path

Medium • LC #120

Java (bottom-up, O(n) space)

int[] dp = triangle.get(n-1).stream().mapToInt(i->i).toArray();
for (int r = n-2; r >= 0; r--) {
    List<Integer> row = triangle.get(r);
    for (int c = 0; c <= r; c++)
        dp[c] = row.get(c) + Math.min(dp[c], dp[c+1]);
}
return dp[0];
Insight: Bottom-up avoids the awkward "min of left/diagonal" boundary cases at row edges and naturally reuses the same array.
