P13 — Interleaving String

Medium • LC #97

Java

if (s1.length() + s2.length() != s3.length()) return false;
boolean[][] dp = new boolean[m+1][n+1];
dp[0][0] = true;
for (int i = 0; i <= m; i++)
  for (int j = 0; j <= n; j++) {
    if (i > 0) dp[i][j] |= dp[i-1][j] && s1.charAt(i-1) == s3.charAt(i+j-1);
    if (j > 0) dp[i][j] |= dp[i][j-1] && s2.charAt(j-1) == s3.charAt(i+j-1);
  }
return dp[m][n];
Insight: At every position you eat the next char of s3 from either s1 or s2 — boolean DP tracks reachability.
