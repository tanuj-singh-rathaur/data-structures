P18 — Minimum Cost to Merge Stones

Hard • LC #1000

Pattern

// Feasibility: (n - 1) % (k - 1) == 0.
// dp[i][j][p] = min cost to merge stones[i..j] into p piles.
// p == 1: dp[i][j][1] = dp[i][j][k] + sum(i..j).
// p > 1 : dp[i][j][p] = min over m of dp[i][m][1] + dp[m+1][j][p-1] (step m by k-1).
Insight: Need a 3rd dim to count "how many piles remain in this interval" — only when piles == 1 does the merge actually happen and pay the sum.
