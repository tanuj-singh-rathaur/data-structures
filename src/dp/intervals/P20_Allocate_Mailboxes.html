P20 — Allocate Mailboxes

Hard • LC #1478

Pattern

// Sort houses. cost(i, j) = sum |house - median(house[i..j])|.
// dp[k][i] = min cost using k mailboxes for first i houses
//          = min over j of dp[k-1][j] + cost(j+1, i).
Insight: The optimum point that minimises sum of absolute distances is the MEDIAN — that's why each contiguous group's cost has a closed form.
