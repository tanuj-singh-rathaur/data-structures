P03 — Stone Game

Medium • LC #877

Java (minimax)

// dp[i][j] = max score-diff (current - opponent) over piles[i..j].
for (int len = 2; len <= n; len++)
  for (int i = 0; i + len <= n; i++) {
      int j = i + len - 1;
      dp[i][j] = Math.max(piles[i] - dp[i+1][j], piles[j] - dp[i][j-1]);
  }
return dp[0][n-1] > 0;
Insight: Picking a stone of value v shifts the opponent's optimal play to a sub-interval; the current player's net advantage is v − opponent's_best.
