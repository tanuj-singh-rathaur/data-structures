P10 — Optimal Binary Search Tree

Hard

Pattern

// dp[i][j] = min expected cost for keys i..j.
// Choose root r ∈ [i,j]:
//   dp[i][j] = sum(freq[i..j]) + min_r ( dp[i][r-1] + dp[r+1][j] ).
Insight: When you choose a root for a sub-interval, every key in the sub-interval contributes +1 depth — that's why the freq-sum gets added once at every level.
