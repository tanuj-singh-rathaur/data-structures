P14 — Min Insertions to Make Palindrome

Hard • LC #1312

Pattern

// dp[i][j] = min insertions to make s[i..j] palindromic.
// If s[i] == s[j]: dp[i][j] = dp[i+1][j-1].
// Else           : dp[i][j] = 1 + min(dp[i+1][j], dp[i][j-1]).
// Equivalently: answer = n - LPS(s).
Insight: Insertions you'd need = chars NOT in the longest palindromic subsequence — every other char needs a mirror added.
