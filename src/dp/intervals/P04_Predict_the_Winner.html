P04 — Predict the Winner

Medium • LC #486

Pattern

// Same recurrence as Stone Game: dp[i][j] = max(nums[i]-dp[i+1][j], nums[j]-dp[i][j-1]).
// Player 1 wins iff dp[0][n-1] >= 0.
Insight: Tracking the SCORE DIFFERENCE rather than two separate totals collapses the state to one number per interval.
