Binary trie problems (max XOR), bitmask DP, and classic single-pass bit tricks all share the same foundation: think of numbers as bit sequences.

Binary Trie Template

class BitTrie {
    static class N { N[] kids = new N[2]; }
    private N root = new N();
    void insert(int x) {
        N n = root;
        for (int b = 31; b >= 0; b--) {
            int bit = (x >> b) & 1;
            if (n.kids[bit] == null) n.kids[bit] = new N();
            n = n.kids[bit];
        }
    }
    int maxXor(int x) {
        N n = root; int res = 0;
        for (int b = 31; b >= 0; b--) {
            int bit = (x >> b) & 1, want = bit ^ 1;
            if (n.kids[want] != null) { res |= 1 << b; n = n.kids[want]; }
            else n = n.kids[bit];
        }
        return res;
    }
}

Common Bit Tricks

n & (n - 1)
Clears the lowest set bit. Used in popcount.
n & -n
Isolates the lowest set bit.
n ^ (n - 1)
Sets all bits below and including the lowest set bit.
XOR-with-self = 0
Cancels pairs. Foundation of Single Number / Missing Number.
1 << k
Set bit k. Used for subset enumeration and bitmask DP.
