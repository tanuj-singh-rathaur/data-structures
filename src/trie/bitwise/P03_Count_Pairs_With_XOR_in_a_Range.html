P03 — Count Pairs With XOR in [low, high]

Hard • LC #1803

Pattern

// Each trie node stores subtree count.
// countLess(x, k): count nums with (nums[i] XOR x) < k by walking bits of k.
// Answer = sum over i of [countLess(nums[i], high+1) - countLess(nums[i], low)] / 2.
Insight: Range count via two "less-than" queries — same trick as range-sum from prefix-sums.
