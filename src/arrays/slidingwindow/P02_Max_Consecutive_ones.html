P02 — Max Consecutive Ones

Easy • LeetCode #485 • Pattern: Simple Counter / Variable Window

📝 The Problem

Given a binary array nums, return the maximum number of consecutive 1s.

Example: [1, 1, 0, 1, 1, 1] → 3

📚 Jargon Buster

Binary array
An array containing only 0s and 1s.
Run / Streak
A maximal stretch of identical consecutive values. Here we want the longest run of 1s.
Counter reset
When a 0 appears, the current streak ends — restart the counter at 0 and keep going.

🌟 In Layman's Terms

Walk through the array counting how many 1s you've seen in a row. Every 0 resets the counter. Keep track of the best (longest) streak you've ever seen.

⚡ The Aha Moment

You don't need two pointers explicitly — the “left edge” of the window is implicit (it's always “just after the last 0”). A single running counter does the same job.

🔧 Algorithm

  1. Set cur = 0, best = 0.
  2. For each value: if it's 1, cur++ else cur = 0.
  3. Update best = max(best, cur) each step.

☕ Java Solution

public int findMaxConsecutiveOnes(int[] nums) {
    int cur = 0, best = 0;
    for (int x : nums) {
        cur = (x == 1) ? cur + 1 : 0;
        best = Math.max(best, cur);
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Sliding Window Pattern

Implicit Variable Window: The window is “everything since the last 0.” The left pointer is implicit — we don't need to store it because the counter encodes it.
Key Insight: When the “window” resets to length 0 on a forbidden character, you don't need an explicit left pointer — a counter is equivalent and simpler.
