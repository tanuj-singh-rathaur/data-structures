P12 — Fruit Into Baskets

Medium • LC #904 • Pattern: Longest Window with At Most 2 Distinct

📝 The Problem

Walk a row of fruit trees. You have 2 baskets, each holds one type of fruit. Starting from any tree, pick from every subsequent tree as long as the fruit type fits one of your baskets. Return the maximum number of fruits you can pick.

Translation: Length of the longest contiguous subarray containing at most 2 distinct values.

Example: [1, 2, 1, 2, 3] → 4 (the prefix [1,2,1,2])

📚 Jargon Buster

Basket = bucket
One basket per fruit type. With 2 baskets, the window can contain at most 2 distinct fruit types.
Distinct count
Number of different values currently inside the window. Track as the size of a HashMap (or a counter on a 26-slot array).
Shrink trigger
When distinct count exceeds 2, shrink L until it drops back to 2.

🌟 In Layman's Terms

This is “longest subarray with at most K=2 distinct values” in disguise. Expand the window to the right; whenever a 3rd distinct value appears, shrink from the left, dropping counts, until only 2 distinct values remain. Track the max length seen.

⚡ The Aha Moment

The fruit/basket framing hides a classic problem. Once you recognize “at most K distinct” (with K=2), the canonical sliding window template applies directly.

🔧 Algorithm

  1. Use a HashMap count.
  2. For each R: add fruits[R] to map.
  3. While count.size() > 2: decrement count[fruits[L]]; remove if 0; L++.
  4. Update best = max(best, R − L + 1).

☕ Java Solution

public int totalFruit(int[] fruits) {
    Map<Integer, Integer> count = new HashMap<>();
    int L = 0, best = 0;
    for (int R = 0; R < fruits.length; R++) {
        count.merge(fruits[R], 1, Integer::sum);
        while (count.size() > 2) {
            count.merge(fruits[L], -1, Integer::sum);
            if (count.get(fruits[L]) == 0) count.remove(fruits[L]);
            L++;
        }
        best = Math.max(best, R - L + 1);
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Sliding Window Pattern

At-Most-K Distinct: Generic template. With K=2 it's Fruit Baskets; K = arbitrary becomes P14. K=2 + the right framing also solves “Longest Substring with At Most Two Distinct Characters.”
