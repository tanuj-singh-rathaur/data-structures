P13 — Subarrays with K Different Integers

Hard • LC #992 • Pattern: exactly(K) = atMost(K) − atMost(K−1)

📝 The Problem

Count contiguous subarrays of nums with exactly K distinct integers.

Example: nums = [1, 2, 1, 2, 3], K = 2 → 7

📚 Jargon Buster

Exactly K
The subarray contains precisely K different values, no more, no less.
At-most-K (helper)
A sliding window function that counts subarrays with ≤ K distinct values. Easy with the standard template.
The exactly-K trick
exactly(K) = atMost(K) − atMost(K−1). The subarrays with at most K minus those with at most K−1 leaves only the ones with exactly K.
Why "exactly" is hard directly
You'd have to track when distinct count is < K or > K. The diff trick sidesteps this.

🌟 In Layman's Terms

Counting "exactly K distinct" subarrays directly is tricky. But counting "at most K distinct" is easy with sliding window. So: subarrays with ≤ K minus subarrays with ≤ K−1 = subarrays with exactly K.

⚡ The Aha Moment

For each R in the "at most K" sweep, the number of valid subarrays ending at R equals the current window length (R−L+1). Summing those over all R gives total subarrays with ≤ K distinct.

🔧 Algorithm

  1. Write helper atMost(nums, K): standard sliding window; accumulate R − L + 1 at each step.
  2. Return atMost(K) − atMost(K − 1).

☕ Java Solution

public int subarraysWithKDistinct(int[] nums, int K) {
    return atMost(nums, K) - atMost(nums, K - 1);
}
private int atMost(int[] nums, int K) {
    Map<Integer, Integer> count = new HashMap<>();
    int L = 0, total = 0;
    for (int R = 0; R < nums.length; R++) {
        count.merge(nums[R], 1, Integer::sum);
        while (count.size() > K) {
            count.merge(nums[L], -1, Integer::sum);
            if (count.get(nums[L]) == 0) count.remove(nums[L]);
            L++;
        }
        total += R - L + 1;
    }
    return total;
}

⏳ Complexity

Time
O(n)
Space
O(K)

📈 Sliding Window Pattern

Exactly-K Trick: A general transformation: any “exactly K” counting can become “atMost(K) − atMost(K−1).” Same idea works for Binary Subarrays With Sum (P19) and Nice Subarrays (P18).
Key Insight: “Exactly” is hard. “At most” is easy. Convert one into a subtraction of the other.
