P14 — Longest Substring with At Most K Distinct Characters

Medium • LC #340 • Pattern: Variable Window + Distinct Counter

📝 The Problem

Given a string s and integer K, return the length of the longest substring containing at most K distinct characters.

Example: s = "eceba", K = 2 → 3 ("ece")

📚 Jargon Buster

At most K distinct
The window may contain ≤ K different characters. Anything more triggers a shrink.
HashMap count
Map character → count inside the window. Map size = number of distinct chars.
Removing a key when count hits 0
Crucial. If you just decrement without removing, the map size won't shrink and the distinct count will be wrong.

🌟 In Layman's Terms

Keep a sliding window. Track which distinct chars are inside via a map. When the map has too many keys (more than K), shrink from the left, decrementing counts and removing entries that hit zero. Whenever the window is valid, update the best length.

⚡ The Aha Moment

Distinct-character count = map size. Decrement-and-remove is the precise way to keep this in sync with the actual window contents.

🔧 Algorithm

  1. Set L = 0, best = 0, count = HashMap.
  2. For each R: count[s[R]]++.
  3. While count.size() > K: decrement count[s[L]], remove if 0, L++.
  4. best = max(best, R − L + 1).

☕ Java Solution

public int lengthOfLongestSubstringKDistinct(String s, int K) {
    Map<Character, Integer> count = new HashMap<>();
    int L = 0, best = 0;
    for (int R = 0; R < s.length(); R++) {
        count.merge(s.charAt(R), 1, Integer::sum);
        while (count.size() > K) {
            char lc = s.charAt(L);
            count.merge(lc, -1, Integer::sum);
            if (count.get(lc) == 0) count.remove(lc);
            L++;
        }
        best = Math.max(best, R - L + 1);
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(K)
