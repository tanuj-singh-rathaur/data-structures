P09 — Longest Substring Without Repeating Characters

Medium • LC #3 • Pattern: Variable Window + Last-Seen Map

📝 The Problem

Given a string s, return the length of the longest substring with all distinct characters.

Example: "abcabcbb" → 3 ("abc")

📚 Jargon Buster

Substring
A contiguous slice of s. Not to be confused with subsequence (can skip).
All distinct
No character repeats inside the window.
Last-seen index map
For each character, store the most recent index we saw it at. Lets us jump L past the duplicate in O(1).
Jump vs Shrink
Instead of slowly shrinking L one step at a time, we can jump L directly to lastSeen[c] + 1 — faster, fewer iterations.

🌟 In Layman's Terms

Slide a window left-to-right. The moment R sees a character that's already inside the window, slide L past where you last saw it. The map tells you exactly where to slide L to.

⚡ The Aha Moment

L only ever needs to move forward. If a duplicate appears at index R and we last saw it at index p, the new L must be at least p+1. Take max(L, lastSeen[c]+1) to never go backwards.

📺 Visual Walkthrough

R=5char 'c' seen at 2 → L = max(2, 2+1) = 3. Window = "abc". best=3
R=6char 'b' seen at 4 → L = max(3, 4+1) = 5. Window = "cb". best=3
R=7char 'b' seen at 6 → L = 7. Window = "b". Final best=3

🔧 Algorithm

  1. Maintain lastSeen[c] (init −1), L = 0, best = 0.
  2. For each R: L = max(L, lastSeen[s[R]] + 1).
  3. Update lastSeen[s[R]] = R; best = max(best, R − L + 1).

☕ Java Solution

public int lengthOfLongestSubstring(String s) {
    int[] last = new int[128];
    java.util.Arrays.fill(last, -1);
    int L = 0, best = 0;
    for (int R = 0; R < s.length(); R++) {
        L = Math.max(L, last[s.charAt(R)] + 1);
        last[s.charAt(R)] = R;
        best = Math.max(best, R - L + 1);
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(|alphabet|)

📈 Sliding Window Pattern

Variable Window + Last-Seen Map: A jump-style window: instead of shrinking one step at a time, leap L past the duplicate's previous position.
Key Insight: The window is always “the longest stretch ending at R with no repeats.” A single map lookup tells you the minimum L that keeps that true.
