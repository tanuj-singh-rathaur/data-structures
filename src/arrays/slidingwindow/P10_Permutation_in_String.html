P10 — Permutation in String

Medium • LC #567 • Pattern: Fixed Window + Char Frequency

📝 The Problem

Given strings s1 and s2, return true if s2 contains a substring that is a permutation of s1.

Example: s1 = "ab", s2 = "eidbaooo" → true (contains "ba")

📚 Jargon Buster

Permutation
Same characters with the same counts, in any order. So “substring is a permutation of s1” = “substring's char frequencies match s1's exactly.”
Fixed-size window
Always exactly len(s1) wide. The size never changes — we just slide it.
Frequency match counter
Track how many of the 26 letter counts currently match between window and s1. When the counter equals 26, we have a permutation.

🌟 In Layman's Terms

Maintain two letter-count arrays: one for s1 (fixed) and one for the current sliding window of size len(s1) in s2. Slide one step at a time; at each step, the window's counts update incrementally. If both arrays match, it's a permutation.

⚡ The Aha Moment

Comparing the full 26-letter count arrays every slide would be O(26·n). Instead, track a counter matches — increment when a count transition makes a letter match, decrement when it breaks. Then “match check” is O(1).

🔧 Algorithm

  1. Build need[26] from s1.
  2. Slide a window of size len(s1) over s2, maintaining window[26].
  3. Maintain matches: incremented when a letter's count becomes equal to need's, decremented when it breaks.
  4. Whenever matches == 26, return true.

☕ Java Solution

public boolean checkInclusion(String s1, String s2) {
    if (s1.length() > s2.length()) return false;
    int[] need = new int[26], win = new int[26];
    for (char c : s1.toCharArray()) need[c - 'a']++;
    int matches = 0;
    for (int i = 0; i < 26; i++) if (need[i] == 0) matches++;
    int K = s1.length();
    for (int R = 0; R < s2.length(); R++) {
        int c = s2.charAt(R) - 'a';
        win[c]++;
        if (win[c] == need[c]) matches++;
        else if (win[c] == need[c] + 1) matches--;
        if (R >= K) {
            int lc = s2.charAt(R - K) - 'a';
            win[lc]--;
            if (win[lc] == need[lc]) matches++;
            else if (win[lc] == need[lc] - 1) matches--;
        }
        if (matches == 26) return true;
    }
    return false;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Sliding Window Pattern

Fixed Window + Frequency: Permutation = multiset equality. Slide a fixed window; let an O(1) match counter handle the equality check.
Key Insight: Comparing arrays in a loop is wasted work. Track only the transitions (count just became equal, count just left equal) and an integer match counter captures full equality.
