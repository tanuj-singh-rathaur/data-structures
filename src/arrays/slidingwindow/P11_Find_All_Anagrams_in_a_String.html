P11 — Find All Anagrams in a String

Medium • LC #438 • Pattern: Fixed Window + Char Frequency

📝 The Problem

Given s and p, return the starting indices of all substrings in s that are anagrams of p.

Example: s = "cbaebabacd", p = "abc" → [0, 6]

📚 Jargon Buster

Anagram
Same letters with the same counts, possibly rearranged. "abc" and "bca" are anagrams.
Anagram = permutation
This is the same problem as P10 (Permutation in String) — we just collect every match instead of stopping at the first.
Sliding fixed window
Window size = len(p). Slide one char at a time, update the window's frequency map incrementally.

🌟 In Layman's Terms

Maintain a small frequency map of the current len(p)-char window. Compare it to p's frequency map; if they match, this window is an anagram — record its left index. Slide and repeat.

⚡ The Aha Moment

You don't need to sort or recompute hashes — tracking a matches counter (incremented/decremented on count-equality transitions) gives O(1) per slide.

🔧 Algorithm

  1. Build need[26] from p.
  2. Initialize win[26], matches.
  3. Slide a window of length len(p) over s.
  4. Whenever matches == 26, push the window's start index into the result list.

☕ Java Solution

public List<Integer> findAnagrams(String s, String p) {
    List<Integer> res = new ArrayList<>();
    if (p.length() > s.length()) return res;
    int[] need = new int[26], win = new int[26];
    for (char c : p.toCharArray()) need[c - 'a']++;
    int matches = 0;
    for (int i = 0; i < 26; i++) if (need[i] == 0) matches++;
    int K = p.length();
    for (int R = 0; R < s.length(); R++) {
        int c = s.charAt(R) - 'a';
        win[c]++;
        if (win[c] == need[c]) matches++;
        else if (win[c] == need[c] + 1) matches--;
        if (R >= K) {
            int lc = s.charAt(R - K) - 'a';
            win[lc]--;
            if (win[lc] == need[lc]) matches++;
            else if (win[lc] == need[lc] - 1) matches--;
        }
        if (matches == 26) res.add(R - K + 1);
    }
    return res;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Sliding Window Pattern

Fixed Window + Frequency: Identical machinery to "Permutation in String"; just collect every anagram start instead of returning on the first hit.
Key Insight: Two strings are anagrams iff their multisets of characters are equal. Sliding-window equality of multisets becomes an O(1) check via the matches counter.
