P15 — Car Pooling

Medium • LC #1094 • Pattern: Difference Array on a Timeline

📝 The Problem

Given trips as [numPassengers, from, to] and a car capacity, return true if all trips fit without exceeding capacity at any point.

Example: trips = [[2,1,5], [3,3,7]], capacity = 4 → false

📚 Jargon Buster

Timeline as an array
Each location index is a "time" point. Use a difference array indexed by location.
Pick-up vs Drop-off
Add passengers at from; remove them at to (not to+1 — passengers leave at the destination, freeing seats for that point).
Sweep + check
Once we have the difference array, run a prefix sum; if it ever exceeds capacity, return false.

🌟 In Layman's Terms

Treat each location as a column. For each trip, +passengers at from, −passengers at to. Walk the timeline (running prefix sum). If you ever exceed capacity, the trips don't fit.

⚡ The Aha Moment

This is the difference-array technique on a timeline. The trick is recognizing that “at the destination, passengers leave before any new trip starts.” That's why we subtract at to, not to+1.

🔧 Algorithm

  1. Allocate diff[1001] (max location).
  2. For each [n, from, to]: diff[from] += n; diff[to] −= n.
  3. Walk; running sum; if > capacity, return false.

☕ Java Solution

public boolean carPooling(int[][] trips, int capacity) {
    int[] diff = new int[1001];
    for (int[] t : trips) {
        diff[t[1]] += t[0];
        diff[t[2]] -= t[0];
    }
    int load = 0;
    for (int x : diff) {
        load += x;
        if (load > capacity) return false;
    }
    return true;
}

⏳ Complexity

Time
O(T + maxLoc)
Space
O(maxLoc)

📈 Prefix Sum Pattern

Difference Array on Timeline: Identical mechanics to flight bookings, but on a location axis. Watch the inclusive/exclusive endpoint — the right endpoint here is exclusive.
Key Insight: Whether to subtract at to or to+1 depends on the problem: does the event end at that index or just before? Misreading this is the most common bug.
