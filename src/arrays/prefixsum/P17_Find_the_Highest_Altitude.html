P17 — Find the Highest Altitude

Easy • LC #1732 • Pattern: Running Sum + Max

📝 The Problem

You start at altitude 0. You're given gain[i] = altitude change from point i to i+1. Return the highest altitude reached.

Example: gain = [−5, 1, 5, 0, −7] → 1

📚 Jargon Buster

Altitude = running sum
Each altitude[i+1] = altitude[i] + gain[i]. The altitude sequence is the prefix sum of gain.
Track max along the way
No need for a separate array — one scalar tracks the running max.

🌟 In Layman's Terms

The altitude is just the running total of the gains. Walk along, keep adding, remember the highest you've reached.

⚡ The Aha Moment

It's prefix sum P01 (Running Sum 1D) with a max tracker. Don't build the prefix array — just compare on the fly.

🔧 Algorithm

  1. Set alt = 0, best = 0 (the starting altitude).
  2. For each g in gain: alt += g; best = max(best, alt).
  3. Return best.

☕ Java Solution

public int largestAltitude(int[] gain) {
    int alt = 0, best = 0;
    for (int g : gain) {
        alt += g;
        best = Math.max(best, alt);
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Prefix Sum Pattern

Running Sum + Max: When the answer is a function of the running prefix, just track it inline — no array needed.
Key Insight: Don't allocate a prefix array if you only need a single derived quantity. One scalar plus a running max is enough.
