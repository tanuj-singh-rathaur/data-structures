P02 — Find Pivot Index

Easy • LeetCode #724 • Pattern: Pivot / Balance

📝 The Problem

Find the leftmost index where the sum of values to its left equals the sum to its right. If none exists, return −1. The pivot itself is excluded from both sides.

Example: [1, 7, 3, 6, 5, 6] → index 3 (left=1+7+3=11, right=5+6=11)

📚 Jargon Buster

Pivot
The index that “balances” the array. Everything to the left and everything to the right add up to the same number.
Left sum / Right sum
The sum of all elements before the index (left) or after the index (right). The pivot value itself is not counted.
Total sum
Sum of every element. Stays fixed during the scan — we use it to compute the right sum without a second loop: right = total − left − nums[i].

🌟 In Layman's Terms

Imagine a see-saw with weights on it. The pivot is the spot where, if you removed that one weight, the two sides would weigh the same. You don't need to weigh both sides separately each time — you know the total weight, so once you know the left side, the right side is just total − left − current.

⚡ The Aha Moment

You can avoid a second pass by reusing the total. Track leftSum as you scan; the right sum at index i is always total − leftSum − nums[i].

🔧 Algorithm

  1. Compute total = sum of all elements.
  2. Start leftSum = 0.
  3. For each index i: if leftSum == total − leftSum − nums[i], return i.
  4. Otherwise add nums[i] to leftSum and continue.
  5. Return −1 if no pivot found.

☕ Java Solution

public int pivotIndex(int[] nums) {
    int total = 0;
    for (int x : nums) total += x;
    int leftSum = 0;
    for (int i = 0; i < nums.length; i++) {
        if (leftSum == total - leftSum - nums[i]) return i;
        leftSum += nums[i];
    }
    return -1;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Prefix Sum Pattern

Pivot / Balance: A single forward sweep with running leftSum; rightSum derived from the constant total. No explicit prefix array needed because we only ever look at one value at a time.
Key Insight: Keeping the total constant turns a two-sided question into a one-pass one. You only have to track what you've seen so far.
