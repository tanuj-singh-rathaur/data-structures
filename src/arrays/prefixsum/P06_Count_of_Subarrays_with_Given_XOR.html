P06 — Count Subarrays with XOR = K

Medium • InterviewBit / LC #1442 family • Pattern: HashMap of Prefix XORs

📝 The Problem

Count subarrays whose XOR (cumulative xor of all elements) equals K.

Example: nums = [4, 2, 2, 6, 4], K = 6 → 4 (subarrays [4,2], [4,2,2,6,4], [2,2,6,4], [6])

📚 Jargon Buster

XOR (^)
Bitwise “exclusive or.” For each bit position, output 1 if the bits differ, 0 if they match. Example: 5 ^ 3 = 0101 ^ 0011 = 0110 = 6.
XOR is self-inverse
a ^ a = 0. That's the magic property: XORing the same value twice cancels it. Same role “subtraction” plays in normal prefix sums.
XOR is associative & commutative
You can XOR a range of values in any order and group them as you like. That's why “prefix XOR” even works.
Prefix XOR
The cumulative XOR from index 0 up to i. Same idea as prefix sum but with ^.
Range XOR identity
xor(nums[l..r]) = prefix[r+1] ^ prefix[l]. So to get xor=K we want a past prefix equal to current ^ K.

🌟 In Layman's Terms

This is the same trick as “subarray sum equals K” but with XOR instead of addition. Because XOR cancels itself, the “range XOR” between two prefixes is just prefix_left ^ prefix_right. You keep a hashmap of every prefix XOR you've seen, and at each step look up current ^ K.

⚡ The Aha Moment

If cumXor[r+1] ^ cumXor[l] = K, then cumXor[l] = cumXor[r+1] ^ K. So at each position, just count how many earlier prefixes equal current ^ K — each is a valid subarray.

🔧 Algorithm

  1. Initialize map = {0: 1} and xorPrefix = 0, count = 0.
  2. For each x: xorPrefix ^= x; lookup xorPrefix ^ K in the map; count += map.getOrDefault(...).
  3. Increment map[xorPrefix].
  4. Return count.

☕ Java Solution

public int subarraysWithXor(int[] nums, int K) {
    Map<Integer, Integer> seen = new HashMap<>();
    seen.put(0, 1);
    int xorPrefix = 0, count = 0;
    for (int x : nums) {
        xorPrefix ^= x;
        count += seen.getOrDefault(xorPrefix ^ K, 0);
        seen.merge(xorPrefix, 1, Integer::sum);
    }
    return count;
}

📈 Prefix Sum Pattern

HashMap of Prefix XORs: Same skeleton as “Subarray Sum Equals K” — swap addition with XOR and subtraction with XOR (since XOR is its own inverse). The exact same loop structure works.
Key Insight: XOR behaves like addition over GF(2) — meaning it's associative, commutative, and self-inverse. Any algorithm that uses “prefix sum + subtract” works for XOR by swapping + with ^ and − with ^.
