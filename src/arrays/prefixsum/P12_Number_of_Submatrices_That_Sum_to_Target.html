P12 — Number of Submatrices That Sum to Target

Hard • LC #1074 • Pattern: Compress Rows → 1D HashMap

📝 The Problem

Count submatrices whose sum equals target.

Example: matrix = [[0,1,0],[1,1,1],[0,1,0]], target = 0 → 4

📚 Jargon Buster

Row compression
Fix two rows r1, r2. For each column, sum all values in rows r1..r2 to get a single 1D array. Now every submatrix between those two rows corresponds to a 1D subarray.
Reduce to P04
Once you have the 1D compressed row, count subarrays with sum = target using the HashMap-of-prefix-sums technique (Subarray Sum Equals K).
Three nested loops total
Two for the row pair (r1, r2), one for the 1D scan. O(m² · n).

🌟 In Layman's Terms

Fix a top and bottom row. Now you only care about columns. Collapse rows r1..r2 into one 1D array (column sums). On that array, count 1D subarrays summing to target with the standard HashMap trick. Repeat for every pair of rows.

⚡ The Aha Moment

2D “submatrices = target” becomes O(m²) executions of 1D “subarrays = target.” Reuse what you already know.

🔧 Algorithm

  1. Build row prefix sums per column to allow fast row collapse.
  2. For each pair (r1, r2): compute the 1D column-sum array.
  3. Apply the “Subarray Sum Equals K” counter to it.
  4. Sum results across all pairs.

☕ Java Solution

public int numSubmatrixSumTarget(int[][] matrix, int target) {
    int m = matrix.length, n = matrix[0].length;
    // Row prefix sums
    for (int i = 0; i < m; i++)
        for (int j = 1; j < n; j++)
            matrix[i][j] += matrix[i][j - 1];
    int total = 0;
    for (int c1 = 0; c1 < n; c1++) {
        for (int c2 = c1; c2 < n; c2++) {
            Map<Integer, Integer> seen = new HashMap<>();
            seen.put(0, 1);
            int prefix = 0;
            for (int i = 0; i < m; i++) {
                prefix += matrix[i][c2] - (c1 > 0 ? matrix[i][c1 - 1] : 0);
                total += seen.getOrDefault(prefix - target, 0);
                seen.merge(prefix, 1, Integer::sum);
            }
        }
    }
    return total;
}

⏳ Complexity

Time
O(m·n²) or O(m²·n)
Space
O(m or n)

📈 Prefix Sum Pattern

Row Compression + 1D HashMap: The canonical 2D → 1D reduction. Any 1D subarray algorithm can be lifted to 2D this way.
Key Insight: Don't reinvent the 2D problem. Pick the dimension with the smaller bound to iterate pairs on; collapse along it; reuse the 1D subarray-sum-equals-K algorithm.
