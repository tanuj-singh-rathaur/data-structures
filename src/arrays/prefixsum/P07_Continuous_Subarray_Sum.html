P07 — Continuous Subarray Sum

Medium • LC #523 • Pattern: Prefix Sum mod K + HashMap

📝 The Problem

Return true if nums has a continuous subarray of length ≥ 2 whose sum is a multiple of K.

Example: nums = [23, 2, 4, 6, 7], K = 6 → true (subarray [2, 4] sums to 6)

📚 Jargon Buster

Multiple of K
Sum divides by K with no remainder. Equivalently: sum mod K == 0.
Prefix mod K
The remainder when running prefix sum is divided by K.
Same remainder ⇒ divisible sub
If prefix[i] mod K == prefix[j] mod K, then the subarray (i, j] has sum divisible by K.
Length ≥ 2 constraint
Store the first index we saw each remainder. The subarray length must be at least 2, so require j − i ≥ 2.

🌟 In Layman's Terms

Walk the array tracking the running sum mod K. If you see the same remainder twice, the chunk between the two indices has sum divisible by K. Need the two indices to be ≥ 2 apart for the “length ≥ 2” rule.

⚡ The Aha Moment

You never need the actual prefix sums — just their remainders mod K. Store the earliest index for each remainder so any future match gives the longest possible interval.

🔧 Algorithm

  1. Map remainder → first index. Seed {0: −1} for empty prefix.
  2. For each i: r = prefix mod K. If r is in map and i − map[r] ≥ 2, return true.
  3. Otherwise, if r is new, store map[r] = i.

☕ Java Solution

public boolean checkSubarraySum(int[] nums, int K) {
    Map<Integer, Integer> first = new HashMap<>();
    first.put(0, -1);
    int prefix = 0;
    for (int i = 0; i < nums.length; i++) {
        prefix = (prefix + nums[i]) % K;
        if (first.containsKey(prefix)) {
            if (i - first.get(prefix) >= 2) return true;
        } else {
            first.put(prefix, i);
        }
    }
    return false;
}

⏳ Complexity

Time
O(n)
Space
O(K)

📈 Prefix Sum Pattern

Prefix mod K + HashMap: When divisibility is involved, store the prefix's remainder, not its full value. Two equal remainders bracket a divisible subarray.
Key Insight: Store the first index per remainder — never overwrite. That guarantees the longest possible subarray, which makes the length constraint easiest to satisfy.
