P12 — Jump Game II

Medium • LC #45 • Pattern: Layered BFS / Greedy Farthest

📝 The Problem

Same as Jump Game, but return the minimum number of jumps to reach the last index. Assume reachable.

Example: [2, 3, 1, 1, 4] → 2 (jump 1 to index 1, then 3 to end)

📚 Jargon Buster

Layered BFS view
Treat indices reachable in k jumps as “layer k.” The next layer is everything reachable from the current layer.
currentEnd
The right edge of the current layer — the furthest position reachable in the current number of jumps.
farthest
The furthest position reachable in one more jump from anywhere in the current layer.
Bump jumps when i reaches currentEnd
When you've consumed all of the current layer, the next jump count becomes "now you'd be in layer+1." Set currentEnd = farthest.

🌟 In Layman's Terms

Imagine BFS in disguise: every jump is a layer. Walk left-to-right. Track how far you could reach with one more jump (farthest). When you cross the current layer's boundary (currentEnd), you've used a jump — bump the count and set the new boundary.

⚡ The Aha Moment

You don't need actual BFS — just track the layer's right boundary and the best reach you've discovered for the next layer. Each time you cross the boundary, increment the jump count.

🔧 Algorithm

  1. Set jumps = 0, currentEnd = 0, farthest = 0.
  2. For i = 0..n−2: update farthest = max(farthest, i + nums[i]).
  3. If i == currentEnd: jumps++; currentEnd = farthest.
  4. Return jumps.

☕ Java Solution

public int jump(int[] nums) {
    int jumps = 0, currentEnd = 0, farthest = 0;
    for (int i = 0; i < nums.length - 1; i++) {
        farthest = Math.max(farthest, i + nums[i]);
        if (i == currentEnd) {
            jumps++;
            currentEnd = farthest;
        }
    }
    return jumps;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Kadane Pattern

Layered Greedy: A BFS in scalars — only two pointers (current boundary, next boundary). No queue, no visited set.
Key Insight: The layer boundary is where the “jump count” ticks. You don't have to commit to a specific position for the current jump — you greedily prepare the farthest reach available for the next layer.
