P20 — Substring with Largest Variance

Hard • LC #2272 • Pattern: Kadane on +1/−1 per Character Pair

📝 The Problem

Variance of a string = max char-count minus min char-count (over distinct characters in it). Return the maximum variance over all substrings of s.

Example: s = "aababbb" → 3 (substring "babbb": 4 b's, 1 a → 4−1=3)

📚 Jargon Buster

Per-pair Kadane
For each ordered pair (a, b) of distinct characters present in s: treat a as +1 and b as −1; run Kadane to find the largest "positive minus negative" stretch where a dominates.
"At least one b" constraint
Variance requires both chars to appear. So during the Kadane, only credit the running sum when a b has been used in this window.
hasMinor flag
A boolean: have we seen at least one b in the current run? Without one, we can't claim variance.
Discarded b carry
When the running sum would restart, but a b just caused the drop, that b is “saved” in a special variable so the next reset begins with hasMinor = true.

🌟 In Layman's Terms

For each pair of distinct letters (a, b), pretend the string is just +1s, −1s and ignored. Run Kadane to find the longest stretch where +1s exceed −1s — that's the (count_a − count_b) we could achieve. Repeat over all 26×25 pairs.

⚡ The Aha Moment

Variance always involves a "winning" character and a "losing" character. Fix them, reduce to Kadane on +1/−1. The only subtlety is requiring at least one of the losing letter so variance isn't bogus.

🔧 Algorithm

  1. Collect set of distinct chars in s.
  2. For each ordered (major, minor) pair:
    • Walk s; for major +1, for minor −1, ignore others.
    • Track running sum; reset when sum < 0, but if a minor was discarded, carry one minor forward so future runs still have a minor.
    • If hasMinor, update global best with current sum.

☕ Java Solution

public int largestVariance(String s) {
    Set<Character> chars = new HashSet<>();
    for (char c : s.toCharArray()) chars.add(c);
    int best = 0;
    for (char a : chars) {
        for (char b : chars) {
            if (a == b) continue;
            int cur = 0; boolean hasB = false; boolean discardedB = false;
            for (char c : s.toCharArray()) {
                if (c == a) cur++;
                else if (c == b) { cur--; hasB = true; }
                if (cur < 0) {
                    discardedB = true;
                    cur = 0;
                    hasB = false;
                }
                if (hasB) best = Math.max(best, cur);
                else if (discardedB && cur > 0) best = Math.max(best, cur - 1);
            }
        }
    }
    return best;
}

⏳ Complexity

Time
O(26·26·n)
Space
O(1)

📈 Kadane Pattern

Per-Pair Kadane with State Flag: Reduce a multi-character objective to many +1/−1 sub-problems. Each is vanilla Kadane with one extra boolean ("have I seen a minor").
Key Insight: Variance is asymmetric — you need at least one of the “losing” character to even count. The discardedB carry is the careful bookkeeping that lets Kadane restart without losing track of that requirement.
