💡 What Is Kadane? (Layman's Explanation)

Imagine you're walking along a coastline at sunrise, and the height of the cliff goes up and down. You want the biggest stretch where the cumulative cliff height stayed highest.

Kadane's trick is brutally simple: at every step ask one question:

“Does the running total so far help me — or is it dragging me down? If it's negative, abandon it and restart from here.”

That's the entire algorithm. One pass, O(n). You're not searching all subarrays — you're letting the “current run” auto-reset whenever it goes underwater.

📚 Jargon Buster (Confusing Terms Explained)

Maximum subarray
The contiguous slice of the array with the highest sum. “Subarray” means contiguous — you can't skip elements.
Local max (curMax)
The best sum of any subarray ending at the current index. Recomputed each step.
Global max (best)
The overall winner so far — the maximum of all curMax values we've ever seen.
Reset
When curMax goes negative, restart it at the current element. The previous run is “abandoned” because keeping it can only hurt future sums.
Extend vs Restart
At each step Kadane picks: “extend the current subarray by including nums[i]” OR “start a brand new subarray at nums[i].” Choose whichever gives the larger curMax.
Dynamic programming (1D)
Kadane is DP in disguise — the recurrence is dp[i] = max(nums[i], dp[i−1] + nums[i]). We just don't bother with an array; a single variable suffices.
Circular subarray
A subarray that may “wrap around” the end of the array back to the front. P03 uses a clever inversion trick to handle this.
Negative-product flip (Product variant)
For products, a negative times a negative is positive — so the smallest negative running product can suddenly become the largest. P04 keeps both min and max trails.

🔎 When Should You Use Kadane?

  • Find maximum (or minimum) sum / product over all contiguous subarrays.
  • Brute force is O(n²) or O(n³) and you want O(n).
  • The metric you're maximizing has the property: extending a run depends only on the previous run's value.
  • Variants: max absolute sum, longest alternating, with one deletion allowed, etc.

📈 The 4 Types of Kadane Variants — Full Breakdown

① Vanilla Kadane (Max Subarray Sum)

What it is: Walk the array once. At each index, decide: extend the previous run, or restart from here. Track the best result seen.

Recognize it when:

  • “Max sum contiguous subarray”
  • Mix of positives and negatives
  • You want O(n) time and O(1) space

The decision rule:

  • cur = max(nums[i], cur + nums[i])
  • best = max(best, cur)
Worked Example: [−2, 1, −3, 4, −1, 2, 1, −5, 4]
Track cur (running) and best (global)
i=0
cur = max(−2, 0+(−2)) = −2
best = −2
i=1
cur = max(1, −2+1) = max(1, −1) = 1  ← RESTART
best = 1
i=2
cur = max(−3, 1+(−3)) = max(−3, −2) = −2
best = 1
i=3
cur = max(4, −2+4) = max(4, 2) = 4  ← RESTART
best = 4
i=4..6
cur grows: 4−1=3, 3+2=5, 5+1=6
best = 6  (from [4,−1,2,1])
i=7
cur = max(−5, 6−5) = 1
best = 6
i=8
cur = max(4, 1+4) = 5
best = 6 Answer: 6
Code Template: 
int cur = nums[0], best = nums[0];
for (int i = 1; i < n; i++) {
    cur = Math.max(nums[i], cur + nums[i]);
    best = Math.max(best, cur);
}
P01 Maximum Subarray
② Kadane on Differences (Buy/Sell Profit)

What it is: If we reframe the problem as “sum of daily price changes,” finding max profit is exactly Kadane on the difference array. In practice we don't even build the difference array — we track the lowest price seen so far.

Recognize it when:

  • “Max profit from one buy and one sell”
  • Any “max gain between two points where you can choose the start” pattern

The decision rule:

  • Track the minimum price seen so far
  • profit at day i = price[i] − minSoFar
  • Best profit = max over all days
Worked Example: prices = [7, 1, 5, 3, 6, 4]
minSoFar starts at +∞
i=0
price=7. minSoFar=7. profit=0.
best=0
i=1
price=1. minSoFar=1. profit=0.
best=0
i=2
price=5. minSoFar=1. profit=5−1=4.
best=4
i=3
price=3. minSoFar=1. profit=2.
best=4
i=4
price=6. minSoFar=1. profit=5.
best=5 ✓
i=5
price=4. profit=3.
best=5 Answer: 5 (buy at 1, sell at 6)
Code Template: 
int minPrice = Integer.MAX_VALUE, best = 0;
for (int p : prices) {
    minPrice = Math.min(minPrice, p);
    best = Math.max(best, p - minPrice);
}
P02 Best Time to Buy and Sell Stock
③ Circular Kadane (Wrap-Around)

What it is: The subarray may wrap around the end of the array. Two cases: (a) best subarray is entirely inside — vanilla Kadane handles it. (b) Best wraps around — equivalent to total − (minimum subarray). Take the max of the two.

Recognize it when:

  • The problem mentions a “circular” or “wrap-around” array

The decision rule:

  • Run Kadane for max sum → maxSum
  • Run Kadane for min sum → minSum
  • Total = sum of all
  • If all numbers negative, answer = maxSum (don't pick empty)
  • Otherwise answer = max(maxSum, total − minSum)
Worked Example: [5, −3, 5]
total = 7
Max
Kadane(max) = 7  (the whole array)
straight case: 7
Min
Kadane(min) = −3  (just [−3])
total − minSum = 7 − (−3) = 10 But 10 corresponds to picking [5, 5] (wrap)
Answer
max(7, 10) = 10
[5, _, 5] wrapping the array
Code Template: 
int maxSum = nums[0], curMax = nums[0];
int minSum = nums[0], curMin = nums[0];
int total = nums[0];
for (int i = 1; i < n; i++) {
    curMax = Math.max(nums[i], curMax + nums[i]);  maxSum = Math.max(maxSum, curMax);
    curMin = Math.min(nums[i], curMin + nums[i]);  minSum = Math.min(minSum, curMin);
    total += nums[i];
}
return maxSum < 0 ? maxSum : Math.max(maxSum, total - minSum);
P03 Max Sum Circular Subarray
④ Two-State Kadane (Product, One-Deletion)

What it is: When the metric isn't simply additive, one running variable isn't enough. You need two states updated together at each index.

Recognize it when:

  • Product of subarray (negatives make “min” matter too)
  • “Allowed to skip one element” (two DP rows: with/without skip)

The decision rule (product version):

  • Track both curMax and curMin (smallest negative might flip to biggest)
  • At each step, recompute both using all three candidates: nums[i], curMax·nums[i], curMin·nums[i]
  • Update best = max(best, curMax)
Worked Example: Max Product Subarray — [2, 3, −2, 4]
curMax and curMin both move forward
i=0
curMax=2, curMin=2
best=2
i=1
candidates of 3 × {2, 2, 1 nums[i]itself}: 3, 6, 6 curMax=6, curMin=3
best=6
i=2
nums[i]=−2. Candidates: −2, 6·(−2)=−12, 3·(−2)=−6 curMax = max(−2, −12, −6) = −2 curMin = min(−2, −12, −6) = −12
best=6 still
i=3
nums[i]=4. Candidates: 4, −2·4=−8, −12·4=−48 curMax = 4, curMin = −48
best=6 final Answer: 6 (from [2,3])
Code Template (Max Product): 
int curMax = nums[0], curMin = nums[0], best = nums[0];
for (int i = 1; i < n; i++) {
    int a = nums[i], b = curMax * nums[i], c = curMin * nums[i];
    curMax = Math.max(a, Math.max(b, c));
    curMin = Math.min(a, Math.min(b, c));
    best = Math.max(best, curMax);
}
