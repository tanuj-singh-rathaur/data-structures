P06 — Best Time to Buy and Sell Stock II

Medium • LC #122 • Pattern: Sum Positive Differences

📝 The Problem

Same setup as P02 but you may buy and sell multiple times (can't hold more than one share at a time). Return the max profit.

Example: prices = [7, 1, 5, 3, 6, 4] → 7 (buy 1, sell 5, buy 3, sell 6)

📚 Jargon Buster

Multiple transactions
Buy and sell any number of times (one position at a time). You can buy and sell on the same day.
Daily-difference greedy
Total profit = sum of all positive daily differences. Every upward move is captured by an implicit buy-yesterday/sell-today.
Why this works
Any longer-range up-move equals the sum of its daily up-moves. Down-moves are skipped (we'd be on the sidelines).

🌟 In Layman's Terms

Every day, ask: is today's price higher than yesterday's? If yes, pocket the difference. Sum the answers. That's the maximum profit possible.

⚡ The Aha Moment

Profit from a long up-stretch = sum of all daily up-steps in that stretch. So you don't need to find peaks and valleys — just sum all positive daily diffs.

🔧 Algorithm

  1. For i = 1..n−1: add max(0, prices[i] − prices[i−1]) to profit.

☕ Java Solution

public int maxProfit(int[] prices) {
    int profit = 0;
    for (int i = 1; i < prices.length; i++) {
        if (prices[i] > prices[i - 1]) profit += prices[i] - prices[i - 1];
    }
    return profit;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Kadane Pattern

Greedy on Diffs: Equivalent to running Kadane on the diff array but keeping every positive piece, not just one contiguous run.
Key Insight: Multiple transactions allow us to capture every up-step. The granular daily view is identical to picking peaks and valleys at higher zoom.
