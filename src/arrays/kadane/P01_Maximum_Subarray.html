P01 — Maximum Subarray

Easy • LeetCode #53 • Pattern: Vanilla Kadane

📝 The Problem

Given an integer array nums, find the contiguous subarray with the largest sum and return that sum.

Example: [−2, 1, −3, 4, −1, 2, 1, −5, 4] → 6 (from [4, −1, 2, 1])

📚 Jargon Buster

Contiguous
Elements right next to each other — no skipping. A subarray is a slice.
cur (current run)
Best sum of any subarray ending at the current index. Updated each step.
best (global)
Maximum value cur has ever taken throughout the walk.
Restart vs extend
If extending the previous run makes the sum smaller than just nums[i] alone, restart from nums[i]. That's the heart of Kadane.

🌟 In Layman's Terms

Walk along, keeping a running total. The moment the running total goes negative, it's only dragging you down — throw it away and start fresh from the next element. Along the way, remember the highest running total you ever hit.

⚡ The Aha Moment

The best subarray ending at index i is either (a) just nums[i] alone, or (b) the best subarray ending at i−1 extended by nums[i]. That's a two-option DP that needs only one variable to track.

🔧 Algorithm

  1. Set cur = nums[0] and best = nums[0].
  2. For each i from 1: cur = max(nums[i], cur + nums[i]).
  3. best = max(best, cur).
  4. Return best.

☕ Java Solution

public int maxSubArray(int[] nums) {
    int cur = nums[0], best = nums[0];
    for (int i = 1; i < nums.length; i++) {
        cur = Math.max(nums[i], cur + nums[i]);
        best = Math.max(best, cur);
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Kadane Pattern

Vanilla Kadane: The textbook formulation. One scalar tracks the best run ending here; another tracks the global best. The decision at each step is a single max.
Key Insight: A negative running sum is poison — any future subarray that includes it would be better off starting fresh. The restart is automatic via max(nums[i], cur + nums[i]).
