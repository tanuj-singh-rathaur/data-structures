P03 — Maximum Sum Circular Subarray

Medium • LeetCode #918 • Pattern: Circular Kadane (Total − Min)

📝 The Problem

Given a circular integer array nums (the last element connects back to the first), find the maximum possible sum of a non-empty subarray. The subarray may wrap around the boundary.

Example: [5, −3, 5] → 10 (from [5, _, 5] wrapping the −3)

📚 Jargon Buster

Circular array
The array is conceptually a ring — nums[n−1] is adjacent to nums[0]. A “wrap-around” subarray includes both ends and skips the middle.
Straight (non-wrap) subarray
A normal contiguous slice that doesn't cross the boundary. Standard Kadane finds the max of these.
Wrap-around subarray
A subarray that starts somewhere in the array, wraps past the end, and ends somewhere near the beginning. Equivalent to “total of all elements minus a middle subarray.”
min-subarray-sum
The smallest possible sum of any contiguous subarray. Subtract it from the total and you get the largest wrap-around sum.
All-negative edge case
If every element is negative, total − minSum would correspond to picking nothing — not allowed. In that case the answer is just maxSubarraySum.

🌟 In Layman's Terms

Two scenarios. Either the best slice fits inside the array without wrapping (normal Kadane), or it wraps — in which case the unselected middle is itself a contiguous slice. So “best wrapping” = “everything” − “worst middle slice.” Run Kadane twice (once for max, once for min) and take the better of the two cases.

⚡ The Aha Moment

The wrap-around case is the complement of a non-wrap subarray. Total minus the smallest contiguous subarray gives the largest wrap-around. Two Kadanes solve it.

📺 Visual Walkthrough

nums = [5, −3, 5], total = 7
Max Kadane
cur sequence: 5, max(−3, 5−3)=2, max(5, 2+5)=7 best = 7
straight answer = 7 (the whole array)
Min Kadane
cur sequence: 5, min(−3, 5−3)=−3, min(5, −3+5)=2 best (smallest) = −3
min subarray sum = −3
Wrap
total − minSum = 7 − (−3) = 10
Corresponds to wrap [5, _, 5]
Compare
max(7, 10) = 10
Answer: 10

🔧 Algorithm

  1. Run Kadane twice in one loop: track curMax, maxSum and curMin, minSum.
  2. Track total = sum of all.
  3. If maxSum < 0 (all negative), return maxSum.
  4. Otherwise return max(maxSum, total − minSum).

☕ Java Solution

public int maxSubarraySumCircular(int[] nums) {
    int curMax = nums[0], maxSum = nums[0];
    int curMin = nums[0], minSum = nums[0];
    int total = nums[0];
    for (int i = 1; i < nums.length; i++) {
        curMax = Math.max(nums[i], curMax + nums[i]);
        maxSum = Math.max(maxSum, curMax);
        curMin = Math.min(nums[i], curMin + nums[i]);
        minSum = Math.min(minSum, curMin);
        total += nums[i];
    }
    return maxSum < 0 ? maxSum : Math.max(maxSum, total - minSum);
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Kadane Pattern

Circular Kadane: Reduce a circular question to two linear ones. Min and max subarrays computed in the same pass; wrap case derived by complement.
Key Insight: A wrap-around subarray's complement is itself a non-wrapping subarray. That self-similarity is what lets us solve a ring with a straight-line algorithm — just run it twice.
