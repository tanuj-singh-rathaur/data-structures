P19 — Shortest Unsorted Continuous Subarray

Medium  •  LeetCode #581  •  Pattern: Opposite Ends

📝 The Problem

Given an integer array nums, find the length of the shortest subarray that, if sorted, makes the whole array sorted.

Example: [2,6,4,8,10,9,15] → 5 (sort [6,4,8,10,9] → entire array sorted)

🌟 In Layman's Terms

Picture the array as a line of people ordered by height (shortest to tallest). If the line is almost sorted, some people are standing in the wrong spot. We need to find the leftmost misplaced person and the rightmost misplaced person — everyone between them (inclusive) is our answer.

How do we spot a misplaced person walking left-to-right? Keep track of the tallest person you've seen so far (maxSoFar). If the next person is shorter than someone already behind them, they're out of place — because in a sorted line, each person should be at least as tall as everyone before them. The last such person you see marks the right edge of the broken region.

Now walk right-to-left with the same idea, flipped. Keep track of the shortest person you've seen so far (minSoFar). If the next person (going left) is taller than someone ahead of them, they're out of place. The last such person (i.e., the leftmost) marks the left edge.

Answer = right − left + 1.

⚡ The Aha Moment

The two "running" values (maxSoFar going forward, minSoFar going backward) act like the answer to "what value should be at this position if the array were sorted?" — from each side. Any element that contradicts that expected value is misplaced. The outermost contradictions on each side bound the "broken" region we need to sort.

🔧 Algorithm (Step by Step)

  1. Scan left→right with maxSoFar; update right boundary whenever nums[i] < maxSoFar.
  2. Scan right→left with minSoFar; update left boundary whenever nums[i] > minSoFar.
  3. Return right - left + 1 (initialize right=-2, left=-1 so if already sorted, result = 0).

☕ Java Solution

public int findUnsortedSubarray(int[] nums) {
    int n = nums.length;
    int left = -1, right = -2;          // -2 so right-left+1 = 0 if sorted
    int maxSoFar = nums[0], minSoFar = nums[n-1];
    for (int i = 1; i < n; i++) {
        maxSoFar = Math.max(maxSoFar, nums[i]);
        if (nums[i] < maxSoFar) right = i;
    }
    for (int i = n-2; i >= 0; i--) {
        minSoFar = Math.min(minSoFar, nums[i]);
        if (nums[i] > minSoFar) left = i;
    }
    return right - left + 1;
}

📈 Two Pointer Pattern

Two Pointer Pattern: Two independent linear scans (forward and backward) that together define the 'broken' region. Each scan mimics one of the two pointers doing their own job independently.
Key Insight: Initialize right=-2 so right-left+1=0 handles the already-sorted edge case elegantly.
