P16 — Is Subsequence

Easy  •  LeetCode #392  •  Pattern: Same Direction

📝 The Problem

Given strings s and t, return true if s is a subsequence of t (characters of s appear in t in order, not necessarily contiguously).

Example: s="ace", t="abcde" → true

🌟 In Layman's Terms

Use one finger on s and one on t. Walk the t finger forward one character at a time. Whenever the t character matches the s finger's character, advance the s finger too. If s's finger reaches the end, all characters were found in order → true.

⚡ The Aha Moment

Same-direction two-pointer on two different arrays: i scans s, j scans t. i only advances on a match.

[a c ei]

s[i]='c' == t[j]='c' → MATCH! i++. j++. (s[i]='e', t[j]='d' → no match, j++)
Done
[a b c d ej]
s[i]='e' == t[j]='e' → MATCH! i=3 == s.length() → return true

🔧 Algorithm (Step by Step)

  1. Set i=0 (pointer into s), j=0 (pointer into t).
  2. While i < s.length() and j < t.length(): if characters match, i++. Always j++.
  3. Return i == s.length() (all of s was matched).

☕ Java Solution

public boolean isSubsequence(String s, String t) {
    int i = 0, j = 0;
    while (i < s.length() && j < t.length()) {
        if (s.charAt(i) == t.charAt(j)) i++;
        j++;
    }
    return i == s.length();
}

⏳ Complexity

Time
O(n) where n=t.length()
Space
O(1)

📈 Two Pointer Pattern

Two Pointer Pattern: Same-direction two-pointer across two strings. i is the 'match tracker', j is the 'scanner'. This is arguably the simplest possible two-pointer problem.
Key Insight: j always advances; i only advances on a match. Done when i reaches end of s.
