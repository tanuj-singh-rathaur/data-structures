💡 What Are Lower & Upper Bound? (Layman's Explanation)

Imagine a sorted list of phone numbers. A “lower bound” question asks: where would I insert this number to keep the list sorted? An “upper bound” question asks: where does the next bigger number begin?

These two boundary searches are the swiss army knife of binary search. They let you count occurrences, find nearest elements, answer "k-th smallest" questions, run patience-sort LIS, and bridge DP transitions — all in O(log n).

📚 Jargon Buster (Confusing Terms Explained)

Lower bound (LB)
Smallest index i with arr[i] ≥ target. If everything is smaller, LB = n.
Upper bound (UB)
Smallest index i with arr[i] > target. If everything is ≤, UB = n.
Count of equal values
UB(t) − LB(t) = number of times t appears in a sorted array. One identity, two boundary calls.
"First occurrence" / "last occurrence"
First = LB(t); last = UB(t) − 1.
Binary search on the answer
Sometimes the array is implicit. You binary search a candidate value v and ask "how many things ≤ v?" That count is monotonic in v → lower / upper bound applies.
Patience sort
The classic O(n log n) LIS trick: keep a sorted "tails" array. For each new number, lower-bound it in tails — replace if found, append if not. The length of tails is the LIS length.
Half-open vs closed
Lower / upper bound is cleanest with half-open: L = 0, R = n, loop while L < R. Answer = L.
Floor / ceil
Floor = last index with value ≤ target = UB − 1. Ceil = first index with value ≥ target = LB.
Java equivalents
Arrays.binarySearch returns insertion point when not found (= LB). Easy substitute for primitive arrays; use Collections.binarySearch for lists. (Both behaviors when present aren't always what you want — rolling your own LB/UB is safer.)

🔎 When Should You Use Lower / Upper Bound?

  • "First / last occurrence of X in sorted array"
  • "How many values are ≤ X / < X / == X"
  • "Closest element to target" → LB + check LB−1
  • "K-th smallest" → binary search the answer value; count ≤ v
  • "Insert into sorted, kept sorted" / "first interval that starts ≥ end"
  • "Longest increasing subsequence" via patience sort
  • "Compatible job for DP transition" / "next event after time t"

📈 The 5 Types of Lower / Upper Bound — Full Breakdown

① First / Last Occurrence (and Count)

What it is: Find where the target's run starts and ends in a sorted array.

Recognize it when:

  • "Find First and Last Position of Element in Sorted Array"
  • "How many times does X appear?"
  • "First occurrence ≥ target", "last occurrence < target"

The identities:

  • first(t) = LB(t)
  • last(t) = UB(t) − 1
  • count(t) = UB(t) − LB(t)
Code Template: 
int lowerBound(int[] a, int t) {
    int L = 0, R = a.length;
    while (L < R) {
        int mid = L + (R - L) / 2;
        if (a[mid] >= t) R = mid;
        else             L = mid + 1;
    }
    return L;
}
int upperBound(int[] a, int t) {
    int L = 0, R = a.length;
    while (L < R) {
        int mid = L + (R - L) / 2;
        if (a[mid] > t) R = mid;
        else            L = mid + 1;
    }
    return L;
}

② Numeric Lower / Upper Bound (Boundary on Math Predicate)

What it is: The "array" is implicit — integers 1..N or 1..M. The predicate is mathematical (mid² ≤ x, missing(mid) < k, etc.).

Recognize it when:

  • "Sqrt(x)" → largest k with k² ≤ x
  • "Kth Missing Positive" → smallest i where missing(i) ≥ k
  • "Find Duplicate Number" → binary search value v with count(≤ v) ≥ v+1
Code Template (Sqrt(x)): 
public int mySqrt(int x) {
    long L = 0, R = x;
    while (L < R) {
        long mid = L + (R - L + 1) / 2;   // upper-mid for "largest k" search
        if (mid * mid <= x) L = mid;
        else                R = mid - 1;
    }
    return (int) L;
}

③ Binary Search on the Answer (K-th Smallest)

What it is: You can't directly access the k-th element, but you can count how many things are ≤ a candidate value. Binary search the candidate; find the smallest value v with count(≤ v) ≥ k.

Recognize it when:

  • "K-th smallest in sorted matrix / multiplication table / fraction list / pair distances"
  • "Median of two sorted arrays" (partition-based, advanced variant)

The pattern:

  • Binary search v in [low_value, high_value]
  • For each v, count entries ≤ v in O(n)
  • Smallest v with count ≥ k is the answer
Code Template (Kth in sorted matrix): 
public int kthSmallest(int[][] m, int k) {
    int n = m.length, lo = m[0][0], hi = m[n-1][n-1];
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        int cnt = 0, j = n - 1;
        for (int i = 0; i < n; i++) {
            while (j >= 0 && m[i][j] > mid) j--;
            cnt += j + 1;
        }
        if (cnt < k) lo = mid + 1;
        else         hi = mid;
    }
    return lo;
}

④ Per-Query Lower Bound (Lookup Table Pattern)

What it is: You build a sorted lookup table once; each query is answered by a lower / upper bound on it.

Recognize it when:

  • "For each X, find the closest Y" / "next event after time t"
  • "Heaters", "Find Right Interval", "Random Pick with Weight" (prefix sums)
  • "Online Election" — precomputed leader per timestamp, q() = upper bound on times

The pattern:

  • Sort / precompute the lookup once: O(n log n)
  • Each query: O(log n) via LB / UB
  • Total: O((n + q) log n)
Code Template (Heaters): 
public int findRadius(int[] houses, int[] heaters) {
    Arrays.sort(heaters);
    int radius = 0;
    for (int h : houses) {
        int idx = lowerBound(heaters, h);
        int dRight = idx < heaters.length ? heaters[idx] - h : Integer.MAX_VALUE;
        int dLeft  = idx > 0              ? h - heaters[idx-1] : Integer.MAX_VALUE;
        radius = Math.max(radius, Math.min(dLeft, dRight));
    }
    return radius;
}

⑤ Patience Sort / DP Transition via LB

What it is: Maintain a sorted helper array; insert each new element via lower bound. Powers O(n log n) LIS and many DP problems where the transition depends on "next compatible item."

Recognize it when:

  • "Longest Increasing Subsequence" / "Russian Doll Envelopes"
  • "Maximum Profit in Job Scheduling" (DP[i] uses LB on start times)
  • "Count of Smaller Numbers After Self" (BIT or sorted insert + LB)
  • "Maximum Number of Removable Characters" (binary search the maximum prefix length)
Code Template (LIS): 
public int lengthOfLIS(int[] nums) {
    int[] tails = new int[nums.length];
    int size = 0;
    for (int x : nums) {
        int L = 0, R = size;
        while (L < R) {
            int mid = L + (R - L) / 2;
            if (tails[mid] < x) L = mid + 1;
            else                R = mid;
        }
        tails[L] = x;
        if (L == size) size++;
    }
    return size;
}

🔨 Universal Lower / Upper Bound Templates

// Lower bound: smallest i with a[i] >= t
int lowerBound(int[] a, int t) {
    int L = 0, R = a.length;
    while (L < R) {
        int mid = L + (R - L) / 2;
        if (a[mid] >= t) R = mid;
        else             L = mid + 1;
    }
    return L;
}

// Upper bound: smallest i with a[i] > t
int upperBound(int[] a, int t) {
    int L = 0, R = a.length;
    while (L < R) {
        int mid = L + (R - L) / 2;
        if (a[mid] > t) R = mid;
        else            L = mid + 1;
    }
    return L;
}
