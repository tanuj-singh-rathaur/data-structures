P11 — Find Right Interval

Medium • LC #436 • Pattern: Sort Starts + Lower Bound per End

📝 The Problem

For each interval [s, e], find the index of the leftmost interval whose start is ≥ e. −1 if none.

Example: [[3,4],[2,3],[1,2]] → [-1, 0, 1]

📚 Jargon Buster

Sorted starts + originalIndex
Pair each start with its original index. Sort by start. Then LB on the start array for each query end.
Per-interval query
For each interval i, lower-bound its end in the sorted starts array → that's the next-right interval.

🌟 In Layman's Terms

Sort starts. For each interval's end value, find the first start that's at least that big — that's your "right interval."

⚡ The Aha Moment

Once starts are sorted (with original indices preserved), every query becomes a single lower bound.

🔧 Algorithm

  1. Build pairs (start, originalIndex). Sort by start.
  2. For each interval i: LB on sorted starts for intervals[i].end. Map back to original index.

☕ Java Solution

public int[] findRightInterval(int[][] intervals) {
    int n = intervals.length;
    int[][] pairs = new int[n][2];
    for (int i = 0; i < n; i++) { pairs[i][0] = intervals[i][0]; pairs[i][1] = i; }
    java.util.Arrays.sort(pairs, (a, b) -> a[0] - b[0]);
    int[] res = new int[n];
    for (int i = 0; i < n; i++) {
        int e = intervals[i][1];
        int L = 0, R = n;
        while (L < R) {
            int mid = L + (R - L) / 2;
            if (pairs[mid][0] >= e) R = mid;
            else                    L = mid + 1;
        }
        res[i] = L == n ? -1 : pairs[L][1];
    }
    return res;
}

⏳ Complexity

Time
O(n log n)
Space
O(n)

📈 LB/UB Pattern

Sort + Per-Query LB: Preserve indices during the sort by pairing. Same skeleton as Heaters, but the lookup table is "starts" and the query is "end."
Key Insight: When the output is an original index but the search uses a derived value, pair both together before sorting.
