P06 — Median of Two Sorted Arrays

Hard • LC #4 • Pattern: Binary Search the Partition

📝 The Problem

Find the median of the union of two sorted arrays without merging them. Required: O(log(min(m, n))).

Example: [1, 3] and [2] → 2.0

📚 Jargon Buster

Partition
Split each array into a left half and a right half. If left1.last ≤ right2.first AND left2.last ≤ right1.first, the partition is valid and the median can be read off.
BS on partition of shorter array
Binary search how many elements of the shorter array go into the left half. The other array's split is determined by total left size.
Sentinel values
If a partition is at array end, use ±∞ for the missing element. Cleaner than special-casing.

🌟 In Layman's Terms

Cut both arrays into two halves such that the total left size equals half the combined length, and the left side's max ≤ the right side's min. The median is at that border.

⚡ The Aha Moment

You don't merge. You binary search the cut point of the shorter array, and the partition of the longer array is forced by the total left-half size.

🔧 Algorithm

  1. Ensure A is the shorter array.
  2. L = 0, R = m. While L ≤ R: i = (L + R)/2; j = (m + n + 1)/2 − i.
  3. Check the cross-comparison; adjust L or R; on valid partition, compute the median.

☕ Java Solution

public double findMedianSortedArrays(int[] A, int[] B) {
    if (A.length > B.length) { int[] t = A; A = B; B = t; }
    int m = A.length, n = B.length, total = m + n, half = (total + 1) / 2;
    int L = 0, R = m;
    while (L <= R) {
        int i = L + (R - L) / 2, j = half - i;
        int Aleft  = i == 0 ? Integer.MIN_VALUE : A[i - 1];
        int Aright = i == m ? Integer.MAX_VALUE : A[i];
        int Bleft  = j == 0 ? Integer.MIN_VALUE : B[j - 1];
        int Bright = j == n ? Integer.MAX_VALUE : B[j];
        if (Aleft <= Bright && Bleft <= Aright) {
            if (total % 2 == 1) return Math.max(Aleft, Bleft);
            return (Math.max(Aleft, Bleft) + Math.min(Aright, Bright)) / 2.0;
        } else if (Aleft > Bright) R = i - 1;
        else                       L = i + 1;
    }
    return -1;
}

⏳ Complexity

Time
O(log(min(m, n)))
Space
O(1)

📈 LB/UB Pattern

BS the Partition: A specialized binary search on "where to cut" rather than on a value. The sentinel trick removes off-by-one branches.
Key Insight: Binary search the shorter array (log of the smaller m) — the longer array's partition follows automatically from the total left-half size.
