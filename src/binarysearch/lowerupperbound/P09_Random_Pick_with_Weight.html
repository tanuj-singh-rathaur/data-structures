P09 — Random Pick with Weight

Medium • LC #528 • Pattern: Cumulative Weights + Upper Bound on Random

📝 The Problem

Given weights array w, implement pickIndex() so each index i is picked with probability w[i] / sum(w).

Example: w = [1, 3] → pickIndex returns 0 with prob 1/4, 1 with prob 3/4.

📚 Jargon Buster

Cumulative weights
prefix[i] = w[0] + ... + w[i]. Sorted ascending automatically.
Random in [1..total]
Pick a uniform random target. Index whose prefix-sum first exceeds target-1 wins. That's lower-bound(target) in the prefix array.
Why O(1) sampling fails for skewed weights
A naive "pick random index then accept with weight prob" wastes calls. Prefix-sum + BS picks an index in O(log n) every time.

🌟 In Layman's Terms

Stack the weights end-to-end on a number line. Pick a random point. Whichever weight-block contains that point is your pick.

⚡ The Aha Moment

Cumulative weights are sorted, so finding "which block contains rand" reduces to a binary search.

🔧 Algorithm

  1. Constructor: build prefix sums; total = prefix[n−1].
  2. pickIndex: target = random.nextInt(total) + 1; lower-bound prefix for target.

☕ Java Solution

class Solution {
    int[] prefix;
    java.util.Random rand = new java.util.Random();
    public Solution(int[] w) {
        prefix = new int[w.length];
        prefix[0] = w[0];
        for (int i = 1; i < w.length; i++) prefix[i] = prefix[i - 1] + w[i];
    }
    public int pickIndex() {
        int total = prefix[prefix.length - 1];
        int target = rand.nextInt(total) + 1;
        int L = 0, R = prefix.length;
        while (L < R) {
            int mid = L + (R - L) / 2;
            if (prefix[mid] >= target) R = mid;
            else                       L = mid + 1;
        }
        return L;
    }
}

⏳ Complexity

Constructor
O(n)
pickIndex
O(log n)
Space
O(n)

📈 LB/UB Pattern

Prefix Sum + Lower Bound: Cumulative arrays are inherently sorted — a perfect substrate for boundary searches.
Key Insight: Weighted random sampling is binary search in disguise. Build prefix sums; sample a uniform value in [1, total]; LB returns the index.
