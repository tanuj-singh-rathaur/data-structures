P10 — Heaters

Medium • LC #475 • Pattern: Lower Bound per House + Nearest Heater Distance

📝 The Problem

Houses and heaters on a number line. Each heater covers a fixed radius. Find the minimum radius so every house is covered by some heater.

Example: houses=[1,2,3], heaters=[2] → 1

📚 Jargon Buster

Per-house distance
For each house, find the closest heater on either side via lower bound. Take the minimum of the two distances.
Answer
Max over all houses of "distance to nearest heater."

🌟 In Layman's Terms

Sort the heaters. For each house, find the closest heater on the left and the closest on the right. The smaller of those two distances is what that house needs. The worst house determines the answer.

⚡ The Aha Moment

Sort once, then use lower bound to answer each house's nearest-heater query in log time.

🔧 Algorithm

  1. Sort heaters.
  2. For each house h: idx = lowerBound(heaters, h); d = min(distance to heaters[idx] and heaters[idx−1]).
  3. radius = max(radius, d).

☕ Java Solution

public int findRadius(int[] houses, int[] heaters) {
    java.util.Arrays.sort(heaters);
    int radius = 0;
    for (int h : houses) {
        int L = 0, R = heaters.length;
        while (L < R) {
            int mid = L + (R - L) / 2;
            if (heaters[mid] >= h) R = mid;
            else                   L = mid + 1;
        }
        int dRight = L < heaters.length ? heaters[L] - h : Integer.MAX_VALUE;
        int dLeft  = L > 0              ? h - heaters[L - 1] : Integer.MAX_VALUE;
        radius = Math.max(radius, Math.min(dLeft, dRight));
    }
    return radius;
}

⏳ Complexity

Time
O((H + h) log h)
Space
O(1)

📈 LB/UB Pattern

Per-Query Lower Bound: Sort the lookup table once, log-time per query. Standard for "find nearest" problems.
Key Insight: The "nearest neighbor on a sorted list" pattern is two LB candidates (left side, right side) followed by a min — no special structure needed.
