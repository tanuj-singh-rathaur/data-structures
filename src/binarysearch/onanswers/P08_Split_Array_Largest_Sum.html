P08 — Split Array Largest Sum

Hard • LC #410 • Pattern: BS limit · greedy splits

📝 The Problem

Split nums into k contiguous non-empty subarrays so the largest subarray-sum is minimized.

📚 Jargon Buster

Partition into k parts
Cuts only — order preserved.
Bounds
lo = max(nums), hi = sum(nums) — any answer lies in this range.

🌟 In Layman's Terms

Guess a "ceiling" for the largest sum. Greedy-cut whenever adding the next number exceeds the ceiling. If you used ≤ k parts, try lower. Else higher.

⚡ The Aha Moment

This is a renaming of Capacity-to-Ship and Allocate-Pages — one universal template, many problem statements.

🔧 Algorithm

  1. lo = max(nums), hi = sum(nums).
  2. BS smallest limit with greedyCuts(limit) ≤ k.

☕ Java Solution

public int splitArray(int[] nums, int k) {
    int lo = 0, hi = 0;
    for (int x : nums) { lo = Math.max(lo, x); hi += x; }
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (parts(nums, mid) <= k) hi = mid;
        else                        lo = mid + 1;
    }
    return lo;
}
private int parts(int[] nums, int limit) {
    int p = 1, cur = 0;
    for (int x : nums) {
        if (cur + x > limit) { p++; cur = 0; }
        cur += x;
    }
    return p;
}

⏳ Complexity

Time
O(n log sum)
Space
O(1)
