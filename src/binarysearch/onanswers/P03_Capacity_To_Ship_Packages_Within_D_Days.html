P03 — Capacity to Ship Packages in D Days

Medium • LC #1011 • Pattern: BS capacity · greedy days

📝 The Problem

Pack packages (in given order) onto a ship of capacity c. Min c so all packages ship in ≤ d days.

📚 Jargon Buster

Lower Bound on c
max(weights) — the ship must fit the heaviest single package.
Upper Bound on c
sum(weights) — one day, one ship, all packages.
Greedy Days
Walk weights; start a new day when adding the next package overflows c.

🌟 In Layman's Terms

Guess a ship capacity. Greedily simulate days. Binary search for smallest capacity that fits in ≤ d days.

⚡ The Aha Moment

Bigger capacity ⇒ fewer days ⇒ monotone. Bounds set themselves: [max, sum].

🔧 Algorithm

  1. lo = max(weights), hi = sum(weights).
  2. While lo < hi: mid; simulate greedy day count.
  3. If days ≤ d: hi = mid. Else lo = mid + 1.

☕ Java Solution

public int shipWithinDays(int[] w, int d) {
    int lo = 0, hi = 0;
    for (int x : w) { lo = Math.max(lo, x); hi += x; }
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (days(w, mid) <= d) hi = mid;
        else                    lo = mid + 1;
    }
    return lo;
}
private int days(int[] w, int cap) {
    int days = 1, cur = 0;
    for (int x : w) {
        if (cur + x > cap) { days++; cur = 0; }
        cur += x;
    }
    return days;
}

⏳ Complexity

Time
O(n log sum)
Space
O(1)
