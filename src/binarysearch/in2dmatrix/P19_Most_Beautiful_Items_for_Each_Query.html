P19 — Most Beautiful Items for Each Query

Medium • LC #2070 • Pattern: Sort by Price + Prefix Max Beauty + LB per Query

📝 The Problem

Each item is (price, beauty). For each query q, return the max beauty of any item with price ≤ q.

📚 Jargon Buster

Prefix Max
After sorting by price, replace each item's beauty with running max so any prefix ⇒ best beauty achievable.
Upper Bound
Per query q, find last index with price ≤ q; the prefix-max at that index is the answer.

🌟 In Layman's Terms

Sort items by price. Walk left to right, keeping the best beauty so far. For each query, binary search for the last affordable item; its running-max beauty is the answer.

⚡ The Aha Moment

Sorting + prefix-max collapses "max over a sliding prefix" into a single binary search per query.

🔧 Algorithm

  1. Sort items by price ascending.
  2. Build prefix-max beauty array.
  3. For each query q: UB to find rightmost price ≤ q; answer = prefix-max at that index (or 0).

☕ Java Solution

public int[] maximumBeauty(int[][] items, int[] queries) {
    java.util.Arrays.sort(items, (a, b) -> a[0] - b[0]);
    int n = items.length;
    int[] prices = new int[n], maxB = new int[n];
    int best = 0;
    for (int i = 0; i < n; i++) {
        prices[i] = items[i][0];
        best = Math.max(best, items[i][1]);
        maxB[i] = best;
    }
    int[] ans = new int[queries.length];
    for (int q = 0; q < queries.length; q++) {
        int lo = 0, hi = n;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (prices[mid] <= queries[q]) lo = mid + 1;
            else                            hi = mid;
        }
        ans[q] = lo == 0 ? 0 : maxB[lo - 1];
    }
    return ans;
}

⏳ Complexity

Time
O((n + q) log n)
Space
O(n)

📈 2D Pattern

Sort + Prefix-Stat + LB: When a query asks "best metric over all entries with key ≤ q," sort by key and pre-build a prefix statistic, then binary search.
Key Insight: Decoupling preprocessing (O(n log n)) from per-query cost (O(log n)) is fundamental for offline query problems.
