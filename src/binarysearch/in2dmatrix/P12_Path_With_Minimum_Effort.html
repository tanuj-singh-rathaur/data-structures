P12 — Path With Minimum Effort

Medium • LC #1631 • Pattern: Binary Search Effort + BFS Reachability

📝 The Problem

"Effort" of a path = max |height(u) − height(v)| over adjacent steps. Return min possible effort from top-left to bottom-right.

📚 Jargon Buster

Edge constraint
You can step between adjacent cells whose height diff ≤ e.
BS on e
Monotonic: if e works, any e' ≥ e also works. Find smallest e with reachability.

🌟 In Layman's Terms

Binary search the max allowed step. For each candidate, BFS using only edges with diff ≤ it.

⚡ The Aha Moment

Same family as P11 (max min path): BS on a threshold + reachability check.

🔧 Algorithm

  1. lo = 0, hi = 10⁶. While lo < hi: mid; BFS using edges with diff ≤ mid.
  2. If reachable: hi = mid. Else lo = mid + 1.

☕ Java Solution (sketch)

public int minimumEffortPath(int[][] h) {
    int lo = 0, hi = 1_000_000;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (canReach(h, mid)) hi = mid;
        else                  lo = mid + 1;
    }
    return lo;
}
// canReach: BFS from (0,0); only step to (nr,nc) if |h[r][c] - h[nr][nc]| <= mid.

⏳ Complexity

Time
O(m·n · log V)
Space
O(m·n)

📈 2D Pattern

BS Threshold + Reachability: Same skeleton as P11. The constraint is per-edge (not per-cell) but the BS shape is identical.
Key Insight: Dijkstra with min-max edge weight also works in O((m·n) log(m·n)). BS + BFS is often easier to write and reason about.
