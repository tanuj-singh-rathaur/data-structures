P15 — Find K Pairs with Smallest Sums

Medium • LC #373 • Pattern: Min-Heap Over Implicit Sorted Matrix

📝 The Problem

Given two sorted arrays nums1, nums2, return the k pairs (a, b) with smallest a + b.

📚 Jargon Buster

Implicit sorted matrix
Treat (i, j) sums as cells M[i][j] = nums1[i] + nums2[j]. Sorted along both axes.
Min-heap expansion
Pop the smallest, expand its right/down neighbors with a visited set.

🌟 In Layman's Terms

Start with (0, 0) in a heap. Each pop yields the next smallest pair; push (i+1, j) and (i, j+1) (deduped). Repeat k times.

⚡ The Aha Moment

The "sum grid" is sorted both ways, so a Dijkstra-style heap walk finds the k smallest cells.

🔧 Algorithm

  1. Heap of (sum, i, j). Start with (sum(0,0), 0, 0).
  2. Pop k times; each pop pushes (i+1, j) and (i, j+1) if unvisited.

☕ Java Solution

public List<List<Integer>> kSmallestPairs(int[] nums1, int[] nums2, int k) {
    List<List<Integer>> res = new ArrayList<>();
    if (nums1.length == 0 || nums2.length == 0 || k == 0) return res;
    java.util.PriorityQueue<int[]> pq = new java.util.PriorityQueue<>((a, b) ->
        (nums1[a[0]] + nums2[a[1]]) - (nums1[b[0]] + nums2[b[1]]));
    boolean[][] seen = new boolean[nums1.length][nums2.length];
    pq.offer(new int[]{0, 0});
    seen[0][0] = true;
    while (res.size() < k && !pq.isEmpty()) {
        int[] cur = pq.poll();
        int i = cur[0], j = cur[1];
        res.add(Arrays.asList(nums1[i], nums2[j]));
        if (i + 1 < nums1.length && !seen[i + 1][j]) {
            seen[i + 1][j] = true; pq.offer(new int[]{i + 1, j});
        }
        if (j + 1 < nums2.length && !seen[i][j + 1]) {
            seen[i][j + 1] = true; pq.offer(new int[]{i, j + 1});
        }
    }
    return res;
}

⏳ Complexity

Time
O(k log k)
Space
O(k)

📈 2D Pattern

Implicit Sorted Matrix: Anywhere "X + Y" forms a doubly-sorted grid, a min-heap walk surfaces the k smallest sums.
Key Insight: Don't enumerate all m·n pairs — only expand neighbors of cells you've actually emitted. The heap bounds work to O(k log k).
