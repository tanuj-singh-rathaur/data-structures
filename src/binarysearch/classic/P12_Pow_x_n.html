P12 — Pow(x, n)

Medium • LC #50 • Pattern: Fast Exponentiation (Halving)

📝 The Problem

Compute x^n (x is a double, n is an integer that may be negative or extremely large).

Example: pow(2.0, 10) → 1024.0

📚 Jargon Buster

Fast power
x^n = (x^(n/2))² if n is even; x · (x^(n/2))² if n is odd. Halve n at each step → O(log n).
Negative n
x^(−n) = 1 / x^n. Compute the positive exponent then invert. Be careful: n = Integer.MIN_VALUE has no positive int form — cast to long first.

🌟 In Layman's Terms

Multiplying x by itself n times takes O(n) operations. But x^10 = (x^5)² and x^5 = x · (x²)². Halving the exponent at each step gives log-n total work.

⚡ The Aha Moment

Exponents distribute over multiplication: x^(a+b) = x^a · x^b. So x^n can always be built from x^(n/2).

🔧 Algorithm

  1. If n < 0: x = 1/x, n = −n (use long to handle MIN_VALUE).
  2. Iteratively: while n > 0, if n is odd multiply result by x; x *= x; n /= 2.

☕ Java Solution

public double myPow(double x, int n) {
    long N = n;
    if (N < 0) { x = 1 / x; N = -N; }
    double result = 1.0;
    while (N > 0) {
        if ((N & 1) == 1) result *= x;
        x *= x;
        N >>= 1;
    }
    return result;
}

⏳ Complexity

Time
O(log n)
Space
O(1)

📈 Binary Search Pattern

Fast Halving: Not a classic L/R search, but the same divide-and-conquer DNA. Each iteration cuts the work in half.
Key Insight: Use long N = n at the start so that N = -N works even for Integer.MIN_VALUE (whose negation overflows int).
