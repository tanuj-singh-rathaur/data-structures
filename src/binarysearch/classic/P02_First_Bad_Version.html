P02 — First Bad Version

Easy • LC #278 • Pattern: Find First True (Oracle API)

📝 The Problem

Versions 1..n. Once a version is bad, every later one is bad too. isBadVersion(v) tells you yes/no. Find the first bad version with minimum calls.

Example: n=5, bad=4 → 4

📚 Jargon Buster

Oracle API
isBadVersion(v) is the only way to query. You don't see the array; you only ask it questions.
Monotonic predicate
The predicate "is this version bad?" is false-then-true. That monotonicity is what lets binary search work.
Find smallest true
Standard "lower bound" template. Half-open interval avoids off-by-one bugs.

🌟 In Layman's Terms

Ask the oracle about the middle version. Bad? The first bad version is at this mid or earlier. Good? It's later. Cut your range in half each time.

⚡ The Aha Moment

The predicate is monotonic (false…false…true…true). Binary search the boundary — this is the same template that solves "search insert position."

🔧 Algorithm

  1. L = 1, R = n. While L < R: mid = L + (R−L)/2.
  2. If isBadVersion(mid): R = mid. Else L = mid + 1.
  3. Return L.

☕ Java Solution

public int firstBadVersion(int n) {
    int L = 1, R = n;
    while (L < R) {
        int mid = L + (R - L) / 2;
        if (isBadVersion(mid)) R = mid;
        else                   L = mid + 1;
    }
    return L;
}

⏳ Complexity

Time
O(log n)
Space
O(1)

📈 Binary Search Pattern

First-True Boundary: The generic "find smallest i where predicate(i) is true." Reusable for insert position, lower bound, and many predicate-on-monotonic problems.
Key Insight: The half-open range [L, R) with L < R termination is the cleanest way to express "find first true" — no fence-post errors.
