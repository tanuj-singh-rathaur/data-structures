P19 — Subarray Sums Divisible by K

Medium • LC #974 • Pattern: Prefix Mod K + Frequency Count

📝 The Problem

Count subarrays whose sum is divisible by k.

📚 Jargon Buster

Java-Safe Mod
For negatives: r = ((sum % k) + k) % k.
Combinatorial Pairing
If c prefixes share a remainder, they form c·(c−1)/2 valid subarrays among themselves.

🌟 In Layman's Terms

Group prefixes by remainder mod k. Any two prefixes in the same group give a divisible subarray. Count pairs incrementally.

⚡ The Aha Moment

Track frequency, not just first index — we want all pairs, not just one.

🔧 Algorithm

  1. map.put(0, 1).
  2. sum = 0, ans = 0.
  3. For x: sum += x; r = ((sum % k) + k) % k; ans += map.getOrDefault(r, 0); map.merge(r, 1, Integer::sum).

☕ Java Solution

public int subarraysDivByK(int[] nums, int k) {
    int[] cnt = new int[k];
    cnt[0] = 1;
    int sum = 0, ans = 0;
    for (int x : nums) {
        sum += x;
        int r = ((sum % k) + k) % k;
        ans += cnt[r];
        cnt[r]++;
    }
    return ans;
}

⏳ Complexity

Time
O(n)
Space
O(k)

📈 Frequency Pattern

Mod K + Frequency: Counting (not finding) divisible subarrays — keep freq, add the freq before incrementing.
Key Insight: Always apply ((x % k) + k) % k in Java to handle negative sums correctly.
