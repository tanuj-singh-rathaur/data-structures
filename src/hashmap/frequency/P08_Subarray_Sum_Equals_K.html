P08 — Subarray Sum Equals K

Medium • LC #560 • Pattern: Prefix Sum + Frequency Map

📝 The Problem

Count subarrays whose sum equals k.

📚 Jargon Buster

Prefix Sum
prefix[i] = sum of nums[0..i]. Subarray sum (l, r] = prefix[r] − prefix[l].
Frequency of Prefix
map<prefixSum, count>: how many indices share each prefix value.
Why prefix − k?
If prefix[r] − prefix[l] = k, then for each r the count of valid l = freq[prefix[r] − k].

🌟 In Layman's Terms

Track running sum and how often each sum value has appeared. At each step, ask: "how many earlier prefixes were exactly k less than now?"

⚡ The Aha Moment

Pre-seed map with 0 → 1 so a subarray starting at index 0 is counted.

🔧 Algorithm

  1. map<Long, Integer>; map.put(0, 1).
  2. sum = 0, count = 0.
  3. For x: sum += x; count += map.getOrDefault(sum − k, 0); map.merge(sum, 1, Integer::sum).

☕ Java Solution

public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> cnt = new HashMap<>();
    cnt.put(0, 1);
    int sum = 0, count = 0;
    for (int x : nums) {
        sum += x;
        count += cnt.getOrDefault(sum - k, 0);
        cnt.merge(sum, 1, Integer::sum);
    }
    return count;
}

⏳ Complexity

Time
O(n)
Space
O(n)

📈 Frequency Pattern

Prefix-Sum Frequency Map: The most powerful subarray-counting trick. Memorize the seed map.put(0, 1) — it accounts for prefix == k.
Key Insight: Negative numbers break sliding-window approaches; prefix-sum + map handles them naturally.
