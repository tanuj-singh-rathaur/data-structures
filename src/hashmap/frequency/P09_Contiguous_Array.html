P09 — Contiguous Array

Medium • LC #525 • Pattern: Map 0 → −1, then "longest subarray with sum 0"

📝 The Problem

Longest subarray with equal counts of 0 and 1.

📚 Jargon Buster

Sign Trick
Replace 0 with −1; "equal count of 0/1" becomes "subarray sum = 0."
First-Index Map
map<prefixSum, earliestIndex> — keep only the earliest occurrence to maximize length.

🌟 In Layman's Terms

Flip 0s to −1s. Walk computing running sum. Whenever the same sum reappears, the slice between is balanced. Keep the earliest index for each sum.

⚡ The Aha Moment

"Sum repeated" ⇒ "slice in between has net zero" — translates equality of counts into a sum query.

🔧 Algorithm

  1. map<Integer, Integer>; map.put(0, −1) (so a balanced prefix starts at index 0).
  2. sum = 0, best = 0.
  3. For i: sum += nums[i] == 1 ? 1 : −1. If map.containsKey(sum) ⇒ best = max(best, i − map.get(sum)); else map.put(sum, i).

☕ Java Solution

public int findMaxLength(int[] nums) {
    Map<Integer, Integer> first = new HashMap<>();
    first.put(0, -1);
    int sum = 0, best = 0;
    for (int i = 0; i < nums.length; i++) {
        sum += nums[i] == 1 ? 1 : -1;
        if (first.containsKey(sum)) best = Math.max(best, i - first.get(sum));
        else                          first.put(sum, i);
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(n)

📈 Frequency Pattern

First-Index Map: For longest-subarray problems, store first occurrence (not count). Reusable for "longest substring with equal X and Y."
Key Insight: The sign-flip transforms a balance problem into a sum problem — a common trick worth knowing.
