P06 — Valid Anagram

Easy • LC #242 • Pattern: +/− Frequency Counter

📝 The Problem

Return true if t is an anagram of s.

📚 Jargon Buster

+/− Counter
One pass: increment for s, decrement for t. Anagram iff all entries are zero.

🌟 In Layman's Terms

Use a 26-length count array. Each char in s adds 1; each char in t subtracts 1. If anything is nonzero at the end, mismatch.

⚡ The Aha Moment

You don't need two separate count arrays; one suffices using +/−.

🔧 Algorithm

  1. If lengths differ, return false.
  2. int[26] count; for s: count[c-'a']++; for t: count[c-'a']--.
  3. Return all zeros.

☕ Java Solution

public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] count = new int[26];
    for (int i = 0; i < s.length(); i++) {
        count[s.charAt(i) - 'a']++;
        count[t.charAt(i) - 'a']--;
    }
    for (int c : count) if (c != 0) return false;
    return true;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Frequency Pattern

+/− Counter: Use a single array with opposite signs to compare two multisets in one pass.
Key Insight: Two arrays equal ⇔ pointwise difference is zero. Cheap, clean, branch-free.
