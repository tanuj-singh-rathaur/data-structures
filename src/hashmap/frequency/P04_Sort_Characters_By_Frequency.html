P04 — Sort Characters By Frequency

Medium • LC #451 • Pattern: Char Frequency + Bucket Sort

📝 The Problem

Sort characters of a string by frequency descending. Repeat each character its count times in the output.

📚 Jargon Buster

Char Frequency
Same as Top-K but for characters; counts bounded by length of string.

🌟 In Layman's Terms

Count chars, group them by count in buckets, then emit characters from highest bucket downwards, repeated count times.

⚡ The Aha Moment

Identical bucket-sort to P03 — just emit each character "count" times into the result builder.

🔧 Algorithm

  1. Count chars in map<Character, Integer>.
  2. buckets[freq] = list of chars; n+1 buckets.
  3. Walk buckets high→low, append c repeated freq times into StringBuilder.

☕ Java Solution

public String frequencySort(String s) {
    int n = s.length();
    Map<Character, Integer> freq = new HashMap<>();
    for (char c : s.toCharArray()) freq.merge(c, 1, Integer::sum);
    List<Character>[] buckets = new List[n + 1];
    for (var e : freq.entrySet()) {
        int c = e.getValue();
        if (buckets[c] == null) buckets[c] = new ArrayList<>();
        buckets[c].add(e.getKey());
    }
    StringBuilder sb = new StringBuilder(n);
    for (int i = n; i >= 1; i--) {
        if (buckets[i] == null) continue;
        for (char c : buckets[i]) for (int j = 0; j < i; j++) sb.append(c);
    }
    return sb.toString();
}

⏳ Complexity

Time
O(n)
Space
O(n)

📈 Frequency Pattern

Bucket-sort Output: "Sort by frequency" output problems collapse to bucket-sort plus a repeat-emit step.
Key Insight: The same bucket data structure serves "Top K" and "Sort by Frequency" with only the emit step changing.
