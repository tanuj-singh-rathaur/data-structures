HashMapFrequency / Counting

HashMap · Frequency — Masterclass

Count, lookup, and remember — the family of problems where a HashMap of counts (or first-seen indices) unlocks an O(n) solution.

📝 What Is Frequency / Counting?

A HashMap (or int[26], int[256], or HashSet) stores how often something has been seen — or where it was first seen. That lets you answer questions like "have I seen this complement before?" or "how many subarrays sum to k?" in O(1) per element instead of O(n).

📚 Jargon Buster

Frequency Map
map<key, count> — how many times each key appeared.
First-Index Map
map<key, firstIndex> — used in longest/earliest subarray problems.
Complement Lookup
For each new element x, check if target − x is already in the map (e.g. Two Sum).
Prefix-Sum Map
map<runningSum, count or index> — turns subarray sum questions into O(n) lookups.
Bucket Sort by Frequency
buckets[freq] = list of items with that count; emit high → low for Top-K in O(n).
Signature Key
Canonical fingerprint (sorted string, count tuple) — groups items that share an equivalence (e.g. anagrams).

🎯 When to use Frequency / HashMap

  • Problem asks for a count, a duplicate, or a "first/last" position.
  • You want to convert nested O(n²) lookups into O(n) via memoised state.
  • Subarray / substring problems with a sum or count condition.
  • Categorising items by an equivalence relation (anagrams, isomorphic).

🏭 The 5 Sub-Patterns

1. Frequency Map (count)

How often does each value appear?

map.merge(x, 1, Integer::sum)

Majority Element, Top K, Sort Chars, Ransom Note, Valid Anagram, Intersection II

2. Complement Lookup (index map)

Have I seen target − x before?

if (map.containsKey(t - x)) ...

Two Sum, First Unique Character

3. Prefix-Sum Frequency Map

Count subarrays summing to k via running sums.

count += map.get(prefix − k)

Subarray Sum = K, Subarray Div by K, Nice Subarrays, Continuous Subarray Sum, Contiguous Array

4. Signature-Key Grouping

Canonical key groups equivalents.

key = sorted(s) or count tuple

Group Anagrams, Find All Anagrams (window), Isomorphic, Word Pattern

5. Set-based Existence / Cycle

Track "seen" items for membership or cycle detection.

set.add(x); if (set.contains(y)) ...

Longest Consecutive Sequence, Happy Number, Find All Duplicates

⚙️ Universal Templates

Frequency Map:

Map<K, Integer> freq = new HashMap<>();
for (K k : items) freq.merge(k, 1, Integer::sum);

Complement Lookup:

Map<Integer, Integer> idx = new HashMap<>();
for (int i = 0; i < n; i++) {
    if (idx.containsKey(target - nums[i])) return new int[]{idx.get(target - nums[i]), i};
    idx.put(nums[i], i);
}

Prefix-Sum Subarray Count:

Map<Long, Integer> cnt = new HashMap<>();
cnt.put(0L, 1);                       // empty prefix
long sum = 0;
int answer = 0;
for (int x : nums) {
    sum += x;
    answer += cnt.getOrDefault(sum - k, 0);
    cnt.merge(sum, 1, Integer::sum);
}
