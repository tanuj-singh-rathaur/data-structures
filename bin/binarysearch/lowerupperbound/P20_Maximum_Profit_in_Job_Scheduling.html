P20 — Maximum Profit in Job Scheduling

Hard • LC #1235 • Pattern: Weighted Interval Scheduling DP via LB

📝 The Problem

Jobs with (start, end, profit). Pick non-overlapping jobs to maximize total profit.

Example: start=[1,2,3,3], end=[3,4,5,6], profit=[50,10,40,70] → 120

📚 Jargon Buster

Sort by end
After sorting, dp[i] = max profit using only jobs 0..i.
Take vs skip
dp[i] = max(dp[i−1], profit[i] + dp[k]) where k = LB(end array, start[i]) − 1.
LB transition
The "k" is the largest index whose end ≤ start[i]. Lower bound finds the first end strictly greater than start[i]; back off one.

🌟 In Layman's Terms

Sort jobs by end time. For each job, decide: skip it (carry previous max) or take it (its profit + the best you could earn from jobs ending before this job starts). Binary search to find the latest compatible job.

⚡ The Aha Moment

Sort + LB turns the "find latest compatible job" query into O(log n) per step, giving O(n log n) total.

🔧 Algorithm

  1. Sort jobs by end time.
  2. dp[0] = profit[0]. For i = 1..n−1: k = LB(end, start[i]) − 1; dp[i] = max(dp[i−1], profit[i] + (k ≥ 0 ? dp[k] : 0)).
  3. Return dp[n−1].

☕ Java Solution

public int jobScheduling(int[] start, int[] end, int[] profit) {
    int n = start.length;
    int[][] jobs = new int[n][3];
    for (int i = 0; i < n; i++) jobs[i] = new int[]{start[i], end[i], profit[i]};
    java.util.Arrays.sort(jobs, (a, b) -> a[1] - b[1]);
    int[] dp = new int[n];
    int[] ends = new int[n];
    for (int i = 0; i < n; i++) ends[i] = jobs[i][1];
    dp[0] = jobs[0][2];
    for (int i = 1; i < n; i++) {
        int L = 0, R = i;
        while (L < R) {
            int mid = L + (R - L) / 2;
            if (ends[mid] > jobs[i][0]) R = mid;
            else                        L = mid + 1;
        }
        int prevProfit = L > 0 ? dp[L - 1] : 0;
        dp[i] = Math.max(dp[i - 1], jobs[i][2] + prevProfit);
    }
    return dp[n - 1];
}

⏳ Complexity

Time
O(n log n)
Space
O(n)

📈 LB/UB Pattern

DP + LB Transition: The standard recipe for weighted interval scheduling. The LB lookup finds the latest non-overlapping prior job in log time.
Key Insight: Sorting by end time creates a useful invariant: dp[i] depends only on a prefix of the array, and the "latest compatible" lookup is a single LB.
