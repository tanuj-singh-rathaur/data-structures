P14 — K-th Smallest Prime Fraction

Medium • LC #786 • Pattern: Binary Search on Real-Valued Answer

📝 The Problem

Sorted array of distinct primes (and 1). Return the k-th smallest fraction arr[i] / arr[j] with i < j.

Example: arr = [1, 2, 3, 5], k = 3 → [2, 5]

📚 Jargon Buster

BS on fraction
The fraction value lies in (0, 1). Binary search f. For each candidate, count how many fractions ≤ f.
Count + track best pair
While counting, remember the largest fraction ≤ f seen — that's a candidate answer.
Real-number BS
Use enough iterations (~100) for floating precision, or rely on the count to be exactly k for termination.

🌟 In Layman's Terms

Guess a fraction value. Sweep through pairs; count those ≤ guess. Adjust guess until count == k. Track the largest pair under guess as you go.

⚡ The Aha Moment

Binary search on a real number (not an integer). Use enough precision and track the actual pair value, since the answer must be one of the input fractions.

🔧 Algorithm

  1. lo = 0, hi = 1.
  2. Loop ~100 iterations: mid; count fractions ≤ mid via two-pointer; track largest pair.
  3. If count < k: lo = mid. Else hi = mid.
  4. Return tracked pair when count == k.

☕ Java Solution

public int[] kthSmallestPrimeFraction(int[] arr, int k) {
    int n = arr.length;
    double lo = 0, hi = 1;
    int[] best = new int[2];
    while (true) {
        double mid = (lo + hi) / 2;
        int cnt = 0, j = 0;
        int p = 0, q = 1;
        for (int i = 0; i < n; i++) {
            while (j < n && arr[i] > mid * arr[j]) j++;
            cnt += n - j;
            if (j < n && (long) p * arr[j] < (long) q * arr[i]) {
                p = arr[i]; q = arr[j];
            }
        }
        if (cnt == k) { best[0] = p; best[1] = q; return best; }
        if (cnt < k) lo = mid; else hi = mid;
    }
}

⏳ Complexity

Time
O(n · log(precision))
Space
O(1)

📈 LB/UB Pattern

BS on Real-Valued Answer: Search a continuous answer space; rely on integer cross-multiplication for exact comparisons.
Key Insight: Compare fractions by cross-multiplication (p · arr[j] < q · arr[i]) to avoid floating-point pitfalls when tracking the best pair.
