P12 — Find K-th Smallest Pair Distance

Hard • LC #719 • Pattern: Binary Search Distance + Sliding Window Count

📝 The Problem

Find the k-th smallest distance |nums[i] − nums[j]| over all pairs.

Example: [1, 3, 1], k = 1 → 0

📚 Jargon Buster

Distance range
After sorting, distance is in [0, max − min]. Binary search d in that range.
Count pairs ≤ d (two-pointer)
For each right index R, advance L until nums[R] − nums[L] ≤ d. Add R − L to the count.
Smallest d with count ≥ k
Lower-bound the distance: smallest d satisfying the predicate.

🌟 In Layman's Terms

Binary search the distance. For each candidate, count how many pairs are within that distance using a sliding window. Find the smallest distance where the count reaches k.

⚡ The Aha Moment

Sorting unlocks the two-pointer count, which makes "how many pairs ≤ d?" O(n) instead of O(n²).

🔧 Algorithm

  1. Sort nums. lo = 0, hi = nums[n−1] − nums[0].
  2. While lo < hi: mid; count pairs with diff ≤ mid via 2-ptr.
  3. If count < k: lo = mid + 1. Else hi = mid.

☕ Java Solution

public int smallestDistancePair(int[] nums, int k) {
    java.util.Arrays.sort(nums);
    int n = nums.length, lo = 0, hi = nums[n - 1] - nums[0];
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2, cnt = 0, L = 0;
        for (int R = 0; R < n; R++) {
            while (nums[R] - nums[L] > mid) L++;
            cnt += R - L;
        }
        if (cnt < k) lo = mid + 1;
        else         hi = mid;
    }
    return lo;
}

⏳ Complexity

Time
O((n + R) log R)
Space
O(1)

📈 LB/UB Pattern

BS Answer + Linear Count: Search the answer's value; use a sorted-data trick (two-pointer here) to count in O(n) per check.
Key Insight: Sorting first is what makes the 2-pointer count work — the windows are monotonic in R, so L only moves forward.
