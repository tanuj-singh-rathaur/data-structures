P18 — Find Smallest Common Element in All Rows

Medium • LC #1198 • Pattern: For each row-0 value, LB it in every other row

📝 The Problem

Sorted rows. Return the smallest value that appears in every row, or −1.

Example: [[1,2,3,4,5],[2,4,5,8,10],[3,5,7,9,11],[1,3,5,7,9]] → 5

📚 Jargon Buster

Row 0 as candidates
The answer must exist in row 0. Iterate its values in order.
LB per row
For each candidate v, lower-bound v in every other row. If found everywhere, return.
Alternative: row pointers
Walk a pointer per row; advance the one with smallest current value. O(m·n) but no BS — cleaner if BS overkill.

🌟 In Layman's Terms

Take each value in the first row in order. For each, binary search it in every other row. Return the first one that appears in all.

⚡ The Aha Moment

Sorted rows + LB per row makes the per-candidate check log-time. Done as soon as the smallest match is found.

🔧 Algorithm

  1. For each v in row 0:
    • For each other row r: if v not found via LB → break.
    • If all rows contain v → return v.
  2. Return −1.

☕ Java Solution

public int smallestCommonElement(int[][] mat) {
    int m = mat.length, n = mat[0].length;
    for (int v : mat[0]) {
        boolean all = true;
        for (int r = 1; r < m; r++) {
            int L = 0, R = n;
            while (L < R) {
                int mid = L + (R - L) / 2;
                if (mat[r][mid] >= v) R = mid;
                else                  L = mid + 1;
            }
            if (L == n || mat[r][L] != v) { all = false; break; }
        }
        if (all) return v;
    }
    return -1;
}

⏳ Complexity

Time
O(m · n · log n)
Space
O(1)

📈 LB/UB Pattern

LB Across Sorted Tables: When each row is sorted, "does X exist here?" is a single LB. Pair with iteration over candidates.
Key Insight: The answer must exist in row 0 (or any single row). Use the smallest row as the candidate source for fewest iterations.
