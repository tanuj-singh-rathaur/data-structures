P02 — Sqrt(x)

Easy • LC #69 • Pattern: Largest k with k² ≤ x

📝 The Problem

Return ⌊√x⌋ for non-negative integer x without using built-in sqrt.

Example: x = 8 → 2 (2² = 4, 3² = 9)

📚 Jargon Buster

Largest k with predicate true
Sqrt is the largest k where k² ≤ x. Binary search the boundary: predicate is true for k = 0..√x and false beyond.
Overflow trap
k² can overflow int when k ≈ 46341. Use long.
Upper-mid for "largest k"
When searching for the largest valid k, compute mid = L + (R − L + 1) / 2. Otherwise the loop hangs when L = R − 1.

🌟 In Layman's Terms

Guess a root. Square it. Too big → guess smaller. Otherwise it's a valid root candidate. Find the largest valid one.

⚡ The Aha Moment

The predicate "k² ≤ x" is monotonic: true for small k, false past √x. Binary search the boundary — same template as lower bound, with upper-mid for "largest valid."

🔧 Algorithm

  1. L = 0, R = x (long).
  2. While L < R: mid = L + (R − L + 1) / 2.
  3. If mid² ≤ x: L = mid. Else R = mid − 1.
  4. Return (int) L.

☕ Java Solution

public int mySqrt(int x) {
    long L = 0, R = x;
    while (L < R) {
        long mid = L + (R - L + 1) / 2;
        if (mid * mid <= x) L = mid;
        else                R = mid - 1;
    }
    return (int) L;
}

⏳ Complexity

Time
O(log x)
Space
O(1)

📈 LB/UB Pattern

Numeric Lower Bound on Math Predicate: Implicit "array" of integers; predicate is a math comparison. Identical structure to "Valid Perfect Square" and "Arranging Coins" in classic binary search.
Key Insight: When searching for the largest valid k (not the smallest), bump the mid upward with (R − L + 1) / 2. Otherwise L = mid can stall.
