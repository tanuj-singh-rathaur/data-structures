P17 — Swim in Rising Water

Hard • LC #778 • Pattern: Binary Search Time + BFS

📝 The Problem

At time t the water level is t; you can step to adjacent cell if its elevation ≤ t. Min time to reach (n−1, n−1) from (0, 0).

📚 Jargon Buster

Monotonic t
If you can reach at time t, you can at any t' ≥ t. Find smallest feasible t.

🌟 In Layman's Terms

Binary search the water level. For each candidate, BFS using cells whose elevation ≤ candidate. Smallest level reaching the end is the answer.

⚡ The Aha Moment

Same skeleton as P11 / P12: BS the threshold + reachability check.

🔧 Algorithm

  1. lo = grid[0][0], hi = max elevation. While lo < hi: mid; BFS using cells ≤ mid.
  2. If reachable: hi = mid. Else lo = mid + 1.

☕ Java Solution

public int swimInWater(int[][] grid) {
    int n = grid.length, lo = grid[0][0], hi = n * n - 1;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (canReach(grid, mid)) hi = mid;
        else                     lo = mid + 1;
    }
    return lo;
}
private boolean canReach(int[][] g, int t) {
    int n = g.length;
    if (g[0][0] > t) return false;
    boolean[][] vis = new boolean[n][n];
    java.util.Deque<int[]> q = new java.util.ArrayDeque<>();
    q.offer(new int[]{0, 0});
    vis[0][0] = true;
    int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
    while (!q.isEmpty()) {
        int[] c = q.poll();
        if (c[0] == n - 1 && c[1] == n - 1) return true;
        for (int[] d : dirs) {
            int nr = c[0] + d[0], nc = c[1] + d[1];
            if (nr >= 0 && nr < n && nc >= 0 && nc < n && !vis[nr][nc] && g[nr][nc] <= t) {
                vis[nr][nc] = true;
                q.offer(new int[]{nr, nc});
            }
        }
    }
    return false;
}

⏳ Complexity

Time
O(n² · log n²)
Space
O(n²)

📈 2D Pattern

BS Time + BFS: Reusable for any "smallest threshold making the grid connected from start to end."
Key Insight: Alternative: Dijkstra where edge weight = max of cell elevations. Both yield the same answer; BS+BFS is conceptually simpler.
