P20 — Minimum Absolute Sum Difference

Medium • LC #1818 • Pattern: Sort One Array + Per-Index LB to Find Best Replacement

📝 The Problem

Given nums1, nums2, you may replace at most one nums1[i] with another nums1[j]. Minimize Σ|nums1[i] − nums2[i]| mod 1e9+7.

📚 Jargon Buster

Replacement Gain
For index i with current cost |a−b|, the best replacement gain = |a−b| − min |a' − b| over a' ∈ nums1. Pick max gain over i.
Closest in sorted array
Use lower bound on sorted nums1 with target = nums2[i] and check neighbours.

🌟 In Layman's Terms

Total sum if no replacement. Then per i, find the nums1 value closest to nums2[i] — that's the best replacement. Largest "saved" wins.

⚡ The Aha Moment

Per-index optimisation is independent ⇒ each replacement decision is a 1D closest-value query.

🔧 Algorithm

  1. Compute base sum of |nums1[i] − nums2[i]|.
  2. Sort copy of nums1.
  3. For each i: LB(sorted, nums2[i]); compare with idx and idx−1 for closest. Compute gain = old − new; track max.
  4. Return (sum − maxGain) % MOD.

☕ Java Solution

public int minAbsoluteSumDiff(int[] nums1, int[] nums2) {
    int MOD = 1_000_000_007, n = nums1.length;
    int[] sorted = nums1.clone();
    java.util.Arrays.sort(sorted);
    long sum = 0, maxGain = 0;
    for (int i = 0; i < n; i++) {
        int diff = Math.abs(nums1[i] - nums2[i]);
        sum += diff;
        int idx = java.util.Arrays.binarySearch(sorted, nums2[i]);
        if (idx < 0) idx = -idx - 1;
        int best = diff;
        if (idx < n)    best = Math.min(best, Math.abs(sorted[idx]     - nums2[i]));
        if (idx > 0)    best = Math.min(best, Math.abs(sorted[idx - 1] - nums2[i]));
        maxGain = Math.max(maxGain, diff - best);
    }
    return (int) ((sum - maxGain) % MOD);
}

⏳ Complexity

Time
O(n log n)
Space
O(n)

📈 2D Pattern

Per-i Closest Lookup: "Replace one element for best total" is solved by precomputing a sorted view, then per-i closest-value search.
Key Insight: Decoupling base cost from "best single edit" turns an O(n²) brute search into O(n log n).
