P10 — Max Side Length of Square with Sum ≤ Threshold

Medium • LC #1292 • Pattern: 2D Prefix Sum + Binary Search on Side

📝 The Problem

Return the maximum side length k such that some k×k square has sum ≤ threshold.

📚 Jargon Buster

2D prefix sum
P[r+1][c+1] = sum of [0..r] × [0..c]. O(1) submatrix sums via inclusion-exclusion.
BS on side
"Exists a k×k square ≤ threshold?" is monotonic in k: a k+1×k+1 square contains a k×k one, but its sum can only grow.

🌟 In Layman's Terms

Compute 2D prefix sums so any submatrix sum is O(1). Binary search the side length. For each candidate k, check if any k×k square fits within threshold.

⚡ The Aha Moment

The "feasible side" predicate is monotonic — if k works, all smaller k' also work.

🔧 Algorithm

  1. Build 2D prefix sums.
  2. BS k in [0, min(m, n)]. For each candidate, scan positions to find a k×k window ≤ threshold.

☕ Java Solution

public int maxSideLength(int[][] mat, int threshold) {
    int m = mat.length, n = mat[0].length;
    int[][] P = new int[m + 1][n + 1];
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            P[i + 1][j + 1] = mat[i][j] + P[i][j + 1] + P[i + 1][j] - P[i][j];
    int L = 0, R = Math.min(m, n);
    while (L < R) {
        int mid = L + (R - L + 1) / 2;
        if (feasible(P, m, n, mid, threshold)) L = mid;
        else                                    R = mid - 1;
    }
    return L;
}
private boolean feasible(int[][] P, int m, int n, int k, int t) {
    for (int i = k; i <= m; i++)
        for (int j = k; j <= n; j++) {
            int s = P[i][j] - P[i - k][j] - P[i][j - k] + P[i - k][j - k];
            if (s <= t) return true;
        }
    return false;
}

⏳ Complexity

Time
O(m·n · log(min(m,n)))
Space
O(m·n)

📈 2D Pattern

2D Prefix + BS Side: Pair O(1) submatrix sum with monotonic side-length predicate. Generic for "largest k×k fitting bound."
Key Insight: Use upper-mid (R−L+1)/2 when searching the largest valid k; otherwise the loop stalls when L = R − 1.
