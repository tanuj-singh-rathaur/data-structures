P07 — Leftmost Column with at Least a One

Medium • LC #1428 • Pattern: Staircase Walk via Oracle API

📝 The Problem

Binary matrix; each row sorted ascending (0s then 1s). Access via BinaryMatrix.get(r, c) only. Return the leftmost column containing a 1, or −1.

📚 Jargon Buster

API-restricted access
Total calls to get() are limited; must use few calls.
Top-right staircase
From top-right: if 1, move left (better candidate). If 0, move down. Each move is O(1).

🌟 In Layman's Terms

Start at top-right. See a 1? Maybe earlier in this row; step left. See a 0? Skip this row; step down. Track the leftmost column where you've seen a 1.

⚡ The Aha Moment

Each row's 1-section starts at some column; the leftmost across all rows is monotonically reachable from top-right.

🔧 Algorithm

  1. r = 0, c = cols − 1, best = −1.
  2. While r < rows AND c ≥ 0: if get(r, c) == 1 → best = c; c--. Else r++.

☕ Java Solution

public int leftMostColumnWithOne(BinaryMatrix bm) {
    int[] dim = bm.dimensions();
    int rows = dim[0], cols = dim[1];
    int r = 0, c = cols - 1, best = -1;
    while (r < rows && c >= 0) {
        if (bm.get(r, c) == 1) { best = c; c--; }
        else                   r++;
    }
    return best;
}

⏳ Complexity

Time
O(m + n) API calls
Space
O(1)

📈 2D Pattern

Staircase via Oracle: Same shape as Search 2D II; just guarded by an API instead of direct access.
Key Insight: When access is via API with call limits, prefer staircase (O(m + n)) over per-row binary search (O(m log n)) — fewer calls and simpler logic.
