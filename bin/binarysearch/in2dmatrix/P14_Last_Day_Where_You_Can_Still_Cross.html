P14 — Last Day Where You Can Still Cross

Hard • LC #1970 • Pattern: Binary Search the Day + BFS

📝 The Problem

A grid of cells; on day d the first d cells in cells[] are flooded. Return the last day you can walk from top row to bottom row using land cells.

📚 Jargon Buster

Monotonic in day
If day d works, all d' < d also work. So "largest d that works" is a binary-search problem.
BFS land-only
For each candidate d, mark first d cells flooded; BFS through remaining land.

🌟 In Layman's Terms

Binary search the day. For each candidate, simulate flooding then BFS across the land.

⚡ The Aha Moment

The reachability flips from true to false at exactly one boundary day. Binary search finds it.

🔧 Algorithm

  1. L = 0, R = cells.length. While L < R: mid = (L + R + 1) / 2.
  2. Mark cells[0..mid−1] flooded; BFS from top row to bottom row.
  3. If reachable: L = mid. Else R = mid − 1.

☕ Java Solution (sketch)

public int latestDayToCross(int rows, int cols, int[][] cells) {
    int L = 0, R = cells.length;
    while (L < R) {
        int mid = L + (R - L + 1) / 2;
        if (canCross(rows, cols, cells, mid)) L = mid;
        else                                   R = mid - 1;
    }
    return L;
}
// canCross: flood first 'mid' cells; BFS from any top-row land to any bottom-row land.

⏳ Complexity

Time
O(m·n · log(m·n))
Space
O(m·n)

📈 2D Pattern

BS Day + BFS: Time-evolving grid problems often reduce to "binary search the time + reachability check at that time."
Key Insight: Alternative: reverse-time union-find (add cells back from last to first; first time top and bottom connect = answer). Both work; BS+BFS is conceptually simpler.
