P05 — Find Peak Element II

Medium • LC #1901 • Pattern: Binary Search Columns + Column Max

📝 The Problem

Cell is a peak if strictly greater than its 4 neighbors. Find any peak in O(m log n) or O(n log m).

📚 Jargon Buster

Column max
For a candidate column, find the row holding the maximum value in that column.
BS the columns
Look at the middle column; the max in that column is a peak in its row. Compare horizontally; move to whichever side has a strictly larger neighbor.

🌟 In Layman's Terms

Pick the middle column. Find the largest value in it. If the value to its left or right is bigger, search that side. Otherwise that cell is a 2D peak.

⚡ The Aha Moment

The column max guarantees no vertical neighbor is bigger; only horizontal neighbors can be. That's the monotonic step direction.

🔧 Algorithm

  1. L = 0, R = cols − 1.
  2. While L < R: midCol; find rowMax in column midCol. If mat[rowMax][midCol] < mat[rowMax][midCol + 1]: L = midCol + 1. Else R = midCol.
  3. Return [maxRow, L].

☕ Java Solution

public int[] findPeakGrid(int[][] mat) {
    int L = 0, R = mat[0].length - 1;
    while (L < R) {
        int mid = L + (R - L) / 2;
        int maxRow = 0;
        for (int r = 1; r < mat.length; r++) if (mat[r][mid] > mat[maxRow][mid]) maxRow = r;
        if (mat[maxRow][mid] < mat[maxRow][mid + 1]) L = mid + 1;
        else                                          R = mid;
    }
    int maxRow = 0;
    for (int r = 1; r < mat.length; r++) if (mat[r][L] > mat[maxRow][L]) maxRow = r;
    return new int[]{maxRow, L};
}

⏳ Complexity

Time
O(m · log n)
Space
O(1)

📈 2D Pattern

BS on Column: Generalize 1D peak by binary searching one dimension and using max within the other.
Key Insight: Column-max + horizontal compare → 2D peak reduces to 1D peak logic with an O(m) lookup per step.
