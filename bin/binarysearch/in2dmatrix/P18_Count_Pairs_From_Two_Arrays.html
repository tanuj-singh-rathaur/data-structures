P18 — Count Pairs From Two Arrays

Medium • LC #2354-ish • Pattern: Sort + Per-i Lower Bound

📝 The Problem

Given arrays nums1, nums2 (same length n), count pairs (i, j) with i < j such that nums1[i] + nums1[j] > nums2[i] + nums2[j].

📚 Jargon Buster

Transform
Let d[k] = nums1[k] − nums2[k]. Condition becomes d[i] + d[j] > 0.
Sort + 2-pointer / LB
Sort d. For each i find smallest j > i with d[i] + d[j] > 0 via lower bound.

🌟 In Layman's Terms

Turn two arrays into one by subtracting elementwise, sort it, then use two pointers (or per-i binary search) to count pairs summing positive.

⚡ The Aha Moment

Counting d[i] + d[j] > 0 in a sorted array is a classic 2-pointer / LB pattern.

🔧 Algorithm

  1. d[k] = nums1[k] − nums2[k]; sort d.
  2. l = 0, r = n − 1. While l < r: if d[l] + d[r] > 0, all elements between l+1..r pair with r ⇒ add (r − l); r--. Else l++.

☕ Java Solution

public long countPairs(int[] nums1, int[] nums2) {
    int n = nums1.length;
    long[] d = new long[n];
    for (int i = 0; i < n; i++) d[i] = nums1[i] - nums2[i];
    java.util.Arrays.sort(d);
    long count = 0;
    int l = 0, r = n - 1;
    while (l < r) {
        if (d[l] + d[r] > 0) { count += r - l; r--; }
        else                   l++;
    }
    return count;
}

⏳ Complexity

Time
O(n log n)
Space
O(n)

📈 2D Pattern

Transform + 2-Pointer: Linear-combination conditions on pairs become 1D sorted-array sum counts.
Key Insight: A subtraction or addition transform almost always reduces 2-array per-pair inequalities to 1-array classic patterns.
