P04 — Row with Maximum Ones

Easy • LC #2643 • Pattern: Row-wise Count

📝 The Problem

Return [rowIdx, count] of the row with the most 1s. Ties go to the smallest index.

Example: [[0,1],[1,0]] → [0, 1]

📚 Jargon Buster

Count per row
If rows are sorted, count = cols − LB(row, 1). If unsorted (general case), just iterate.
Tie-break
Use strict > when comparing, so the first max encountered wins.

🌟 In Layman's Terms

Count 1s in each row; track the row with the highest count, preferring earlier rows on ties.

⚡ The Aha Moment

If the binary matrix has each row sorted (0s then 1s), you can replace counting with a single lower bound per row.

🔧 Algorithm

  1. For each row: count ones (or LB(row, 1) for sorted).
  2. Track best (rowIdx, count) with strict greater comparison.

☕ Java Solution

public int[] rowAndMaximumOnes(int[][] mat) {
    int bestRow = 0, bestCount = 0;
    for (int r = 0; r < mat.length; r++) {
        int cnt = 0;
        for (int v : mat[r]) if (v == 1) cnt++;
        if (cnt > bestCount) { bestRow = r; bestCount = cnt; }
    }
    return new int[]{bestRow, bestCount};
}

⏳ Complexity

Time
O(m·n)
Space
O(1)

📈 2D Pattern

Per-Row Count: Simple sweep, but the sorted-row variant replaces counting with a single LB per row.
Key Insight: Strict > comparison gives free tie-break in favor of the first row.
