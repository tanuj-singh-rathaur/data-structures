P08 — Smallest Rectangle Enclosing Black Pixels

Hard • LC #302 • Pattern: Binary Search Each Side of the Bounding Box

📝 The Problem

Binary image (0/1) with all black pixels connected. Given any black pixel (x, y), find the area of the smallest axis-aligned rectangle enclosing all blacks.

📚 Jargon Buster

Connected blob
Reachability via 4-neighbor moves. We don't need to BFS — connectivity ensures the bounding rows/columns each contain at least one black.
Per-side BS
Top row: smallest r with any black in row r. Bottom: largest r. Left, right: same for columns. Four monotone predicates.

🌟 In Layman's Terms

The image is connected, so each border of the bounding box is a single boundary on a monotonic "any-black-in-this-row/column" predicate. Binary search each of the four edges.

⚡ The Aha Moment

"Does row r contain any black?" is a monotone predicate around the bounding row (true inside the band, false outside). Four binary searches give four edges.

🔧 Algorithm

  1. top = BS smallest r with any black in [0..x].
  2. bottom = BS largest r with any black in [x..rows−1].
  3. left, right: same on columns.
  4. area = (right − left + 1) · (bottom − top + 1).

☕ Java Solution (sketch)

public int minArea(char[][] image, int x, int y) {
    int rows = image.length, cols = image[0].length;
    int top = bs(image, 0, x, true, true);
    int bottom = bs(image, x, rows - 1, true, false);
    int left = bs(image, 0, y, false, true);
    int right = bs(image, y, cols - 1, false, false);
    return (bottom - top + 1) * (right - left + 1);
}
// bs walks a binary search where the predicate is "does row r (or col c) contain a '1'?"

⏳ Complexity

Time
O((m + n) log(m·n))
Space
O(1)

📈 2D Pattern

BS the Bounds: Four independent boundary searches replace an O(m·n) flood-fill.
Key Insight: Connectedness is what makes "any black in this row" a monotone predicate around the bounding row, enabling per-edge binary search.
