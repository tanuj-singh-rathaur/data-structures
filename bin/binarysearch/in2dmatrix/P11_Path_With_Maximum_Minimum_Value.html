P11 — Path With Maximum Minimum Value

Medium • LC #1102 • Pattern: Binary Search Threshold + BFS Reachability

📝 The Problem

4-direction grid traversal from (0,0) to (m−1,n−1). The score of a path is its minimum cell value. Return the maximum achievable score.

📚 Jargon Buster

Score = min on path
The smallest cell on the path determines the score. We want to maximize that smallest.
BS on threshold t
"Can we get from start to end using only cells with value ≥ t?" — monotonic in t. Smallest infeasible / largest feasible.
BFS check
For each candidate t, BFS using cells ≥ t.

🌟 In Layman's Terms

Binary search the bar height. For each bar, can you walk from start to end using only cells at or above it? Find the highest bar that still works.

⚡ The Aha Moment

"Bar reachable" is monotonic in t — easier bars stay reachable as bars get lower.

🔧 Algorithm

  1. lo = 0, hi = max cell value.
  2. While lo < hi: mid = (lo + hi + 1)/2 (upper-mid for "largest valid"). BFS using cells ≥ mid. If reachable: lo = mid. Else hi = mid − 1.

☕ Java Solution (sketch)

public int maximumMinimumPath(int[][] grid) {
    int lo = 0, hi = 0;
    for (int[] row : grid) for (int v : row) hi = Math.max(hi, v);
    while (lo < hi) {
        int mid = lo + (hi - lo + 1) / 2;
        if (canReach(grid, mid)) lo = mid;
        else                     hi = mid - 1;
    }
    return lo;
}
// canReach: BFS from (0,0) using only cells >= mid; return true if (m-1, n-1) hit.

⏳ Complexity

Time
O(m·n · log V)
Space
O(m·n)

📈 2D Pattern

BS Threshold + Reachability: Standard "binary search the answer on a grid" — pair BS with BFS / DFS / Union-Find.
Key Insight: Alternative: Dijkstra with max-heap on min-value, also O(mn log mn). BS-on-answer is cleaner when the threshold range is small.
