P02 — Minimum Days to Make m Bouquets

Medium • LC #1482 • Pattern: BS Day · Greedy Adjacent-Bloom Run Count

📝 The Problem

Each flower blooms on day bloomDay[i]. A bouquet needs k adjacent bloomed flowers. Min day to make m bouquets, or −1.

📚 Jargon Buster

Adjacent Run
A maximal contiguous block of flowers bloomed by day d. A run of length L contributes L/k bouquets.
Monotonicity
If day d works, every d' > d also works. Smallest feasible d is the BS answer.

🌟 In Layman's Terms

Pick a day d. Count adjacent bloomed flowers in groups of k; that's the bouquets you can make. Binary search the smallest d that yields ≥ m bouquets.

⚡ The Aha Moment

BS on day, not on flowers. Predicate runs in O(n) via a simple counter.

🔧 Algorithm

  1. If n < m*k return −1.
  2. lo = min(bloomDay), hi = max(bloomDay).
  3. While lo < hi: mid; sweep counting bouquets at day mid.
  4. If bouquets ≥ m: hi = mid. Else lo = mid + 1.

☕ Java Solution

public int minDays(int[] bloom, int m, int k) {
    long need = (long) m * k;
    if (need > bloom.length) return -1;
    int lo = Integer.MAX_VALUE, hi = Integer.MIN_VALUE;
    for (int b : bloom) { lo = Math.min(lo, b); hi = Math.max(hi, b); }
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (canMake(bloom, m, k, mid)) hi = mid;
        else                            lo = mid + 1;
    }
    return lo;
}
private boolean canMake(int[] b, int m, int k, int d) {
    int flowers = 0, bouquets = 0;
    for (int x : b) {
        if (x <= d) {
            flowers++;
            if (flowers == k) { bouquets++; flowers = 0; }
        } else flowers = 0;
    }
    return bouquets >= m;
}

⏳ Complexity

Time
O(n log(max−min))
Space
O(1)

📈 BS-on-Answers Pattern

BS Day + Greedy Run: When an inequality is feasible after some threshold and runs/groups can be counted greedily, BS the threshold.
Key Insight: Adjacency makes a sliding count enough; no DP needed.
