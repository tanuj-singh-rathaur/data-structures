P20 — Median of Two Sorted Arrays

Hard • LC #4 • Pattern: BS partition i in smaller array

📝 The Problem

Two sorted arrays nums1 (size m) and nums2 (size n). Return the median of the combined array in O(log(min(m, n))).

📚 Jargon Buster

Partition
Choose i in [0, m] and j = (m + n + 1)/2 − i in [0, n]. Combined left = nums1[0..i) ∪ nums2[0..j).
Valid Partition
max(left1, left2) ≤ min(right1, right2) — left half maxes ≤ right half mins.
Sentinels
−∞ for empty-left, +∞ for empty-right to handle boundary cases.

🌟 In Layman's Terms

Don't merge. Split both arrays into "left" and "right" halves with the right element counts so that the median can be read off the four boundary values.

⚡ The Aha Moment

Binary searching the partition index in the smaller array converges in O(log min(m, n)) — far better than the O(m + n) merge.

🔧 Algorithm

  1. Make nums1 the smaller. BS i in [0, m]; j = (m + n + 1)/2 − i.
  2. If L1 > R2: shrink hi. If L2 > R1: increase lo. Else partition valid.
  3. Odd total ⇒ max(L1, L2). Even ⇒ (max(L1, L2) + min(R1, R2)) / 2.0.

☕ Java Solution

public double findMedianSortedArrays(int[] a, int[] b) {
    if (a.length > b.length) return findMedianSortedArrays(b, a);
    int m = a.length, n = b.length, half = (m + n + 1) / 2;
    int lo = 0, hi = m;
    while (lo <= hi) {
        int i = lo + (hi - lo) / 2;
        int j = half - i;
        int L1 = i == 0 ? Integer.MIN_VALUE : a[i - 1];
        int R1 = i == m ? Integer.MAX_VALUE : a[i];
        int L2 = j == 0 ? Integer.MIN_VALUE : b[j - 1];
        int R2 = j == n ? Integer.MAX_VALUE : b[j];
        if (L1 <= R2 && L2 <= R1) {
            if (((m + n) & 1) == 1) return Math.max(L1, L2);
            return (Math.max(L1, L2) + Math.min(R1, R2)) / 2.0;
        } else if (L1 > R2) hi = i - 1;
        else                  lo = i + 1;
    }
    return 0.0;
}

⏳ Complexity

Time
O(log min(m, n))
Space
O(1)

📈 BS-on-Answers Pattern

BS the Index, Not the Value: Some problems search the partition position rather than the answer's numeric value. The structure is identical: monotone predicate, binary squeeze.
Key Insight: Always BS the smaller array — both bounds tighter and avoids out-of-range issues.
