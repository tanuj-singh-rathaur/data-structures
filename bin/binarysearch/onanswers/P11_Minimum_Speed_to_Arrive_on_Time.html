P11 — Minimum Speed to Arrive on Time

Medium • LC #1870 • Pattern: BS speed · ceil + fractional last leg

📝 The Problem

For each leg dist[i], the time is ceil(dist[i] / s) for all but the last leg, which is dist[last] / s (fractional). Min integer s such that total ≤ hour. Hour is given to 2 decimal places.

📚 Jargon Buster

Wait at station
You must wait at each non-last station for the next hour boundary, hence ceil.
Hour precision
Multiply by 100 to avoid floating point.

🌟 In Layman's Terms

Pick a speed. Compute total time using ceilings + last fractional. Binary search smallest feasible speed.

⚡ The Aha Moment

Use integer arithmetic with scaling instead of doubles to avoid precision bugs.

🔧 Algorithm

  1. If n − 1 ≥ hour ceil ⇒ impossible.
  2. BS speed in [1, 1e7]; predicate uses 100·hour for precision.

☕ Java Solution

public int minSpeedOnTime(int[] dist, double hour) {
    int n = dist.length;
    if (n - 1 >= hour) return -1;
    long h100 = Math.round(hour * 100);
    int lo = 1, hi = 10_000_000;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (timeAtSpeed100(dist, mid) <= h100) hi = mid;
        else                                    lo = mid + 1;
    }
    return lo;
}
private long timeAtSpeed100(int[] d, int s) {
    long t = 0;
    for (int i = 0; i < d.length - 1; i++) t += ((long)(d[i] + s - 1) / s) * 100;
    t += (long) d[d.length - 1] * 100 / s + ((long) d[d.length - 1] * 100 % s == 0 ? 0 : 1);
    return t;
}

⏳ Complexity

Time
O(n log 1e7)
Space
O(1)

📈 BS-on-Answers Pattern

Real Predicate via Integer Scale: When real numbers appear, scale up to avoid floating-point error.
Key Insight: A small twist (last-leg fractional) changes the predicate, not the BS skeleton.
