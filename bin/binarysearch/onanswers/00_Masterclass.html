Binary Search on Answers — Masterclass

Search for the optimal numeric answer by binary-searching the answer space and verifying via a monotone predicate.

📝 What Is Binary Search on Answers?

Instead of searching an array for a target, you search the range of possible answers. The key insight:

  • The answer is a number in some range [lo, hi].
  • A predicate check(x) exists such that if it's true for x, it's true for all x' "on one side" of x — i.e., the feasibility region is monotone.
  • You binary-search the answer space and converge on the boundary.

📚 Jargon Buster

Answer Space
The numeric range in which the optimal value lives, e.g. [1, max(arr)] or [min, sum].
Monotone Predicate
A check function such that if check(x) holds, check(x+1) also holds (or vice versa). This monotonicity is what makes binary search work.
Feasibility
"Can we achieve the goal at value x?" — typically encoded by a greedy or counting routine.
Minimize / Maximize
Two variants: min x s.t. check(x) (push hi=mid) vs. max x s.t. check(x) (push lo=mid+1).
Greedy Check
Most predicates simulate a greedy distribution / packing / placement at parameter x and count whether it meets the constraint.

🎯 When to use Binary Search on Answers

  • Problem asks "min / max value of X such that some count/feasibility holds."
  • Brute force would test every candidate answer ⇒ too slow.
  • The check at each candidate is fast (O(n) or O(n log n)).
  • Monotonicity is obvious: if a slower / smaller X works, a faster / larger X works too.

🏭 The 5 Sub-Patterns

1. Minimize X (rate / capacity)

Find smallest X s.t. work fits a constraint.

BS [1, max]; predicate: workNeeded(X) ≤ limit

Koko, Capacity-to-Ship, Smallest Divisor

2. Maximize X (gap / per-share)

Find largest X feasible — usually "best minimum among many."

BS [1, max]; predicate: greedy(X) ≥ required

Aggressive Cows, Magnetic Force, Candies to K

3. Minimize max-of-groups (partition)

Split array into k contiguous parts; minimize max part-sum.

BS [max(arr), sum(arr)]; predicate: greedy splits ≤ k

Allocate Pages, Painter's Partition, Split-Array, Ship-Packages

4. Real-valued / sqrt predicates

Answer is a real number or has a nonlinear predicate.

BS integer [1, hi]; predicate uses sqrt, ceil, fractional time

Nth Root, Min Speed on Time, Repair Cars

5. Partition / index binary search

BS the split index, not the value itself.

BS partition i; verify with O(1) comparison

Median of Two Sorted Arrays

⚙️ Universal Templates

MIN x s.t. check(x):

int lo = lowBound, hi = highBound;
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (check(mid)) hi = mid;       // mid feasible — try smaller
    else            lo = mid + 1;   // need larger
}
return lo;

MAX x s.t. check(x):

int lo = lowBound, hi = highBound;
while (lo < hi) {
    int mid = lo + (hi - lo + 1) / 2;   // upper mid (avoid infinite loop)
    if (check(mid)) lo = mid;           // mid feasible — try larger
    else            hi = mid - 1;
}
return lo;
