P05 — Allocate Minimum Number of Pages

Hard • Pattern: Partition Skeleton (same as Ship-Packages, Split-Array)

📝 The Problem

Books with page counts must be allocated to k students as contiguous ranges. Minimize the maximum pages any student must read.

📚 Jargon Buster

Contiguous Allocation
Each student gets a prefix-range. Order of books fixed.
Greedy Students
For a guessed limit L, scan books, opening a new student whenever adding the next book exceeds L.

🌟 In Layman's Terms

Guess L. Count how many students you'd need at limit L. Binary search smallest L with students ≤ k.

⚡ The Aha Moment

Identical algorithm to Capacity-To-Ship. Different problem skin, same mechanic.

🔧 Algorithm

  1. lo = max(books), hi = sum(books).
  2. If k > n return −1 (need more students than books).
  3. BS smallest L such that studentsNeeded(L) ≤ k.

☕ Java Solution

public int allocate(int[] books, int k) {
    if (k > books.length) return -1;
    int lo = 0, hi = 0;
    for (int b : books) { lo = Math.max(lo, b); hi += b; }
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (students(books, mid) <= k) hi = mid;
        else                            lo = mid + 1;
    }
    return lo;
}
private int students(int[] b, int limit) {
    int s = 1, cur = 0;
    for (int x : b) {
        if (cur + x > limit) { s++; cur = 0; }
        cur += x;
    }
    return s;
}

⏳ Complexity

Time
O(n log sum)
Space
O(1)
