P16 — Sum of Square Numbers

Medium • LC #633 • Pattern: Two Pointer or Binary Search

📝 The Problem

Given a non-negative integer c, return true if there exist non-negative a, b with a² + b² = c.

Example: c = 5 → true (1² + 2²)

📚 Jargon Buster

Two-pointer approach
Set a = 0, b = ⌊√c⌋. If a² + b² < c, a++. If > c, b--. If ==, return true.
Binary search approach
For each a in [0..√c], binary search for b such that b² = c − a². Slightly slower in big-O but conceptually clearer.
Overflow
Squares can exceed int range — use long for products.

🌟 In Layman's Terms

Try every a from 0 up to √c. For each, check whether c − a² is itself a perfect square. If yes, we've found our pair.

⚡ The Aha Moment

You don't need a hash set of all squares up to c. For each candidate a, the required b² is determined — just check if it's a perfect square.

🔧 Algorithm (Two-Pointer)

  1. a = 0, b = (long) Math.sqrt(c).
  2. While a ≤ b: compute s = a*a + b*b.
  3. If s == c → true. If s < c → a++. Else → b--.
  4. Return false.

☕ Java Solution

public boolean judgeSquareSum(int c) {
    long a = 0, b = (long) Math.sqrt(c);
    while (a <= b) {
        long s = a * a + b * b;
        if      (s == c) return true;
        else if (s < c)  a++;
        else             b--;
    }
    return false;
}

⏳ Complexity

Time
O(√c)
Space
O(1)

📈 Binary Search Pattern

Numeric / Math (Two-Pointer Variant): Two-pointer on a numeric range works the same way as on an array — converge from both ends based on a monotonic comparison.
Key Insight: Even when the problem doesn't mention "search," the underlying "find a + b = target" structure is the same converging-pointers pattern from sorted-array Two Sum.
