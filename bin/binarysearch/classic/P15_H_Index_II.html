P15 — H-Index II

Medium • LC #275 • Pattern: Binary Search a Predicate (n − i ≥ citations)

📝 The Problem

Citations are sorted ascending. The H-index is the maximum h such that h papers each have ≥ h citations. Find it in O(log n).

Example: citations = [0, 1, 3, 5, 6] → 3 (3 papers with ≥ 3 citations)

📚 Jargon Buster

H-index
Largest h where h papers each have ≥ h citations.
Predicate
For sorted citations, at index i there are n − i papers from i onwards. The condition citations[i] ≥ n − i means "those n−i papers each have ≥ n−i citations." Find the smallest such i.
Answer
If smallest such i is i*, the H-index is n − i*.

🌟 In Layman's Terms

Walk along the sorted citations. The papers from index i onward number n − i. If the citation at i is at least that big, you've found a working h. Find the smallest such i; the H-index is n − i.

⚡ The Aha Moment

"Citation at i ≥ remaining count" is a monotonic predicate. Binary search finds where false flips to true.

🔧 Algorithm

  1. L = 0, R = n. While L < R: mid; if citations[mid] ≥ n − mid: R = mid. Else L = mid + 1.
  2. Return n − L.

☕ Java Solution

public int hIndex(int[] citations) {
    int n = citations.length;
    int L = 0, R = n;
    while (L < R) {
        int mid = L + (R - L) / 2;
        if (citations[mid] >= n - mid) R = mid;
        else                            L = mid + 1;
    }
    return n - L;
}

⏳ Complexity

Time
O(log n)
Space
O(1)

📈 Binary Search Pattern

First-True Predicate: Once you spot a false-then-true predicate over a sorted index, the lower-bound template applies regardless of what the predicate "means."
Key Insight: The translation step ("smallest i with predicate true" → "answer = n − i") is the kind of reformulation that turns hard problems into one-liner templates.
