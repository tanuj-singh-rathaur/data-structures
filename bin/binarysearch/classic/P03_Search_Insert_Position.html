P03 — Search Insert Position

Easy • LC #35 • Pattern: Lower Bound (Insert Position)

📝 The Problem

Given a sorted array nums and a value target, return the index where it is, or the index where it should be inserted to keep the array sorted.

Example: nums = [1, 3, 5, 6], target = 5 → 2; target = 2 → 1

📚 Jargon Buster

Insert position
The leftmost index where placing the target preserves sorted order.
Lower bound
Smallest index i with nums[i] ≥ target. Identical to insert position.
Half-open [L, R)
R can equal n (insert at end). Loop ends with L == R at the insert position.

🌟 In Layman's Terms

Find the smallest index whose value is ≥ target. That's where the target slots in — whether it's already there or being inserted.

⚡ The Aha Moment

If you allow R = n (just past the end), the same algorithm naturally handles "target is bigger than everything" by returning n.

🔧 Algorithm

  1. L = 0, R = n. While L < R: mid = L + (R−L)/2.
  2. If nums[mid] ≥ target: R = mid. Else L = mid + 1.
  3. Return L.

☕ Java Solution

public int searchInsert(int[] nums, int target) {
    int L = 0, R = nums.length;
    while (L < R) {
        int mid = L + (R - L) / 2;
        if (nums[mid] >= target) R = mid;
        else                     L = mid + 1;
    }
    return L;
}

⏳ Complexity

Time
O(log n)
Space
O(1)
