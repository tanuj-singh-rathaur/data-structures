P07 — Find Duplicate Subtrees

Medium • LC #652

Java

// Post-order canonical serialization. HashMap<sig, count>; when count == 2, record node.
Map<String, Integer> cnt = new HashMap<>();
List<TreeNode> res = new ArrayList<>();
String sig(TreeNode n) {
    if (n == null) return "#";
    String s = n.val + "," + sig(n.left) + "," + sig(n.right);
    if (cnt.merge(s, 1, Integer::sum) == 2) res.add(n);
    return s;
}
Insight: Add when seeing the SECOND occurrence — not third — to avoid duplicates in the output.
