Medium • LC #331

Java

// Treat tokens as slots: root provides 1 slot; null consumes 1; non-null consumes 1 and adds 2.
int slots = 1;
for (String t : tokens) {
    if (slots == 0) return false;
    slots += t.equals("#") ? -1 : 1;  // -1 + 0 or -1 + 2
}
return slots == 0;
Insight: Slot counting is a clever O(n) substitute for actual tree construction.
