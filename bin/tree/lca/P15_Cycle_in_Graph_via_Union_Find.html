P15 — Redundant Connection (UF)

Medium • LC #684

Java

int[] p = new int[n+1]; for (int i=0;i<=n;i++) p[i]=i;
for (int[] e : edges) {
    int a = find(e[0]), b = find(e[1]);
    if (a == b) return e;        // cycle detected
    p[a] = b;
}
int find(int x) { return p[x]==x ? x : (p[x]=find(p[x])); }
Insight: Union-Find detects cycle creation in O(α(n)) per edge — perfect for tree-augmentation problems.
