P11 — Kth Ancestor of a Tree Node

Hard • LC #1483

Java

// Precompute up[v][k] = 2^k-th ancestor.
// getKthAncestor: walk bits of k; if set, jump via up[v][k].
int getKthAncestor(int node, int k) {
    for (int j = 0; j < LOG; j++) if (((k >> j) & 1) == 1) { node = up[node][j]; if (node == -1) return -1; }
    return node;
}
Insight: Just the "lift" step of binary-lifting LCA — no need to compare two nodes.
