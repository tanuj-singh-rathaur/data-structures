P10 — Binary Lifting LCA

Hard

Pattern

Preprocess up[u][k] = 2^k-th ancestor of u. Equalise depths via up jumps, then walk u and v together from highest k down.

Java (sketch)

int[][] up; int LOG;
// Preprocess in DFS: up[v][0] = parent[v]; up[v][k] = up[up[v][k-1]][k-1].
int lca(int u, int v) {
    if (depth[u] < depth[v]) { int t = u; u = v; v = t; }
    int diff = depth[u] - depth[v];
    for (int k = 0; k < LOG; k++) if (((diff >> k) & 1) == 1) u = up[u][k];
    if (u == v) return u;
    for (int k = LOG - 1; k >= 0; k--) if (up[u][k] != up[v][k]) { u = up[u][k]; v = up[v][k]; }
    return up[u][0];
}
Insight: O(n log n) preprocessing, O(log n) per query — essential for ≥ 10^5 queries.
