TreeDFS

Tree · DFS — Masterclass

Recursive walks through a tree. Three patterns: pre-order (process then recurse), in-order (left, process, right), post-order (recurse then combine).

Jargon

Pre-order
Visit root, recurse left, recurse right. Useful for building paths top-down.
In-order
Recurse left, visit root, recurse right. In a BST, produces sorted order.
Post-order
Recurse left, recurse right, combine. Computes any value that depends on children.
Global Best
A class-level variable updated during recursion when the "answer" includes the through-node case.
Sentinel Return
Special -1 to abort upstream (e.g., unbalanced tree).

Templates

// Post-order combine (max depth, diameter)
int dfs(TreeNode n) {
    if (n == null) return 0;
    int L = dfs(n.left), R = dfs(n.right);
    return combine(n, L, R);
}
// Pre-order accumulator (path sum, root-to-leaf numbers)
void dfs(TreeNode n, int acc) {
    if (n == null) return;
    int newAcc = update(acc, n.val);
    if (n.left == null && n.right == null) report(newAcc);
    dfs(n.left, newAcc); dfs(n.right, newAcc);
}
