P11 — Sum Root to Leaf Numbers

Medium • LC #129

Java

public int sumNumbers(TreeNode r) { return dfs(r, 0); }
int dfs(TreeNode n, int acc) {
    if (n==null) return 0;
    acc = acc * 10 + n.val;
    if (n.left==null && n.right==null) return acc;
    return dfs(n.left, acc) + dfs(n.right, acc);
}
Insight: Build the number left-to-right via *10+digit; sum at leaves.
