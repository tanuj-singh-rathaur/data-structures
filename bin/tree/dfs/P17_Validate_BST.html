P17 — Validate BST

Medium • LC #98

Java

public boolean isValidBST(TreeNode r) { return dfs(r, null, null); }
boolean dfs(TreeNode n, Integer lo, Integer hi) {
    if (n==null) return true;
    if (lo != null && n.val <= lo) return false;
    if (hi != null && n.val >= hi) return false;
    return dfs(n.left, lo, n.val) && dfs(n.right, n.val, hi);
}
Insight: Use (min, max) bounds — left subtree must be < node, right > node, recursively.
