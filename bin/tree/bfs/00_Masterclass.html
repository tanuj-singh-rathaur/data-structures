TreeBFS

Tree · BFS — Masterclass

Level-by-level traversal of trees using a queue. Solves shortest depth, level aggregations, and "rightmost / leftmost / max per level" problems uniformly.

Jargon

Level
Set of nodes at the same depth from root.
Queue (FIFO)
The data structure powering BFS. Enqueue children, dequeue current.
Size Snapshot
Record queue.size() before processing a level so you process exactly one level at a time.
Multi-source BFS
Initialise queue with all "starting" nodes; useful for "nearest gate" problems.
Sentinel
Insert null into the queue to mark level boundaries (alternative to size snapshot).

Template

Queue<TreeNode> q = new ArrayDeque<>();
q.offer(root);
while (!q.isEmpty()) {
    int sz = q.size();
    for (int i = 0; i < sz; i++) {
        TreeNode n = q.poll();
        // process n at this level
        if (n.left != null)  q.offer(n.left);
        if (n.right != null) q.offer(n.right);
    }
    // advance level
}
