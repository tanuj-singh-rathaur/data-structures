P16 — Sum of Left Leaves

Easy • LC #404

Java (DFS)

public int sumOfLeftLeaves(TreeNode root) {
    if (root == null) return 0;
    int left = (root.left != null && root.left.left == null && root.left.right == null) ? root.left.val : sumOfLeftLeaves(root.left);
    return left + sumOfLeftLeaves(root.right);
}
Insight: The "is left leaf" predicate goes on the LEFT child of root, not on root itself.
