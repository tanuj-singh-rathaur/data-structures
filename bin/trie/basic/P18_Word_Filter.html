P18 — Prefix and Suffix Search

Hard • LC #745

Pattern

// For each word w of length L: insert all "suffix#prefix" variants (L+1 variants).
// At each node store max index seen so far.
// f(prefix, suffix) = walk trie via "suffix#prefix" string; node.maxIndex.
Insight: Sentinel '#' between suffix and prefix joins two prefix searches into one trie walk.
