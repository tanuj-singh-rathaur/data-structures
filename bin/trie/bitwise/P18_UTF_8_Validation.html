P18 — UTF-8 Validation

Medium • LC #393

Java

int remaining = 0;
for (int b : data) {
    if (remaining == 0) {
        if      ((b >> 5) == 0b110)   remaining = 1;
        else if ((b >> 4) == 0b1110)  remaining = 2;
        else if ((b >> 3) == 0b11110) remaining = 3;
        else if ((b >> 7) != 0)       return false;
    } else {
        if ((b >> 6) != 0b10) return false;
        remaining--;
    }
}
return remaining == 0;
Insight: First byte's top bits encode the sequence length; each follower must start with 10.
