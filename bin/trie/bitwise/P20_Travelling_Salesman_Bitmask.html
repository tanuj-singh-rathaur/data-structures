P20 — Travelling Salesman (Bitmask DP)

Hard

Pattern

// dp[mask][i] = min cost visiting cities in mask, ending at i.
// Transition: for each j ∉ mask, dp[mask | (1<<j)][j] = min(dp[mask | (1<<j)][j], dp[mask][i] + d[i][j]).
// Answer: min over i of dp[(1<<n) - 1][i] + d[i][0].
// O(2ⁿ · n²) — only feasible for n ≤ 20.
Insight: Bitmask DP collapses the exponential TSP search to "best state for each (visited-set, current-city)."
