P09 — Cherry Pickup II

Hard • LC #1463

Pattern

// Two robots in same row r; state (r, c1, c2).
// Both move down to row r+1; each has 3 column choices ⇒ 9 transitions.
// If c1 == c2 ⇒ count cell once.
Insight: Robots move IN LOCK-STEP row by row ⇒ row is the natural DP axis; both column positions form the state.
