P08 — Cherry Pickup

Hard • LC #741

Pattern

// Two walkers both go from (0,0) to (n-1,n-1) — equivalent to round-trip.
// State (k, r1, r2) where k = steps; columns are c1 = k-r1, c2 = k-r2.
// If r1==r2 ⇒ don't double-count cell. Transition: 4 combos of moves.
Insight: Splitting one round trip into two synchronized forward walks reduces 4-D state to 3-D (k+r1+r2).
