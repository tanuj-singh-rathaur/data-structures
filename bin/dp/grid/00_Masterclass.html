26.2 DP Grid — Masterclass

Grid DP is just linear DP in two dimensions. State = "best answer ending at cell (i,j)"; transition usually depends on cell (i-1, j), (i, j-1), or diagonals. Two strings ⇒ dp[i][j] over prefixes (edit distance, LCS). A matrix ⇒ dp[i][j] over the cell itself. Often reducible to a rolling 1-D array for O(min(m,n)) space.

Jargon Buster

Top-left to bottom-right walk
Most grid DP iterates rows then cols; predecessors live above and to the left.
Bottom-right to top-left
For "min health" / "exit grid" problems, you DP backward — successors are below and to the right.
String-prefix DP
dp[i][j] = answer for first i chars of s1 vs first j chars of s2. Boundary row/col handle empty-prefix base cases.
Rolling array
When dp[i][*] only needs dp[i-1][*], reuse a 1-D array; iterate column index carefully (asc/desc).

Java — Path-Count Template

int[][] dp = new int[m][n];
for (int i = 0; i < m; i++) dp[i][0] = 1;
for (int j = 0; j < n; j++) dp[0][j] = 1;
for (int i = 1; i < m; i++)
    for (int j = 1; j < n; j++)
        dp[i][j] = dp[i-1][j] + dp[i][j-1];
return dp[m-1][n-1];

Java — Two-String Template (LCS)

int[][] dp = new int[m+1][n+1];
for (int i = 1; i <= m; i++)
    for (int j = 1; j <= n; j++)
        dp[i][j] = s1.charAt(i-1) == s2.charAt(j-1)
                 ? dp[i-1][j-1] + 1
                 : Math.max(dp[i-1][j], dp[i][j-1]);
return dp[m][n];
