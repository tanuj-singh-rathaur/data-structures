P16 — Minimum Falling Path Sum

Medium • LC #931

Java

for (int r = 1; r < n; r++)
  for (int c = 0; c < n; c++) {
      int up  = matrix[r-1][c];
      int ul  = c > 0     ? matrix[r-1][c-1] : Integer.MAX_VALUE;
      int ur  = c < n - 1 ? matrix[r-1][c+1] : Integer.MAX_VALUE;
      matrix[r][c] += Math.min(up, Math.min(ul, ur));
  }
int best = Integer.MAX_VALUE;
for (int c = 0; c < n; c++) best = Math.min(best, matrix[n-1][c]);
return best;
Insight: Each cell picks the cheapest of three "predecessors" in the row above — straight-up, diagonal-left, diagonal-right.
