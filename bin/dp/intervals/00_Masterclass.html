26.3 DP Intervals — Masterclass

Interval DP solves problems on contiguous ranges [i..j]. State = best answer on a sub-interval; transition splits at some pivot k (a "first move," a "last move," or a "merge point"). The defining loop is iterate by length, then by start, then by split — short intervals are computed first because long intervals depend on them.

Jargon Buster

Split DP
Pick a pivot k in (i..j) that divides the interval into two sub-intervals.
Length-first iteration
Fill dp for length 1, then 2, then 3 ... so when you compute dp[i][j] all sub-intervals are ready.
"Last move" framing
Instead of "what's the first move", ask "what's the LAST move you make on this interval?" — often gives a cleaner recurrence (Burst Balloons).
Minimax DP
Two players alternate. dp[i][j] = best score difference assuming the current player picks optimally; the next state flips sign.

Java — Generic Interval Template

int n = arr.length;
int[][] dp = new int[n][n];           // dp[i][j] over [i..j]
for (int len = 2; len <= n; len++) {
    for (int i = 0; i + len - 1 < n; i++) {
        int j = i + len - 1;
        dp[i][j] = INIT;
        for (int k = i; k < j; k++) {
            int cand = dp[i][k] + dp[k+1][j] + cost(i, k, j);
            dp[i][j] = Math.min(dp[i][j], cand);   // or max
        }
    }
}
return dp[0][n-1];

Java — "Last Move" Template (Burst Balloons)

// dp[i][j] = best result if (i..j) is the SET of remaining items;
// pivot k is the LAST item processed:
for (int len = 1; len <= n; len++)
    for (int i = 1; i + len - 1 <= n; i++) {
        int j = i + len - 1;
        for (int k = i; k <= j; k++)
            dp[i][j] = Math.max(dp[i][j],
