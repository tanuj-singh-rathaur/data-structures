P13 — Scramble String

Hard • LC #87

Pattern

// dp(i1, i2, len) = "s1[i1..i1+len) is a scramble of s2[i2..i2+len)".
// For each split k in (0, len):
//   no-swap : dp(i1, i2, k) AND dp(i1+k, i2+k, len-k)
//   swap    : dp(i1, i2+len-k, k) AND dp(i1+k, i2, len-k)
// Prune: char-frequency must match for both halves.
Insight: Every scramble is a tree of splits; for each split the two children either keep order or swap — try both.
