P06 — Target Sum

Medium • LC #494

Pattern

// Split nums into P (signs +) and N (signs −) with sum(P) − sum(N) = target.
// sum(P) = (S + target)/2 where S = total sum.
// Count # subsets summing to (S + target)/2 using 0/1 count-DP:
//   for x in nums: for t from T down to x: dp[t] += dp[t - x].
Insight: A signed-sum problem becomes an unsigned subset-sum-count once you isolate "items assigned a + sign."
