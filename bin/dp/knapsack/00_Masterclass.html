26.4 DP Knapsack — Masterclass

Knapsack DP handles "pick a subset of items under a capacity constraint to optimise something." Two flavours dominate: 0/1 (each item used at most once — iterate capacity descending) and unbounded (each item reusable — iterate capacity ascending). Most counting / subset-sum / target-sum problems reduce to one of these two shapes.

Jargon Buster

0/1 Knapsack
Item-at-most-once. To prevent reuse in 1-D DP, iterate capacity DESCENDING.
Unbounded Knapsack
Reusable items. Iterate capacity ASCENDING so a new pick can stack on prior picks.
Bounded by 2 resources
Capacity is a tuple (e.g., m zeros and n ones); state becomes dp[m][n].
Subset-sum trick
"Target Sum" / "Last Stone Weight II" / "Equal Subset" all reduce to: "is there a subset summing to T?"
Loop order = combinations vs permutations
Items-outer, amount-inner ⇒ combinations. Amount-outer, items-inner ⇒ permutations.

Java — 0/1 Knapsack Template

int[] dp = new int[W + 1];
for (int i = 0; i < n; i++) {
    for (int w = W; w >= weight[i]; w--) {   // descending
        dp[w] = Math.max(dp[w], dp[w - weight[i]] + value[i]);
    }
}
return dp[W];

Java — Unbounded Template (Coin Change II)

int[] dp = new int[amount + 1];
dp[0] = 1;
for (int c : coins)
    for (int a = c; a <= amount; a++)        // ascending
        dp[a] += dp[a - c];
return dp[amount];
