P19 — Min Refueling Stops

Hard • LC #871

Pattern (DP form)

// dp[t] = max distance reachable using EXACTLY t refuelings.
// For each station (pos, fuel) in order:
//   for t from done desc to 0:
//     if dp[t] >= pos: dp[t+1] = max(dp[t+1], dp[t] + fuel);
// Smallest t with dp[t] >= target is the answer.
Insight: Inverting the question — "what's the FURTHEST you can go with t stops?" — turns it into a classic 0/1 DP indexed by stop-count.
