P07 — Maximum Product Subarray

Medium • LC #152

Java

int hi = nums[0], lo = nums[0], best = nums[0];
for (int i = 1; i < nums.length; i++) {
    int x = nums[i];
    int a = hi * x, b = lo * x;
    hi = Math.max(x, Math.max(a, b));
    lo = Math.min(x, Math.min(a, b));
    best = Math.max(best, hi);
}
Insight: Negatives flip max ↔ min. Track BOTH the current max and the current min so a future negative can turn the min back into a max.
