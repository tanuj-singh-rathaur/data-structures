26.1 DP Linear — Masterclass

Linear DP solves problems on a 1-D structure (array, string, sequence of decisions). State = "best answer using first i elements"; transition = "what choice do I make at position i?" Once you find the recurrence, the implementation is usually just one for-loop.

Jargon Buster

Optimal substructure
Best answer at i built from best answers at smaller indices. Required for DP to work.
Overlapping subproblems
Same subproblem solved many times in naïve recursion. Memoise it.
Top-down (memo)
Recursion + cache. Easy to write; sometimes deeper than stack allows.
Bottom-up (table)
Fill dp[] from base case upward. Usually iterative; avoids recursion limits.
Rolling array
If dp[i] only needs dp[i-1] and dp[i-2], store just two scalars. O(1) space.
Kadane
Linear DP for max-subarray: cur = max(x, cur + x).

Java — Generic 1-D Template

int n = nums.length;
int[] dp = new int[n + 1];
dp[0] = BASE;                          // base case
for (int i = 1; i <= n; i++) {
    dp[i] = combine(dp[i-1], dp[i-2], ..., nums[i-1]);
}
return dp[n];

Java — Rolling Array Template

int prev2 = base0, prev1 = base1;
for (int i = 2; i <= n; i++) {
    int cur = combine(prev1, prev2, nums[i-1]);
    prev2 = prev1; prev1 = cur;
}
return prev1;
