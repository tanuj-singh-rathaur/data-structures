P08 — Longest Increasing Subsequence

Medium • LC #300

Java (Patience sort, O(n log n))

List<Integer> tails = new ArrayList<>();
for (int x : nums) {
    int lo = 0, hi = tails.size();
    while (lo < hi) { int m = (lo + hi) >>> 1; if (tails.get(m) < x) lo = m + 1; else hi = m; }
    if (lo == tails.size()) tails.add(x); else tails.set(lo, x);
}
return tails.size();
Insight: tails[i] = smallest possible last value of any increasing subseq of length i+1. Binary search to replace.
