P09 — Word Break

Medium • LC #139

Java

Set<String> dict = new HashSet<>(wordDict);
boolean[] dp = new boolean[s.length() + 1];
dp[0] = true;
for (int i = 1; i <= s.length(); i++)
    for (int j = 0; j < i; j++)
        if (dp[j] && dict.contains(s.substring(j, i))) { dp[i] = true; break; }
return dp[s.length()];
Insight: dp[i] = "prefix length i is segmentable." Try every split point j and look up the suffix in the dictionary.
