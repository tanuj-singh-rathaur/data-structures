P10 — Decode Ways

Medium • LC #91

Java

int n = s.length();
int[] dp = new int[n + 1]; dp[0] = 1;
for (int i = 1; i <= n; i++) {
    if (s.charAt(i-1) != '0')              dp[i] += dp[i-1];
    if (i > 1) {
        int two = Integer.parseInt(s.substring(i-2, i));
        if (two >= 10 && two <= 26)        dp[i] += dp[i-2];
    }
}
return dp[n];
Insight: '0' is a trap — it can never stand alone, only as part of 10 or 20.
