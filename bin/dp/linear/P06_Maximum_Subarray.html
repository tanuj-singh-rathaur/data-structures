P06 — Maximum Subarray (Kadane)

Medium • LC #53

Java

int cur = nums[0], best = nums[0];
for (int i = 1; i < nums.length; i++) {
    cur = Math.max(nums[i], cur + nums[i]);
    best = Math.max(best, cur);
}
return best;
Insight: If the prefix sum drops below 0 it can only hurt; start fresh at nums[i].
