P13 — Sudoku Solver

Hard • LC #37 • Pattern: Cell-by-Cell Try 1..9 + Row/Col/Box Bitmasks

📝 The Problem

Fill a 9×9 Sudoku grid so every row, column, and 3×3 box contains digits 1-9 exactly once.

📚 Jargon Buster

Box Index
(r / 3) · 3 + (c / 3) — maps each cell to one of the 9 boxes.
Bitmask
rowMask[r] bit d is set iff digit d already exists in row r. Same for col and box.

🌟 In Layman's Terms

Find the next empty cell. Try each digit 1-9 that doesn't collide with row/col/box. Set it, recurse. If unsolvable, undo and try the next.

⚡ The Aha Moment

Bitmasks keep "available digits" check O(1). Smarter solvers pick the cell with fewest options first (MRV heuristic).

🔧 Algorithm

  1. Initialise row/col/box masks from given digits.
  2. solve(): find next empty cell; for each available digit set it, recurse; on failure unset.

☕ Java Solution

private int[] rows = new int[9], cols = new int[9], boxes = new int[9];
public void solveSudoku(char[][] b) {
    for (int r = 0; r < 9; r++) for (int c = 0; c < 9; c++)
        if (b[r][c] != '.') flip(r, c, b[r][c] - '0');
    solve(b, 0, 0);
}
private boolean solve(char[][] b, int r, int c) {
    if (r == 9) return true;
    int nr = c == 8 ? r + 1 : r, nc = c == 8 ? 0 : c + 1;
    if (b[r][c] != '.') return solve(b, nr, nc);
    int used = rows[r] | cols[c] | boxes[(r / 3) * 3 + c / 3];
    for (int d = 1; d <= 9; d++) {
        if ((used & (1 << d)) != 0) continue;
        b[r][c] = (char) ('0' + d); flip(r, c, d);
        if (solve(b, nr, nc)) return true;
        b[r][c] = '.'; flip(r, c, d);
    }
    return false;
}
private void flip(int r, int c, int d) {
    int bit = 1 << d;
    rows[r] ^= bit; cols[c] ^= bit; boxes[(r / 3) * 3 + c / 3] ^= bit;
}

⏳ Complexity

Time
O(9^k) k = empties, heavy pruning
Space
O(81)

📈 Choice Pattern

Mask-Based Constraint Search: Bitmasks for "what's used" turn O(9) lookups into O(1) bit ops.
Key Insight: Use bit 1..9 (not 0..8) so digits map naturally to their bit positions.
