P19 — Non-decreasing Subsequences

Medium • LC #491 • Pattern: HashSet Per Level (Can't Sort)

📝 The Problem

Return all non-decreasing subsequences of nums with length ≥ 2. No duplicates.

📚 Jargon Buster

Can't Sort
Sorting would destroy the original order, making non-decreasing meaningless. Use a per-level HashSet instead of the sort-and-skip pattern.

🌟 In Layman's Terms

From start index, walk forward. Only pick j if nums[j] ≥ path's last value. Use a HashSet within the call to skip duplicate VALUES at this depth.

⚡ The Aha Moment

The seen set is created INSIDE the dfs call — its scope is the current parent, so siblings see it but children don't.

🔧 Algorithm

  1. dfs(start, path): if path.size ≥ 2 ⇒ record.
  2. seen = new HashSet<Integer>().
  3. For j = start..n−1: if (!path.isEmpty && nums[j] < last) continue; if seen.contains(nums[j]) continue; seen.add; pick; recurse(j + 1); unpick.

☕ Java Solution

public List<List<Integer>> findSubsequences(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    dfs(nums, 0, new ArrayList<>(), res);
    return res;
}
private void dfs(int[] nums, int start, List<Integer> path, List<List<Integer>> res) {
    if (path.size() >= 2) res.add(new ArrayList<>(path));
    Set<Integer> seen = new HashSet<>();
    for (int j = start; j < nums.length; j++) {
        if (!path.isEmpty() && nums[j] < path.get(path.size() - 1)) continue;
        if (!seen.add(nums[j])) continue;
        path.add(nums[j]);
        dfs(nums, j + 1, path, res);
        path.remove(path.size() - 1);
    }
}

⏳ Complexity

Time
O(2ⁿ · n)
Space
O(n)

📈 Choice Pattern

Dynamic Dedup Set: When sort+skip isn't available (order-dependent), a per-call HashSet provides equivalent dedup.
Key Insight: The set lives in the call frame — that's what limits its dedup scope to siblings only.
