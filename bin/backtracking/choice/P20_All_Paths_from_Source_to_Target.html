P20 — All Paths from Source to Target

Medium • LC #797 • Pattern: DFS Backtracking on Directed Acyclic Graph

📝 The Problem

Given a DAG with n nodes (0..n−1) as adjacency list, return all paths from 0 to n−1.

📚 Jargon Buster

DAG
Directed Acyclic Graph — no cycles, so no visited[] array is needed.
Backtrack on Path
Push the next node, recurse, pop. Classic include-then-undo.

🌟 In Layman's Terms

Start at node 0 with path [0]. For each neighbour, push it onto the path and recurse. When you reach n−1, record. Pop back to try the next neighbour.

⚡ The Aha Moment

No cycle ⇒ no visited[] — each call's path is its own visited record by construction.

🔧 Algorithm

  1. dfs(node, path): if node == n−1 ⇒ record.
  2. For each nxt in graph[node]: path.add(nxt); dfs(nxt); path.removeLast.

☕ Java Solution

public List<List<Integer>> allPathsSourceTarget(int[][] graph) {
    List<List<Integer>> res = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    path.add(0);
    dfs(graph, 0, path, res);
    return res;
}
private void dfs(int[][] g, int node, List<Integer> path, List<List<Integer>> res) {
    if (node == g.length - 1) { res.add(new ArrayList<>(path)); return; }
    for (int nxt : g[node]) {
        path.add(nxt);
        dfs(g, nxt, path, res);
        path.remove(path.size() - 1);
    }
}

⏳ Complexity

Time
O(2ⁿ · n) worst
Space
O(n)

📈 Choice Pattern

DFS Backtracking on Graph: Same skeleton as tree-style choice, with the adjacency list providing the choices at each node.
Key Insight: For cyclic graphs you'd need a visited set; here the DAG guarantee removes that overhead.
