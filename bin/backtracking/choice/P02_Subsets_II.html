P02 — Subsets II

Medium • LC #90 • Pattern: Sort + Skip Duplicates at Same Level

📝 The Problem

Return all subsets of nums (may contain duplicates) — no duplicate subsets.

📚 Jargon Buster

Same-Level Dedup
Among siblings (calls from the same parent), skip values equal to the previously chosen one.

🌟 In Layman's Terms

Sort first. Use the "pick from start index" template. In the for-loop, if the current value equals the one immediately before AND we're not at the loop's first iteration, skip it.

⚡ The Aha Moment

The check is "j > start" not "j > 0" — we only block duplicates among SIBLINGS, not in the path.

🔧 Algorithm

  1. Sort nums.
  2. dfs(start, path): result.add(path snapshot); loop j from start; skip if j > start && nums[j] == nums[j−1].

☕ Java Solution

public List<List<Integer>> subsetsWithDup(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> res = new ArrayList<>();
    dfs(nums, 0, new ArrayList<>(), res);
    return res;
}
private void dfs(int[] nums, int start, List<Integer> path, List<List<Integer>> res) {
    res.add(new ArrayList<>(path));
    for (int j = start; j < nums.length; j++) {
        if (j > start && nums[j] == nums[j - 1]) continue;
        path.add(nums[j]);
        dfs(nums, j + 1, path, res);
        path.remove(path.size() - 1);
    }
}

⏳ Complexity

Time
O(2ⁿ · n)
Space
O(n)

📈 Choice Pattern

Sort + Skip: The canonical dedup trick. Recognise it across Subsets II, Combination Sum II, Permutations II.
Key Insight: Sorting first is what makes "compare to previous" a valid dedup test.
