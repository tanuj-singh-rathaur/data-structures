P09 — Palindrome Partitioning

Medium • LC #131 • Pattern: Cut After Each Palindromic Prefix

📝 The Problem

Partition s such that every piece is a palindrome; return all such partitions.

📚 Jargon Buster

Palindromic Prefix
A prefix of the remaining suffix that reads the same forwards/backwards.
DP Precompute
Optional: precompute is_palindrome[i][j] in O(n²) for O(1) checks.

🌟 In Layman's Terms

Starting at index i, try every end-index e. If s[i..e] is a palindrome, add it and recurse from e + 1.

⚡ The Aha Moment

This is the "split a range" pattern (sub-pattern 4) — choose where to cut, recurse on the rest.

🔧 Algorithm

  1. dfs(start, path): if start == n ⇒ record path.
  2. For end = start..n−1: if isPalin(s, start, end): path.add; dfs(end + 1); path.pop.

☕ Java Solution

public List<List<String>> partition(String s) {
    List<List<String>> res = new ArrayList<>();
    dfs(s, 0, new ArrayList<>(), res);
    return res;
}
private void dfs(String s, int start, List<String> path, List<List<String>> res) {
    if (start == s.length()) { res.add(new ArrayList<>(path)); return; }
    for (int end = start; end < s.length(); end++) {
        if (isPalin(s, start, end)) {
            path.add(s.substring(start, end + 1));
            dfs(s, end + 1, path, res);
            path.remove(path.size() - 1);
        }
    }
}
private boolean isPalin(String s, int i, int j) {
    while (i < j) if (s.charAt(i++) != s.charAt(j--)) return false;
    return true;
}

⏳ Complexity

Time
O(n · 2ⁿ)
Space
O(n)

📈 Choice Pattern

Cut-and-Recurse: "Split a range into valid pieces" is one of the four main Choice templates.
Key Insight: Precomputing palindrome flags (O(n²) DP) eliminates redundant palindrome checks for large inputs.
