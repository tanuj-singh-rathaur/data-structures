P18 — Confusing Number II

Hard • LC #1088 • Branch valid digits {0,1,6,8,9}

Problem

Count numbers in [1, N] that look different when rotated 180°.

Pattern

Build numbers using only rotatable digits {0,1,6,8,9}. For each, check if its rotation ≠ itself.

Java

private int[] digits = {0, 1, 6, 8, 9};
private int count;
public int confusingNumberII(int n) {
    count = 0;
    dfs(0L, n);
    return count;
}
void dfs(long num, int n) {
    if (rotate(num) != num) count++;
    for (int d : digits) {
        long next = num * 10 + d;
        if (next == 0 || next > n) continue;
        dfs(next, n);
    }
}
long rotate(long x) {
    long r = 0;
    while (x > 0) {
        int d = (int) (x % 10);
        if (d == 6) d = 9; else if (d == 9) d = 6;
        r = r * 10 + d; x /= 10;
    }
    return r;
}

Complexity

O(5^log₁₀ N).

Insight: Skip num == 0 in recursion (no leading-zero numbers); skip x % 10 == 0 in rotation contexts as needed.
