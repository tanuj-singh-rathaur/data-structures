P16 — 24 Game

Hard • LC #679 • Pick pair + operator

Problem

Can you combine 4 cards with +, -, ×, / to make 24?

Pattern

Pick any two numbers, apply each operator, replace the pair with the result. Recurse on shrunken list. Stop when list has size 1 and equals 24 (within epsilon for division).

Java

public boolean judgePoint24(int[] cards) {
    List<Double> nums = new ArrayList<>();
    for (int x : cards) nums.add((double) x);
    return solve(nums);
}
boolean solve(List<Double> nums) {
    if (nums.size() == 1) return Math.abs(nums.get(0) - 24) < 1e-6;
    for (int i = 0; i < nums.size(); i++)
        for (int j = 0; j < nums.size(); j++) {
            if (i == j) continue;
            List<Double> rest = new ArrayList<>();
            for (int k = 0; k < nums.size(); k++) if (k != i && k != j) rest.add(nums.get(k));
            double a = nums.get(i), b = nums.get(j);
            for (double res : new double[]{a + b, a - b, a * b, b == 0 ? Double.NaN : a / b}) {
                if (Double.isNaN(res)) continue;
                rest.add(res);
                if (solve(rest)) return true;
                rest.remove(rest.size() - 1);
            }
        }
    return false;
}

Complexity

O(constant) — exhaustive but finite.

Insight: Replacing-pair-with-result reduces problem size by 1 each level.
