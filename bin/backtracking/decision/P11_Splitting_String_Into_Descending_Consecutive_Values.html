P11 — Splitting a String Into Descending Consecutive Values

Medium • LC #1849 • Split + constraint = prev - 1

Problem

Can s be split into 2+ numeric pieces each exactly one less than the previous?

Pattern

Decide the FIRST number's length; the rest is deterministic (each subsequent must equal prev - 1). Use long to handle overflow.

Java

public boolean splitString(String s) {
    int n = s.length();
    for (int len = 1; len < n; len++) {
        long first = Long.parseLong(s.substring(0, len));
        if (canFollow(s, len, first)) return true;
        if (first > 1e10) break;
    }
    return false;
}
boolean canFollow(String s, int start, long prev) {
    if (start == s.length()) return true;
    for (int len = 1; start + len <= s.length(); len++) {
        long cur = Long.parseLong(s.substring(start, start + len));
        if (cur == prev - 1) {
            if (canFollow(s, start + len, cur)) return true;
        } else if (cur > prev - 1) break;
    }
    return false;
}

Complexity

O(n²) split decisions.

Insight: Once the first number is fixed, the sequence is determined — just verify.
