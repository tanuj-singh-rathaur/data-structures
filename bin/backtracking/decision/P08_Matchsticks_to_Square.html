P08 — Matchsticks to Square

Medium • LC #473 • Bucket assignment with k = 4

Problem

Use all matchsticks to form 4 equal sides of a square.

Pattern

Special case of Partition K Equal Subsets with k = 4. Same algorithm.

Java

public boolean makesquare(int[] m) {
    int s = 0; for (int x : m) s += x;
    if (s % 4 != 0) return false;
    int side = s / 4;
    Arrays.sort(m);
    if (m[m.length - 1] > side) return false;
    return dfs(m, m.length - 1, new int[4], side);
}
boolean dfs(int[] m, int i, int[] buckets, int side) {
    if (i < 0) return true;
    for (int b = 0; b < 4; b++) {
        if (buckets[b] + m[i] > side) continue;
        buckets[b] += m[i];
        if (dfs(m, i - 1, buckets, side)) return true;
        buckets[b] -= m[i];
        if (buckets[b] == 0) break;
    }
    return false;
}

Complexity

O(4ⁿ) worst.

Insight: Sort descending so big sticks fill buckets fast and conflicts surface early.
