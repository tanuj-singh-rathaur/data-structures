Backtracking · Decision — Masterclass

At each step you face a small number of decisions ("take or skip", "insert + or - or ×", "assign to bucket 1..k"). Recurse on each, backtrack the side-effect.

📝 What Is Decision-Based Backtracking?

Decision backtracking is the cousin of Choice. Where Choice enumerates arrangements (subsets, permutations), Decision answers "at this step, what action do I take?" — keep/skip a character, insert an operator, place an item into a bucket. Often produces YES/NO or count answers rather than full enumeration.

📚 Jargon Buster

Decision Tree
Each node represents a state; each edge is one possible action. Leaves are terminal states (valid solution, dead-end, or quota met).
Memoise
Cache the answer for a given state (often (index, remaining-budget) or (index, bitmask-of-used)) to avoid recomputation.
Action vs Element
Choice loops over "which element"; Decision loops over "which action to take with this element."
Bitmask State
Compact integer encoding "which subset is used so far" — perfect for memoisation.
Prune by Overflow
Cut branches once the partial answer exceeds the budget (sum > target, bucket > side, etc.).

🎯 When to use Decision Backtracking

  • "Can the input be split / parsed / formed into …?" YES/NO answers.
  • "How many ways to decode / partition / combine?" count answers.
  • "What is the minimum / maximum value achievable?" optimisation answers.
  • Bucket / assignment problems where each item picks one of k slots.

🏭 The 5 Sub-Patterns

1. Take/Skip per Character

At index i: include vs skip.

dfs(i+1, with) ; dfs(i+1, without)

Decode Ways, Remove Invalid Parentheses

2. Split Prefix Recursively

Try each prefix length; recurse on suffix.

for len: if valid(s[i..i+len]) dfs(i+len)

Word Break II, Concatenated Words, Additive Number, Descending Split, Number of Atoms, Equal Parts

3. Bucket Assignment

Place each item into one of k buckets.

for b in buckets: if fits, push, recurse

Partition K Equal Sum, Matchsticks Square

4. Insert Operator / Branch

Between symbols decide which operator.

for op in {+, -, *, none}: recurse

Expression Add Operators, 24 Game

5. Bind / Assign + Memo

Bind a key to a value; memoise state.

memo[bitmask][index]

Word Pattern II, Stickers to Spell Word, Max Length Unique Concat, Optimal Account Balancing, Squareful Arrays, Confusing Number II, Letter Combinations, Word Search

⚙️ Universal Templates

Take/Skip:

int dfs(int i) {
    if (i == n) return baseAnswer;
    int take = canTake(i) ? dfs(i + 1) : 0;
    int skip = dfs(i + 1);
    return combine(take, skip);
}

Split Prefix:

boolean dfs(int i) {
    if (i == n) return true;
    for (int j = i + 1; j <= n; j++) {
        if (validPiece(s, i, j) && dfs(j)) return true;
    }
    return false;
}

Bucket Assignment:

boolean dfs(int idx, int[] buckets, int target) {
    if (idx == nums.length) return allEqual(buckets, target);
    for (int b = 0; b < buckets.length; b++) {
        if (buckets[b] + nums[idx] > target) continue;
        buckets[b] += nums[idx];
        if (dfs(idx + 1, buckets, target)) return true;
        buckets[b] -= nums[idx];
        if (buckets[b] == 0) break;       // symmetric prune
    }
    return false;
}
