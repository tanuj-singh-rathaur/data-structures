P19 — Split a String Into the Max Number of Unique Substrings

Medium • LC #1593 • Split + used-set

Problem

Maximise the number of unique substrings in a partition of s.

Pattern

Split prefix backtrack; reject pieces already in the used-set. Track best so far.

Java

public int maxUniqueSplit(String s) {
    return dfs(s, 0, new HashSet<>());
}
int dfs(String s, int i, Set<String> used) {
    if (i == s.length()) return used.size();
    int best = 0;
    for (int j = i + 1; j <= s.length(); j++) {
        String w = s.substring(i, j);
        if (used.contains(w)) continue;
        used.add(w);
        best = Math.max(best, dfs(s, j, used));
        used.remove(w);
    }
    return best;
}

Complexity

O(2ⁿ · n) worst.

Insight: No memo needed at this size; the used-set state varies too much to compress.
