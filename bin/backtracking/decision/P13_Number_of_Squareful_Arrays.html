P13 — Number of Squareful Arrays

Hard • LC #996 • Permute + adjacency = perfect square

Problem

Count permutations of nums where every adjacent pair sums to a perfect square.

Pattern

Permutation backtrack with constraint: nums[next] + nums[last] must be square. Sort + skip-dup-at-level for duplicates.

Java

private int count;
public int numSquarefulPerms(int[] nums) {
    Arrays.sort(nums); count = 0;
    dfs(nums, new boolean[nums.length], new ArrayList<>());
    return count;
}
void dfs(int[] nums, boolean[] used, List<Integer> path) {
    if (path.size() == nums.length) { count++; return; }
    for (int j = 0; j < nums.length; j++) {
        if (used[j]) continue;
        if (j > 0 && nums[j] == nums[j - 1] && !used[j - 1]) continue;
        if (!path.isEmpty() && !isSquare(path.get(path.size() - 1) + nums[j])) continue;
        used[j] = true; path.add(nums[j]);
        dfs(nums, used, path);
        used[j] = false; path.remove(path.size() - 1);
    }
}
boolean isSquare(int x) { int r = (int) Math.sqrt(x); return r * r == x; }

Complexity

O(n!) with heavy adjacency pruning.

Insight: Constraint check at each branch site eliminates entire subtrees early.
