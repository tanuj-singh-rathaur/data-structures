P17 — Generate Maze (DFS Carve)

Medium • Procedural generation

Pattern

Start with all walls. From a random cell, shuffle 4 directions; jump 2 cells if neighbour is wall-status, knock down intermediate wall, recurse. Produces a perfect maze (one path between any two cells).

Java (sketch)

void carve(int[][] m, int r, int c, Random rnd) {
    int[][] dirs = {{0,1},{1,0},{0,-1},{-1,0}};
    shuffle(dirs, rnd);
    for (int[] d : dirs) {
        int nr = r + d[0]*2, nc = c + d[1]*2;
        if (nr>=0 && nr<m.length && nc>=0 && nc<m[0].length && m[nr][nc] == 1) {
            m[r + d[0]][c + d[1]] = 0;
            m[nr][nc] = 0;
            carve(m, nr, nc, rnd);
        }
    }
}
Insight: Jump by 2 to keep walls thick enough for paths; randomised order makes each maze unique.
