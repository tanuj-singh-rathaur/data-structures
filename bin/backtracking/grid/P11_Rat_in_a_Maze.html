P11 — Rat in a Maze

Medium • Classic • Path enumeration with D/L/R/U

Pattern

From (0,0) try moves in lex order (D, L, R, U) so the output paths come out sorted. Record path string; restore on backtrack.

Java

char[] moves = {'D','L','R','U'};
int[] dr = {1,0,0,-1}, dc = {0,-1,1,0};
public List<String> findPath(int[][] m) {
    int n = m.length;
    List<String> res = new ArrayList<>();
    if (m[0][0] == 0 || m[n-1][n-1] == 0) return res;
    dfs(m, 0, 0, new StringBuilder(), res);
    return res;
}
void dfs(int[][] m, int r, int c, StringBuilder p, List<String> res) {
    int n = m.length;
    if (r == n-1 && c == n-1) { res.add(p.toString()); return; }
    m[r][c] = 0;
    for (int k = 0; k < 4; k++) {
        int nr = r + dr[k], nc = c + dc[k];
        if (nr>=0 && nr<n && nc>=0 && nc<n && m[nr][nc] == 1) {
            p.append(moves[k]); dfs(m, nr, nc, p, res); p.deleteCharAt(p.length()-1);
        }
    }
    m[r][c] = 1;
}
Insight: Direction order D-L-R-U keeps results lex-sorted without post-sorting.
