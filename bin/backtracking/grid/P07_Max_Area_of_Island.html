P07 — Max Area of Island

Medium • LC #695 • Flood fill returning size

Pattern

Same as Number of Islands but DFS returns the area; track max across calls.

Java

public int maxAreaOfIsland(int[][] g) {
    int best = 0;
    for (int r=0;r<g.length;r++) for (int c=0;c<g[0].length;c++)
        if (g[r][c]==1) best = Math.max(best, area(g, r, c));
    return best;
}
int area(int[][] g, int r, int c) {
    if (r<0||c<0||r>=g.length||c>=g[0].length||g[r][c]!=1) return 0;
    g[r][c]=0;
    return 1 + area(g,r+1,c) + area(g,r-1,c) + area(g,r,c+1) + area(g,r,c-1);
}
Insight: Returning the sum recursively is the cleanest way to total connected sizes.
