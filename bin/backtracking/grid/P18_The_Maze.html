P18 — The Maze (Ball Slides Until Wall)

Medium • LC #490 • Slide-to-wall BFS/DFS

Pattern

From each visited "rest" cell, try each direction; slide until hitting a wall or edge; that landing cell is the next node. Only mark "rest" cells visited, not intermediate.

Java

public boolean hasPath(int[][] m, int[] start, int[] dest) {
    boolean[][] vis = new boolean[m.length][m[0].length];
    return dfs(m, start[0], start[1], dest, vis);
}
boolean dfs(int[][] m, int r, int c, int[] dest, boolean[][] vis) {
    if (vis[r][c]) return false;
    if (r == dest[0] && c == dest[1]) return true;
    vis[r][c] = true;
    int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
    for (int[] d : dirs) {
        int nr = r, nc = c;
        while (nr+d[0]>=0 && nr+d[0]<m.length && nc+d[1]>=0 && nc+d[1]<m[0].length && m[nr+d[0]][nc+d[1]] == 0) {
            nr += d[0]; nc += d[1];
        }
        if (dfs(m, nr, nc, dest, vis)) return true;
    }
    return false;
}
Insight: Sliding turns continuous motion into a discrete graph of "stop points."
