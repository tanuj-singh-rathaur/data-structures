P15 — Cherry Pickup

Hard • LC #741 • Two simultaneous walks

Pattern

Round-trip = two walks both going only D/R, same step k. State = (k, r1, r2); c1 = k-r1, c2 = k-r2. Memoise. If r1==r2, count cell once.

Java

public int cherryPickup(int[][] g) {
    int n = g.length;
    Integer[][][] memo = new Integer[n][n][n];
    return Math.max(0, dfs(g, 0, 0, 0, memo, n));
}
int dfs(int[][] g, int k, int r1, int r2, Integer[][][] m, int n) {
    int c1 = k - r1, c2 = k - r2;
    if (r1>=n||r2>=n||c1>=n||c2>=n||g[r1][c1]==-1||g[r2][c2]==-1) return Integer.MIN_VALUE;
    if (r1==n-1 && c1==n-1) return g[r1][c1];
    if (m[k][r1][r2] != null) return m[k][r1][r2];
    int val = g[r1][c1] + (r1==r2 ? 0 : g[r2][c2]);
    int best = Math.max(Math.max(dfs(g,k+1,r1,r2,m,n), dfs(g,k+1,r1+1,r2,m,n)), Math.max(dfs(g,k+1,r1,r2+1,m,n), dfs(g,k+1,r1+1,r2+1,m,n)));
    return m[k][r1][r2] = best == Integer.MIN_VALUE ? best : val + best;
}
Insight: Two simultaneous walks ≥ round-trip because both can independently choose the best path.
