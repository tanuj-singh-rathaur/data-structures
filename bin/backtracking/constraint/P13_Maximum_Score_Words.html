P13 — Maximum Score Words Formed by Letters

Hard • LC #1255 • Subset with inventory

Pattern

For each subset of words check letter inventory ≤ available; track max score. Brute-force subsets feasible because |words| ≤ 14 ⇒ 16K subsets.

Java

public int maxScoreWords(String[] words, char[] letters, int[] score) {
    int[] inv = new int[26]; for (char c : letters) inv[c-'a']++;
    return dfs(words, 0, inv, score);
}
int dfs(String[] w, int i, int[] inv, int[] sc) {
    if (i == w.length) return 0;
    int skip = dfs(w, i+1, inv, sc);
    int gain = 0; boolean ok = true;
    int[] used = new int[26];
    for (char c : w[i].toCharArray()) { used[c-'a']++; gain += sc[c-'a']; if (used[c-'a'] > inv[c-'a']) ok = false; }
    if (!ok) return skip;
    for (int k=0;k<26;k++) inv[k] -= used[k];
    int take = gain + dfs(w, i+1, inv, sc);
    for (int k=0;k<26;k++) inv[k] += used[k];
    return Math.max(skip, take);
}
Insight: Inventory is shared mutable state — restore on backtrack.
