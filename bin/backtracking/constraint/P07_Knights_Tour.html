P07 — Knight's Tour

Hard • Visit every cell once via knight moves

Pattern

From (0,0) try the 8 knight moves. Mark visited; if all n² cells reached, success. Warnsdorff's heuristic (move to the square with fewest onward options) makes this practical for n ≥ 5.

Java

int[] dr = {2,2,-2,-2,1,1,-1,-1}, dc = {1,-1,1,-1,2,-2,2,-2};
boolean dfs(int[][] b, int r, int c, int step, int n) {
    b[r][c] = step;
    if (step == n*n - 1) return true;
    for (int d = 0; d < 8; d++) {
        int nr=r+dr[d], nc=c+dc[d];
        if (nr>=0 && nr<n && nc>=0 && nc<n && b[nr][nc]==-1)
            if (dfs(b, nr, nc, step+1, n)) return true;
    }
    b[r][c] = -1;
    return false;
}
Insight: Without Warnsdorff's heuristic, n ≥ 7 explodes; with it, polynomial in practice.
