P19 — Closest Subsequence Sum

Hard • LC #1755 • Meet-in-the-middle

Pattern

n up to 40 ⇒ 2⁴⁰ too big. Split into halves, enumerate all 2ⁿ/² subset sums for each. Sort second half; for each sum from first, binary-search the closest complement.

Java

public int minAbsDifference(int[] nums, int goal) {
    int n = nums.length, h = n / 2;
    int[] L = subsetSums(nums, 0, h);
    int[] R = subsetSums(nums, h, n);
    Arrays.sort(R);
    int best = Integer.MAX_VALUE;
    for (int x : L) {
        int need = goal - x;
        int idx = lowerBound(R, need);
        if (idx < R.length) best = Math.min(best, Math.abs(R[idx] - need));
        if (idx > 0) best = Math.min(best, Math.abs(R[idx-1] - need));
    }
    return best;
}
int[] subsetSums(int[] a, int from, int to) {
    int len = to - from;
    int[] sums = new int[1 << len];
    for (int m = 0; m < (1<<len); m++)
        for (int i=0;i<len;i++) if ((m>>i & 1)==1) sums[m] += a[from+i];
    return sums;
}
Insight: Meet-in-the-middle reduces 2⁴⁰ to 2 × 2²⁰ + sort.
