P01 — Partition to K Equal Sum Subsets

Medium • LC #698 • Bucket assignment

Pattern

Sum % k == 0 and max ≤ target. Sort descending; assign each number to one of k buckets, skipping equal-and-empty siblings for symmetry pruning.

Java

boolean dfs(int[] a, int i, int[] b, int t) {
    if (i < 0) return true;
    for (int k=0;k<b.length;k++) {
        if (b[k]+a[i]>t) continue;
        if (k>0 && b[k]==b[k-1]) continue;
        b[k]+=a[i];
        if (dfs(a,i-1,b,t)) return true;
        b[k]-=a[i];
        if (b[k]==0) break;
    }
    return false;
}
Insight: The "empty bucket break" prevents exponential blowup of equivalent permutations.
