P09 — Smallest Sufficient Team

Hard • LC #1125 • Bitmask cover

Pattern

Encode each person as a skill bitmask. DP over "skills covered" bitmask: dp[mask] = min team to cover mask. For each person, dp[mask | personMask] candidate updates.

Java

public int[] smallestSufficientTeam(String[] req, List<List<String>> people) {
    Map<String,Integer> idx = new HashMap<>();
    for (int i=0;i<req.length;i++) idx.put(req[i], i);
    int n = req.length;
    int[] pm = new int[people.size()];
    for (int i=0;i<people.size();i++) for (String s: people.get(i)) if (idx.containsKey(s)) pm[i] |= 1<<idx.get(s);
    long[] dp = new long[1<<n];
    Arrays.fill(dp,(long)1e18); dp[0] = 0;
    long[] parent = new long[1<<n];
    for (int mask=0;mask<(1<<n);mask++) if (dp[mask]<1e18)
        for (int p=0;p<pm.length;p++) {
            long next = dp[mask] | (1L << p);
            int nm = mask | pm[p];
            if (Long.bitCount(next) < Long.bitCount(dp[nm])) { dp[nm] = next; }
        }
    long res = dp[(1<<n)-1];
    int sz = Long.bitCount(res); int[] ans = new int[sz]; int k=0;
    for (int p=0;p<64;p++) if ((res>>p & 1) == 1) ans[k++] = p;
    return ans;
}
Insight: Represent the chosen team as a bitmask of people indices — comparison by popcount.
