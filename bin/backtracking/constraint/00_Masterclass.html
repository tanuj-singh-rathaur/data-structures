Backtracking · Constraint — Masterclass

Hard constraints prune most of the search tree. Track conflict sets, propagate as you go, and abort branches as soon as any constraint fails.

📝 What Is Constraint-Based Backtracking?

A specialised flavour of backtracking where each placement / assignment must respect a hard rule. The data structures (row/col/box bitmasks, color sets, used inventory) are designed for O(1) conflict checks so most of the tree is pruned away.

📚 Jargon Buster

Constraint Set
Auxiliary data structure (HashSet, bitmask, count array) tracking which values/positions are taken.
Constraint Propagation
Updating conflict sets each time you make a choice; revert on backtrack.
MRV Heuristic
"Most Restricted Variable" first — pick the cell with fewest legal options to prune fast.
Symmetry Prune
Skip equivalent siblings (empty buckets, equal previous values).
Hard vs Soft Constraint
Hard = must hold; soft = preference. Backtracking handles hard ones; optimisation needs branch-and-bound.

🎯 When to use Constraint Backtracking

  • Puzzle solving with rigid rules (Sudoku, N-Queens, Cryptarithmetic).
  • Assignment problems where each item must satisfy compatibility.
  • Resource-limited placement (matchsticks, hats, words from letters).
  • Bitmask state spaces where conflict checks reduce to AND tests.

🏭 The 5 Sub-Patterns

1. Place per Row/Column

One queen per row; check column + diagonals.

N-Queens, N-Queens II

2. Grid Fill with Masks

Bitmask row/col/box; try digits 1-9.

Sudoku Solver, Crossword, Magic Square

3. Bucket Assign

Place each item into one of k buckets.

Partition K Subsets, Min Incompatibility, Hats

4. Bitmask Cover State

State = bits of "what's already covered".

Sufficient Team, Score Words, Valid Words Puzzle, Wear Hats

5. Path / Tour with Validity

Walk a graph/grid respecting move rules.

Knight's Tour, Android Unlock, Closest Subseq Sum, Restore Array, Beautiful Partitions, Tiling Rectangle, M-Coloring, Compatibility, Verbal Arithmetic

⚙️ Universal Template

boolean dfs(state) {
    if (complete(state)) return true;
    for (Choice c : optionsAt(state)) {
        if (!feasible(state, c)) continue;          // hard constraint
        apply(state, c);
        if (dfs(state)) return true;
        undo(state, c);
    }
    return false;
}
