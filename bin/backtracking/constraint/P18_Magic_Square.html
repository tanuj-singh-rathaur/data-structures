P18 — Magic Square

Medium • Classic puzzle

Pattern

Fill an n×n grid with 1..n² such that all rows, cols, both diagonals sum to n(n²+1)/2. Used[] tracks placed numbers; check completed row/col/diag sums on the fly.

Java (3×3 sketch)

int n = 3, target = 15;
boolean[] used = new boolean[10];
int[][] g = new int[n][n];
boolean solve(int idx) {
    if (idx == n*n) return verify(g, target);
    int r = idx/n, c = idx%n;
    for (int v = 1; v <= n*n; v++) {
        if (used[v]) continue;
        g[r][c] = v; used[v] = true;
        if (partialOk(g, r, c, target) && solve(idx+1)) return true;
        used[v] = false;
    }
    return false;
}
Insight: Check row sum only when row is full; same for cols/diagonals. Early pruning when a partial row exceeds target.
