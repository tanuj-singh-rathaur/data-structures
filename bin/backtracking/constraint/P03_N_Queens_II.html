P03 — N-Queens II

Hard • LC #52 • Count only

Pattern

Same as N-Queens but only count valid placements. Bitmask version is faster (no HashSet overhead).

Java (bitmask)

private int count;
public int totalNQueens(int n) {
    count = 0; dfs(n, 0, 0, 0, 0);
    return count;
}
void dfs(int n, int r, int c, int d, int a) {
    if (r==n) { count++; return; }
    int avail = ((1<<n)-1) & ~(c | d | a);
    while (avail!=0) {
        int pick = avail & -avail;
        dfs(n, r+1, c|pick, (d|pick)<<1, (a|pick)>>1);
        avail &= avail-1;
    }
}
Insight: Shift diag masks by ±1 between rows; iterate set bits via x & -x.
