P20 — Number of Beautiful Partitions

Hard • LC #2478 • DP with split constraints

Pattern

Each piece must start with a prime digit, end with non-prime, length ≥ minLength. dp[i][k] = ways to partition s[i..] into k more pieces.

Java

private final int MOD = 1_000_000_007;
private int n, minL;
private String s;
private Integer[][] memo;
public int beautifulPartitions(String s, int k, int minLength) {
    this.s = s; this.n = s.length(); this.minL = minLength;
    if (!isPrime(s.charAt(0)) || isPrime(s.charAt(n-1))) return 0;
    memo = new Integer[n + 1][k + 1];
    return dfs(0, k);
}
int dfs(int i, int k) {
    if (k == 0) return i == n ? 1 : 0;
    if (n - i < k * minL) return 0;
    if (memo[i][k] != null) return memo[i][k];
    long res = 0;
    for (int j = i + minL; j <= n - (k - 1) * minL; j++) {
        if (j < n && isPrime(s.charAt(j))) {
            if (!isPrime(s.charAt(j-1))) res = (res + dfs(j, k-1)) % MOD;
        } else if (j == n && !isPrime(s.charAt(n-1)) && k == 1) res = (res + 1) % MOD;
    }
    return memo[i][k] = (int) res;
}
boolean isPrime(char c) { return c=='2'||c=='3'||c=='5'||c=='7'; }
Insight: Boundary "prev is non-prime, current is prime" defines the only legal split point.
