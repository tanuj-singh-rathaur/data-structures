P18 — Count Number of Nice Subarrays

Medium • LC #1248 • Pattern: exactly(K) = atMost(K) − atMost(K−1)

📝 The Problem

A “nice” subarray contains exactly K odd numbers. Count nice subarrays in nums.

Example: nums = [1, 1, 2, 1, 1], K = 3 → 2

📚 Jargon Buster

Nice subarray
Contains exactly K odd numbers; evens are “free” padding.
Replace odd with 1
Mental trick: treat odd as 1 and even as 0. The problem becomes “count subarrays whose sum = K” — identical to P19.
Exactly-K trick
Same as P13: exactly(K) = atMost(K) − atMost(K−1).

🌟 In Layman's Terms

Imagine writing 1 for every odd number and 0 for every even. Now you're counting subarrays summing to exactly K. Use the exactly-K trick: count subarrays with sum ≤ K and subtract those with sum ≤ K−1.

⚡ The Aha Moment

The same exactly-K subtraction trick works for any “exactly K of property P” problem — not just distinct counts. Sum-of-indicator counters fit too.

🔧 Algorithm

  1. Helper atMostK(nums, K): standard sliding window counting odds; while oddCount > K shrink L.
  2. Return atMostK(K) − atMostK(K − 1).

☕ Java Solution

public int numberOfSubarrays(int[] nums, int K) {
    return atMostK(nums, K) - atMostK(nums, K - 1);
}
private int atMostK(int[] nums, int K) {
    int L = 0, oddCount = 0, total = 0;
    for (int R = 0; R < nums.length; R++) {
        if (nums[R] % 2 == 1) oddCount++;
        while (oddCount > K) {
            if (nums[L++] % 2 == 1) oddCount--;
        }
        total += R - L + 1;
    }
    return total;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Sliding Window Pattern

Exactly-K Trick: Generalizes to any "count subarrays where indicator-sum = K." The atMost helper changes only in what it counts (distinct, sum, odd count, etc.).
Key Insight: “Exactly = atMost(K) − atMost(K−1)” is one of the most reusable identities in sliding window problems. Memorize it.
