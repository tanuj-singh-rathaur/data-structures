P14 — House Robber II

Medium • LC #213 • Pattern: House Robber on a Circle

📝 The Problem

Same as House Robber but the houses are arranged in a circle — first and last are adjacent. Return max robbed.

Example: [2, 3, 2] → 3 (you can't take both index 0 and index 2)

📚 Jargon Buster

Circular constraint
House 0 and house n−1 are now neighbors. You cannot rob both.
Two cases
Either skip house 0 (rob from nums[1..n−1]), or skip house n−1 (rob from nums[0..n−2]). Take the max of the two.
Single-house edge case
If n == 1, just return nums[0].

🌟 In Layman's Terms

The first and last houses can't both be robbed. So either exclude the first or exclude the last — whichever gives more. On each excluded version, run the linear House Robber.

⚡ The Aha Moment

A circular constraint of "first ↔ last conflict" splits cleanly into two linear sub-problems. Run House Robber twice; take the max.

🔧 Algorithm

  1. If n == 1: return nums[0].
  2. Helper rob1(l, r): linear House Robber on the slice.
  3. Return max(rob1(0, n−2), rob1(1, n−1)).

☕ Java Solution

public int rob(int[] nums) {
    int n = nums.length;
    if (n == 1) return nums[0];
    return Math.max(robRange(nums, 0, n - 2), robRange(nums, 1, n - 1));
}
private int robRange(int[] nums, int l, int r) {
    int prev2 = 0, prev1 = 0;
    for (int i = l; i <= r; i++) {
        int cur = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Kadane Pattern

Linear Twice on Circular Problem: Same idea as Circular Kadane (P03) — split the cyclic constraint into two linear cases.
Key Insight: "First and last can't both be picked" = "either exclude first or exclude last." Two linear DPs cover both worlds. The cyclic structure dissolves.
