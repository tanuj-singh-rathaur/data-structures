P13 — House Robber

Medium • LC #198 • Pattern: Take/Skip DP (No Adjacent)

📝 The Problem

Each house has some money. You can't rob two adjacent houses. Return the maximum money you can rob.

Example: [2, 7, 9, 3, 1] → 12 (rob 2, 9, 1)

📚 Jargon Buster

Take vs Skip
At each house: skip it (carry the prior best) or take it + best from two houses ago. Whichever's larger.
Two scalars enough
The recurrence dp[i] = max(dp[i−1], dp[i−2] + nums[i]) only looks back two steps — rolling two variables works.
Why this is "Kadane-like"
A scalar-based DP that sweeps left-to-right keeping rolling state. Same family.

🌟 In Layman's Terms

At each house, you have a choice: rob it (and add it to your loot from two houses back) or skip it (and keep your loot from the previous house). Take whichever's bigger.

⚡ The Aha Moment

Each house only cares about the best totals from the last two houses. Two scalars roll the entire DP.

🔧 Algorithm

  1. Initialize prev2 = 0 (two before), prev1 = 0 (immediately previous).
  2. For each x: cur = max(prev1, prev2 + x); shift: prev2 = prev1; prev1 = cur.
  3. Return prev1.

☕ Java Solution

public int rob(int[] nums) {
    int prev2 = 0, prev1 = 0;
    for (int x : nums) {
        int cur = Math.max(prev1, prev2 + x);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Kadane Pattern

Take/Skip DP: The classic constrained-selection DP. Two scalars track everything; the recurrence only looks two steps back.
Key Insight: "No two adjacent" creates a take/skip choice. The recurrence depends only on the last two states, so the whole DP collapses to two variables.
