P17 — Gas Station

Medium • LC #134 • Pattern: Kadane-Style Greedy Restart

📝 The Problem

Given gas and cost arrays (circular), find the starting station from which you can complete the circuit. Return the index, or −1 if impossible.

Example: gas = [1,2,3,4,5], cost = [3,4,5,1,2] → 3

📚 Jargon Buster

diff[i] = gas[i] − cost[i]
Net fuel gained or lost moving from station i to i+1.
Total possible iff total ≥ 0
If the sum of all diffs is negative, no start works. Otherwise exactly one start does.
Greedy restart
Walk diffs; whenever the running tank goes negative, no starting point in [start..i] works. Reset start to i + 1.

🌟 In Layman's Terms

Walk around once. Track a running fuel tank. Every time the tank goes below zero, you can't start from anywhere you've tried so far — reset and start trying from the next station. If total fuel-vs-cost balance is non-negative, the last reset point is your answer.

⚡ The Aha Moment

If your tank goes negative at index i, no station in [start..i] could have worked. (Any earlier candidate would have had ≥ fuel and still failed.) So restart at i+1 — never look back.

🔧 Algorithm

  1. Compute totalDiff; if < 0, return −1.
  2. Walk: keep tank running. If tank < 0, set start = i + 1; tank = 0.
  3. Return start.

☕ Java Solution

public int canCompleteCircuit(int[] gas, int[] cost) {
    int totalDiff = 0, tank = 0, start = 0;
    for (int i = 0; i < gas.length; i++) {
        int diff = gas[i] - cost[i];
        totalDiff += diff;
        tank += diff;
        if (tank < 0) { start = i + 1; tank = 0; }
    }
    return totalDiff >= 0 ? start : -1;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Kadane Pattern

Greedy Restart: Same restart logic as vanilla Kadane — abandon the current run the moment it goes negative, and re-anchor at the next index.
Key Insight: Once your tank drops below zero at index i, all candidate starts in [start..i] are equally doomed. Restarting at i + 1 doesn't miss any solution. That's the same logic Kadane uses to abandon negative running sums.
