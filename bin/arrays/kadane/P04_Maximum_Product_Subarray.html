P04 — Maximum Product Subarray

Medium • LeetCode #152 • Pattern: Track Both Min and Max

📝 The Problem

Find the contiguous subarray within nums with the largest product. Return that product.

Example: [2, 3, −2, 4] → 6 (from [2, 3])

Tricky example: [−2, 3, −4] → 24 (multiplying all three)

📚 Jargon Buster

Why product is harder than sum
For sums, “more negative” is always worse. For products, multiplying by a negative flips the sign — what was very small (negative) becomes very large (positive). So you can't just track the max.
curMax / curMin
Two running values: the best (largest positive) and worst (most negative) product ending at the current index.
Three candidates per step
At each new index i, the new curMax/curMin could come from: (1) nums[i] alone (restart), (2) curMax × nums[i], (3) curMin × nums[i]. Take min and max of these three.
Zeros
Multiplying by zero resets both states to 0. The next non-zero element re-seeds from itself.

🌟 In Layman's Terms

Walk along the array tracking two things: the largest product you can make ending here, AND the smallest (most-negative) one. Why both? Because the smallest can suddenly become the largest after multiplying by a negative. Each step, the new curMax/curMin comes from the three candidates: current value alone, value times old max, value times old min.

⚡ The Aha Moment

A “huge negative” is a future asset. If we throw it away because it's not the current max, we lose the chance to multiply two negatives into a big positive. So we keep both.

🔧 Algorithm

  1. Initialize curMax = curMin = best = nums[0].
  2. For each i from 1:
    • Compute candidates a = nums[i], b = curMax × nums[i], c = curMin × nums[i].
    • Update curMax = max(a, b, c) and curMin = min(a, b, c) — both from the old values, so use locals.
    • best = max(best, curMax).

☕ Java Solution

public int maxProduct(int[] nums) {
    int curMax = nums[0], curMin = nums[0], best = nums[0];
    for (int i = 1; i < nums.length; i++) {
        int a = nums[i];
        int b = curMax * a;
        int c = curMin * a;
        curMax = Math.max(a, Math.max(b, c));
        curMin = Math.min(a, Math.min(b, c));
        best = Math.max(best, curMax);
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Kadane Pattern

Two-State Kadane: When the metric isn't monotone under the update rule (like product flipping signs), one running state is too few. Track both extremes and let them swap as needed.
Key Insight: Two negatives multiply to a positive. So the “worst” running product is an option that pays off later — you must carry it forward, not discard it.
