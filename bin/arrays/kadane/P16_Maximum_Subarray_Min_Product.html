P16 — Maximum Subarray Min-Product

Medium • LC #1856 • Pattern: Monotonic Stack + Prefix Sums

📝 The Problem

The min-product of a subarray is min(subarray) · sum(subarray). Return the maximum min-product over all subarrays, mod 10⁹ + 7.

Example: [1, 2, 3, 2] → 14 (subarray [2, 3, 2] → 2 × 7 = 14)

📚 Jargon Buster

Min-product
The minimum value of a subarray times its sum. Maximized when sum is huge AND min is large.
"i as the min" framing
For each index i, find the widest subarray where nums[i] is the min. That width is bounded by the previous-smaller index on the left and the next-smaller on the right.
Monotonic stack
An increasing stack lets you compute previous-smaller and next-smaller for every index in O(n).
Prefix sum lookup
Once you know the widest range, the subarray sum is P[right] − P[left + 1].

🌟 In Layman's Terms

For each element, find the largest subarray where it's the smallest value. Multiply that subarray's sum by this minimum element. Take the max over all elements.

⚡ The Aha Moment

The candidate maximum always has some element acting as the minimum. So fix the min, then find the widest subarray it dominates. Mono stack + prefix sums solves both in one pass.

🔧 Algorithm

  1. Build prefix sums.
  2. For each i: use a monotonic stack to find previous smaller index l and next smaller index r. The widest subarray where i is min is (l+1..r−1).
  3. Candidate = nums[i] · (P[r] − P[l + 1]); track max.

☕ Java Solution

public int maxSumMinProduct(int[] nums) {
    int n = nums.length;
    long MOD = 1_000_000_007L;
    long[] P = new long[n + 1];
    for (int i = 0; i < n; i++) P[i + 1] = P[i] + nums[i];
    int[] left = new int[n], right = new int[n];
    Deque<Integer> st = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        while (!st.isEmpty() && nums[st.peek()] >= nums[i]) st.pop();
        left[i] = st.isEmpty() ? -1 : st.peek();
        st.push(i);
    }
    st.clear();
    for (int i = n - 1; i >= 0; i--) {
        while (!st.isEmpty() && nums[st.peek()] >= nums[i]) st.pop();
        right[i] = st.isEmpty() ? n : st.peek();
        st.push(i);
    }
    long best = 0;
    for (int i = 0; i < n; i++) {
        long sum = P[right[i]] - P[left[i] + 1];
        best = Math.max(best, sum * nums[i]);
    }
    return (int) (best % MOD);
}
