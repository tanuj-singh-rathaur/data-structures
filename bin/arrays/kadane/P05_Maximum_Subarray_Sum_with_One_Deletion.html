P05 — Maximum Subarray Sum with One Deletion

Medium • LeetCode #1186 • Pattern: Two-State DP (No-Skip / Skipped)

📝 The Problem

Given an array arr, you may delete at most one element. Return the maximum possible sum of a non-empty contiguous subarray (after the optional deletion).

Example: arr = [1, −2, 0, 3] → 4 (delete −2 → subarray [1, 0, 3] sums to 4)

📚 Jargon Buster

At most one deletion
You're allowed zero or one removal — either case is valid. The answer is the max over both.
Two states per index
noDel[i] = best subarray ending at i that hasn't used its delete. del[i] = best subarray ending at i that has used its delete.
Transition rule
noDel[i] = max(arr[i], noDel[i−1] + arr[i]) — classic Kadane.
del[i] = max(noDel[i−1], del[i−1] + arr[i]) — either delete arr[i] now (drop to noDel[i−1]) or extend an already-deleted run.
Answer
Max over all i of max(noDel[i], del[i]).

🌟 In Layman's Terms

Think of it as carrying two parallel tallies at each index. Tally A is “best run if I haven't deleted anything yet.” Tally B is “best run if I've already used my one deletion.” Each step you update both. The deletion is implicit: deleting arr[i] means you continue B from yesterday's A.

⚡ The Aha Moment

You don't need to try every possible deletion explicitly. Two parallel DP states — one before deletion, one after — capture everything. The transition into “deleted” mode happens when you skip the current element.

📺 Visual Walkthrough

i=3
noDel = max(3, 0+3=3) = 3 del = max(noDel_prev=0, del_prev+3=1+3=4) = 4
best = 4 ✓ Answer: 4 (subarray [1, 0, 3] with −2 deleted)

🔧 Algorithm

  1. Initialize noDel = arr[0], del = 0 (or use sentinel), best = arr[0].
  2. For each i from 1:
    • newDel = max(noDel, del + arr[i])
    • noDel = max(arr[i], noDel + arr[i])
    • del = newDel
    • best = max(best, noDel, del)

☕ Java Solution

public int maximumSum(int[] arr) {
    int noDel = arr[0];     // Kadane without deletion
    int del   = 0;          // Kadane after using one deletion
    int best  = arr[0];
    for (int i = 1; i < arr.length; i++) {
        int newDel = Math.max(noDel, del + arr[i]);  // delete arr[i] or extend
        noDel = Math.max(arr[i], noDel + arr[i]);
        del = newDel;
        best = Math.max(best, Math.max(noDel, del));
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Kadane Pattern

Two-State Kadane (No-Skip / Skipped): When the problem allows “up to one X,” encode it as two parallel DP states — one before using the freebie, one after. Transition between them when the freebie is used.
Key Insight: “At most one deletion” isn't a search over n possible deletions — it's a single binary state (used / not used) tracked alongside the normal Kadane.
