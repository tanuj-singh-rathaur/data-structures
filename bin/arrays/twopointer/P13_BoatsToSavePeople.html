P13 — Boats to Save People

Medium  •  LeetCode #881  •  Pattern: Opposite Ends

📝 The Problem

Each boat can carry at most 2 people with a total weight ≤ limit. Given a people array (weights), return the minimum number of boats required. Every person must be in a boat.

Example: [3,2,2,1], limit=3 → 3

🌟 In Layman's Terms

Sort by weight. Always put the heaviest person in a boat. Then check if the lightest person can share. If they can, pair them (both pointers move). If not, the heavy person sails alone (only right pointer moves). Either way, one boat is used per iteration.

⚡ The Aha Moment

Greedy + two pointer: always place the heaviest person. Then greedily try to pair with the lightest. This greedy choice is optimal — if the lightest can't pair with the heaviest, they can't pair with anyone heavier.

🔧 Algorithm (Step by Step)

  1. Sort people.
  2. Set left=0, right=n-1, boats=0.
  3. While left <= right: if people[left]+people[right] <= limit, pair them: left++. Always: right--, boats++.

☕ Java Solution

public int numRescueBoats(int[] people, int limit) {
    Arrays.sort(people);
    int left = 0, right = people.length - 1, boats = 0;
    while (left <= right) {
        if (people[left] + people[right] <= limit) left++;  // pair!
        right--;   // heaviest always gets a boat
        boats++;
    }
    return boats;
}

Time

📈 Two Pointer Pattern

Two Pointer Pattern: Greedy + opposite-end two-pointer. The sort + greedy pairing guarantees minimum boats. Notice: right-- happens unconditionally every iteration.
Key Insight: Heaviest person always gets a boat. Try to pair with lightest. If not, heaviest goes alone.
