P19 — Shortest Unsorted Continuous Subarray

Medium  •  LeetCode #581  •  Pattern: Opposite Ends

📝 The Problem

Given an integer array nums, find the length of the shortest subarray that, if sorted, makes the whole array sorted.

Example: [2,6,4,8,10,9,15] → 5 (sort [6,4,8,10,9] → entire array sorted)

🌟 In Layman's Terms

Find where the array 'breaks' from the left and from the right. From the left, scan with a running max — whenever a number is smaller than the running max, it's out of place (mark as the right boundary). From the right, scan with a running min — whenever a number is larger than the running min, it's out of place (mark as the left boundary). The distance between these two boundaries is the answer.

⚡ The Aha Moment

Two passes (or conceptually two pointers) from opposite ends using a running max/min. The 'broken' region is defined by the last position that violated the sorted order from each side.

📺 Visual Walkthrough

Two-pass scan  |  array=[2,6,4,8,10,9,15]  |  forward finds rightBound, backward finds leftBound
Forward
[2 6 4!8 10 9!15 ]
runMax: 2,6,6,8,10,10,15. Violation (nums[i]<runMax) at i=2 (4<6) and i=5 (9<10). rightBound=5
Backward
[2 6!4 8 10!9 15 ]
runMin: 15,9,9,8,8,4,2. Violation (nums[i]>runMin) at i=4 (10>9) and i=1 (6>4). leftBound=1
Answer
[2 6left4 8 10 9right15 ]
rightBound-leftBound+1 = 5-1+1 = 5. Sort [6,4,8,10,9] → entire array sorted!

🔧 Algorithm (Step by Step)

  1. Scan left→right with maxSoFar; update right boundary whenever nums[i] < maxSoFar.
  2. Scan right→left with minSoFar; update left boundary whenever nums[i] > minSoFar.
  3. Return right - left + 1 (initialize right=-2, left=-1 so if already sorted, result = 0).

☕ Java Solution

public int findUnsortedSubarray(int[] nums) {
    int n = nums.length;
    int left = -1, right = -2;          // -2 so right-left+1 = 0 if sorted
    int maxSoFar = nums[0], minSoFar = nums[n-1];
    for (int i = 1; i < n; i++) {
        maxSoFar = Math.max(maxSoFar, nums[i]);
        if (nums[i] < maxSoFar) right = i;
    }
    for (int i = n-2; i >= 0; i--) {
        minSoFar = Math.min(minSoFar, nums[i]);
        if (nums[i] > minSoFar) left = i;
    }
    return right - left + 1;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Two Pointer Pattern

Two Pointer Pattern: Two independent linear scans (forward and backward) that together define the 'broken' region. Each scan mimics one of the two pointers doing their own job independently.
Key Insight: Initialize right=-2 so right-left+1=0 handles the already-sorted edge case elegantly.
