P04 — Trapping Rain Water

Hard  •  LeetCode #42  •  Pattern: Opposite Ends

📝 The Problem

Given an elevation map as an array of heights, compute how much water it can trap after rain. Water at position i is limited by the shortest wall on either side.

Example: [0,1,0,2,1,0,1,3,2,1,2,1] → 6

🌟 In Layman's Terms

Each column can hold water up to min(tallest wall on its left, tallest wall on its right) - its own height. The trick: you don't need to scan both sides separately for every column. Use two pointers from the ends. Whichever side has the smaller max-so-far is the definite bottleneck. Process that side — its water amount is already decided. Move that pointer inward.

⚡ The Aha Moment

Water at a position depends on the min of the two sides' maximums. Two pointers let you process whichever side's maximum is smaller — that side's water is already fully determined.

L≥R → loop ends. Key insight: leftMax guaranteed the water — rightMax was always larger.

🔧 Algorithm (Step by Step)

  1. Set left=0, right=n-1, leftMax=0, rightMax=0, water=0.
  2. While left < right: if height[left] < height[right], process left side; else right side.
  3. Process left: if height[left] >= leftMax, update leftMax; else water += leftMax - height[left]. Then left++.
  4. Process right: same logic mirrored. Then right--.

☕ Java Solution

public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = 0, rightMax = 0, water = 0;
    while (left < right) {
        if (height[left] < height[right]) {
            if (height[left] >= leftMax) leftMax = height[left];
            else                          water += leftMax - height[left];
            left++;
        } else {
            if (height[right] >= rightMax) rightMax = height[right];
            else                            water += rightMax - height[right];
            right--;
        }
    }
    return water;
}
