P10 — Reverse String

Easy  •  LeetCode #344  •  Pattern: Opposite Ends

📝 The Problem

Write a function that reverses a character array s in-place. Do it with O(1) extra memory.

Example: ['h','e','l','l','o'] → ['o','l','l','e','h']

🌟 In Layman's Terms

The simplest two-pointer problem. Swap the outermost characters, then move both pointers inward, repeat until they meet. Like flipping a pancake — you always take the two outermost and switch them.

⚡ The Aha Moment

This is the simplest two-pointer pattern: swap outermost pair, converge, repeat. It's the building block of many harder reverse/palindrome problems.

L=2, R=2. L≥R → stop. Result: ['o','l','l','e','h']

🔧 Algorithm (Step by Step)

  1. Set left=0, right=n-1.
  2. While left < right: swap s[left] and s[right], then left++, right--.

☕ Java Solution

public void reverseString(char[] s) {
    int left = 0, right = s.length - 1;
    while (left < right) {
        char tmp  = s[left];
        s[left++] = s[right];
        s[right--] = tmp;
    }
}

Time
O(n)
Space
O(1)
