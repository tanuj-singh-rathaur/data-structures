P09 — Valid Palindrome

Easy  •  LeetCode #125  •  Pattern: Opposite Ends

📝 The Problem

A phrase is a palindrome if it reads the same forward and backward after converting all uppercase to lowercase and removing all non-alphanumeric characters. Given string s, return true if it is a palindrome.

Example: "A man, a plan, a canal: Panama" → true

🌟 In Layman's Terms

Put one finger at the start and one at the end of the string. Skip non-letters/digits (spaces, commas, colons). Compare the characters your fingers land on. If they ever differ, it's not a palindrome. If the fingers meet without any mismatch, it is a palindrome.

⚡ The Aha Moment

Palindrome check = converging two-pointer from both ends, skip non-alphanumeric, compare case-insensitively.

L=3, R=3. L≥R → loop ends. Return true — it IS a palindrome!

🔧 Algorithm (Step by Step)

  1. Set left=0, right=s.length()-1.
  2. While left < right: skip non-alphanumeric on both sides.
  3. Compare toLowerCase(s[left]) vs toLowerCase(s[right]). If they differ, return false.
  4. left++, right--.
  5. Return true.

☕ Java Solution

public boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        while (left < right && !Character.isLetterOrDigit(s.charAt(left)))  left++;
        while (left < right && !Character.isLetterOrDigit(s.charAt(right))) right--;
        if (Character.toLowerCase(s.charAt(left)) !=
            Character.toLowerCase(s.charAt(right))) return false;
        left++; right--;
    }
    return true;
}

Two Pointer Pattern: Purest converging two-pointer: compare from both ends toward center. Works on strings, arrays, linked lists.
Key Insight: Skip non-alphanumeric on both ends, compare case-insensitively, converge until pointers meet.
