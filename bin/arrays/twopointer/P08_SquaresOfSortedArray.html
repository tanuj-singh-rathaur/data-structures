P08 — Squares of a Sorted Array

Easy  •  LeetCode #977  •  Pattern: Fill From Back

📝 The Problem

Given an integer array sorted in non-decreasing order (may include negatives), return an array of the squares of each number, also sorted in non-decreasing order.

Example: [-4,-1,0,3,10] → [0,1,9,16,100]

🌟 In Layman's Terms

Squaring a negative makes it positive, and large negatives square to huge values. So the largest squares are always at the two ends of the sorted array (either the most-negative or the most-positive). Use two pointers at both ends, compare absolute values, and fill a result array from right to left (largest first). This avoids sorting after squaring.

⚡ The Aha Moment

After squaring a sorted array, the largest values come from the two ends. Fill the result from the back by comparing the ends.

🔧 Algorithm (Step by Step)

  1. Set left=0, right=n-1, pos=n-1.
  2. While left <= right: compare |nums[left]| vs |nums[right]|.
  3. Write the larger square at result[pos--].
  4. Advance the pointer whose absolute value was larger.

☕ Java Solution

public int[] sortedSquares(int[] nums) {
    int n = nums.length, left = 0, right = n - 1, pos = n - 1;
    int[] result = new int[n];
    while (left <= right) {
        int lSq = nums[left]  * nums[left];
        int rSq = nums[right] * nums[right];
        if (lSq > rSq) { result[pos--] = lSq; left++;  }
        else            { result[pos--] = rSq; right--; }
    }
    return result;
}

📈 Two Pointer Pattern

Two Pointer Pattern: Fill-from-back two-pointer. The key insight is that the two extremes of a sorted array hold the largest squares, so you build the answer array in reverse.
