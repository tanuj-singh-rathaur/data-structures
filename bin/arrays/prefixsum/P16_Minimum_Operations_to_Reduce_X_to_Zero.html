P16 — Minimum Operations to Reduce X to Zero

Medium • LC #1658 • Pattern: Reframe to Longest Middle Subarray

📝 The Problem

Given nums (positive) and integer x, in each operation you may remove the leftmost or rightmost element, subtracting it from x. Return the minimum operations to make x exactly 0, or −1 if impossible.

Example: nums = [1, 1, 4, 2, 3], x = 5 → 2 (remove right twice: 3, 2)

📚 Jargon Buster

The reframe
Removing from both ends = keeping a contiguous middle. If total − middle = x, then middle = total − x. So: find the longest middle subarray summing to total − x; the answer is n − middleLength.
Why longest middle
Minimum operations corresponds to maximum kept. So we want the longest middle that sums to total − x.
Sliding window applicability
nums are positive ⇒ sliding window works for "longest subarray summing to target."

🌟 In Layman's Terms

Whatever you remove from the ends, the remaining middle subarray sums to total − x. The fewer the operations, the longer the middle. So find the longest contiguous middle summing to total − x; answer = n − thatLength.

⚡ The Aha Moment

A hard “remove from ends” problem becomes a classic “longest subarray with target sum” via a single subtraction. Reframing is the work; the algorithm is standard.

🔧 Algorithm

  1. Compute target = total − x.
  2. If target < 0: return −1.
  3. If target == 0: return n.
  4. Sliding window: longest subarray summing to target.
  5. Return n − bestLength (or −1 if no such subarray).

☕ Java Solution

public int minOperations(int[] nums, int x) {
    int total = 0; for (int v : nums) total += v;
    int target = total - x;
    if (target < 0) return -1;
    int L = 0, sum = 0, best = -1;
    for (int R = 0; R < nums.length; R++) {
        sum += nums[R];
        while (sum > target) sum -= nums[L++];
        if (sum == target) best = Math.max(best, R - L + 1);
    }
    return best == -1 ? -1 : nums.length - best;
}

⏳ Complexity

Time
O(n)
Space
O(1)
