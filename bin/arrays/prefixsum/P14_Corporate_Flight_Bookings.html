P14 — Corporate Flight Bookings

Medium • LC #1109 • Pattern: Difference Array + Prefix

📝 The Problem

You have n flights and a list of bookings [first, last, seats] meaning seats are booked for every flight in [first, last] (1-indexed). Return an array of total seats booked per flight.

Example: n = 5, bookings = [[1,2,10], [2,3,20], [2,5,25]] → [10, 55, 45, 25, 25]

📚 Jargon Buster

Difference array
The inverse of prefix sum. Instead of storing values, store the change between consecutive cells. A range update is just two point updates: diff[l] += s; diff[r+1] −= s.
Range update O(1)
A naive approach updates every cell in [l, r] (O(range) per booking). Difference array drops it to O(1) per booking; the final prefix scan reconstructs everything in O(n).
Recover values
Take prefix sum of the difference array → original values.

🌟 In Layman's Terms

For each booking, just mark "+seats at start" and "−seats just after end" in a delta array. After processing all bookings, walk left to right adding up deltas — you've effectively applied every range update.

⚡ The Aha Moment

Range updates + final read = difference array. Prefix sum and difference array are perfect duals: one walks values to deltas, the other walks deltas back to values.

🔧 Algorithm

  1. Allocate diff[n + 1].
  2. For each [l, r, s]: diff[l−1] += s; diff[r] −= s (convert to 0-indexed).
  3. Take running prefix sum to get final result.

☕ Java Solution

public int[] corpFlightBookings(int[][] bookings, int n) {
    int[] diff = new int[n + 1];
    for (int[] b : bookings) {
        diff[b[0] - 1] += b[2];
        diff[b[1]] -= b[2];
    }
    int[] res = new int[n];
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += diff[i];
        res[i] = sum;
    }
    return res;
}

⏳ Complexity

Time
O(B + n)
Space
O(n)

📈 Prefix Sum Pattern

Difference Array: The inverse of the build-the-prefix pattern. Range updates become two point updates; one final prefix scan recovers the result.
Key Insight: If you're applying many range updates and only need the final state, never update each cell. Use a difference array — O(1) per update, O(n) to finalize.
