P08 — Contiguous Array

Medium • LC #525 • Pattern: Transform Trick + HashMap of First Occurrence

📝 The Problem

Given a binary array nums, return the maximum length of a contiguous subarray with equal numbers of 0s and 1s.

Example: [0, 1, 0, 0, 1, 1, 0] → 6

📚 Jargon Buster

The 0 → −1 trick
Replace 0 with −1. Now "equal 0s and 1s" becomes "subarray sum = 0."
First-occurrence map
For each prefix-sum value, store the earliest index where it appeared. Later, if the same sum reappears at index j, the subarray from map[sum]+1 to j sums to 0 (and is the longest one for that sum).
Seed map with {0: −1}
Empty prefix has sum 0 at "before index 0," i.e. position −1. Lets a prefix-sum-of-0 at index j produce length j − (−1) = j + 1.

🌟 In Layman's Terms

Substitute each 0 with −1. Now an “equal 0s and 1s” subarray sums to 0. Walk the array tracking running sum; whenever you've seen this sum before, the chunk in between is a 0-sum (equal counts) subarray.

⚡ The Aha Moment

Reframing 0 as −1 turns a counting problem into a sum problem — one we already know how to solve with a HashMap of prefix sums.

🔧 Algorithm

  1. Treat 0 as −1 implicitly while summing.
  2. Map first occurrence of each running sum. Seed {0: −1}.
  3. If sum repeats at index i: best = max(best, i − map[sum]).
  4. Otherwise store map[sum] = i.

☕ Java Solution

public int findMaxLength(int[] nums) {
    Map<Integer, Integer> first = new HashMap<>();
    first.put(0, -1);
    int sum = 0, best = 0;
    for (int i = 0; i < nums.length; i++) {
        sum += (nums[i] == 1) ? 1 : -1;
        if (first.containsKey(sum)) {
            best = Math.max(best, i - first.get(sum));
        } else {
            first.put(sum, i);
        }
    }
    return best;
}

⏳ Complexity

Time
O(n)
Space
O(n)

📈 Prefix Sum Pattern

Transform + HashMap: Reframe the problem so that the answer corresponds to "subarray sum equals 0." Then prefix-sum + first-occurrence map yields the longest such subarray.
Key Insight: Whenever a problem says “equal count of A and B,” convert A → +1 and B → −1. The “balanced” condition becomes a sum-of-zero condition.
