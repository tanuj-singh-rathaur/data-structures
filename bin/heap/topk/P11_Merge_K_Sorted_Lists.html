P11 — Merge K Sorted Lists

Hard • LC #23

Java

PriorityQueue<ListNode> pq = new PriorityQueue<>((a,b) -> a.val - b.val);
for (ListNode h : lists) if (h != null) pq.offer(h);
ListNode dummy = new ListNode(0), cur = dummy;
while (!pq.isEmpty()) {
    ListNode n = pq.poll();
    cur.next = n; cur = n;
    if (n.next != null) pq.offer(n.next);
}
return dummy.next;
Insight: Heap of HEADS gives O(N log k) — each node enters/leaves once.
