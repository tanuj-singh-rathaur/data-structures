P09 — Reverse Pairs

Hard • LC #493 • Pattern: Modified Merge Sort with Cross-Pair Count

📝 The Problem

Count pairs (i, j) with i < j and nums[i] > 2 · nums[j].

📚 Jargon Buster

Cross-Pair
A pair where i comes from the left half and j from the right half. Each merge level counts these.

🌟 In Layman's Terms

During merge sort, before the merge step, count pairs (i in left half, j in right half) with nums[i] > 2·nums[j]. The two halves are sorted, so a two-pointer sweep counts all such pairs in O(n).

⚡ The Aha Moment

Within-half pairs are counted by recursion; cross-half pairs are counted here. Every pair belongs to exactly one merge level.

🔧 Algorithm

  1. Standard merge sort recursion returns inversion count.
  2. Before merge: two-pointer count of pairs across halves.
  3. Then merge as usual.

☕ Java Solution

public int reversePairs(int[] nums) {
    int[] tmp = new int[nums.length];
    return ms(nums, 0, nums.length - 1, tmp);
}
private int ms(int[] a, int lo, int hi, int[] tmp) {
    if (lo >= hi) return 0;
    int mid = lo + (hi - lo) / 2;
    int count = ms(a, lo, mid, tmp) + ms(a, mid + 1, hi, tmp);
    int j = mid + 1;
    for (int i = lo; i <= mid; i++) {
        while (j <= hi && (long) a[i] > 2L * a[j]) j++;
        count += j - (mid + 1);
    }
    merge(a, lo, mid, hi, tmp);
    return count;
}
private void merge(int[] a, int lo, int mid, int hi, int[] tmp) {
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= hi)  tmp[k++] = a[j++];
    System.arraycopy(tmp, lo, a, lo, hi - lo + 1);
}

⏳ Complexity

Time
O(n log n)
Space
O(n)
