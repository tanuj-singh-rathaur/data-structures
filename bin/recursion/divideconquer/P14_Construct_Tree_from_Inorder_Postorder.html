P14 — Build Tree from Inorder + Postorder

Medium • LC #106 • Pattern: Root = postorder[last]; right before left

📝 The Problem

Reconstruct the tree given inorder and postorder traversals.

📚 Jargon Buster

Postorder
left, right, root. The last element is always the root.
Right-Before-Left Recursion
Walking postorder backwards: root, then right subtree, then left subtree.

🌟 In Layman's Terms

Same skeleton as P13 but read postorder from the END. The trick is to build the RIGHT subtree first because its values precede the left subtree's in the reversed postorder stream.

⚡ The Aha Moment

Order of recursive calls (right before left) is the key difference from the preorder variant.

🔧 Algorithm

  1. Hash inorder positions.
  2. build(lo, hi): root = postorder[postIdx--]; mid = idx[rootVal]; recurse RIGHT then LEFT.

☕ Java Solution

private int[] post; private Map<Integer, Integer> idx; private int postIdx;
public TreeNode buildTree(int[] inorder, int[] postorder) {
    post = postorder; idx = new HashMap<>();
    for (int i = 0; i < inorder.length; i++) idx.put(inorder[i], i);
    postIdx = postorder.length - 1;
    return build(0, inorder.length - 1);
}
private TreeNode build(int lo, int hi) {
    if (lo > hi) return null;
    int rootVal = post[postIdx--];
    TreeNode root = new TreeNode(rootVal);
    int mid = idx.get(rootVal);
    root.right = build(mid + 1, hi);   // right FIRST
    root.left  = build(lo, mid - 1);
    return root;
}

⏳ Complexity

Time
O(n)
Space
O(n)

📈 D&C Pattern

Mirror Skeleton: Pre/In vs In/Post is essentially the same algorithm walked in opposite direction.
Key Insight: Always recurse on the side whose values come FIRST in your traversal stream.
