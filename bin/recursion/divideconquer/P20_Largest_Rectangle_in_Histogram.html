P20 — Largest Rectangle in Histogram (D&C)

Hard • LC #84 • Pattern: Recurse Around the Minimum Bar

📝 The Problem

Given heights, return the area of the largest rectangle inscribed in the histogram.

📚 Jargon Buster

Min-Pivot
Pick the index of the smallest bar in [lo, hi]; the answer is either (hi − lo + 1) · minHeight or lies entirely on one side of it.
RMQ / Sparse Table
Range Minimum Query — preprocess in O(n log n), query in O(1), so pivot finding is fast.

🌟 In Layman's Terms

For range [lo, hi], find the smallest bar. The largest rectangle either uses it (width × height) or lies entirely left or entirely right of it. Recurse.

⚡ The Aha Moment

Any rectangle that crosses the min bar must have its height capped by it ⇒ "include it" case has known area.

🔧 Algorithm

  1. Build RMQ on heights.
  2. solve(lo, hi): if lo > hi ⇒ 0. m = argmin; return max((hi − lo + 1) · h[m], solve(lo, m − 1), solve(m + 1, hi)).

☕ Java Solution (sketch)

// Build sparse table once, then:
private int solve(int[] h, int lo, int hi, SparseRMQ rmq) {
    if (lo > hi) return 0;
    int m = rmq.argMin(lo, hi);
    return Math.max((hi - lo + 1) * h[m],
           Math.max(solve(h, lo, m - 1, rmq), solve(h, m + 1, hi, rmq)));
}

⏳ Complexity

Time
O(n log n) avg with RMQ
Space
O(n log n) table

📈 D&C Pattern

Recurse at Extremum: Pick a structural extremum (min/max), split, and combine — used in tournament problems and Cartesian-tree construction.
Key Insight: Worst case is O(n²) when heights are monotone; the monotonic-stack solution is O(n) and usually preferred — D&C is the conceptually clean version.
