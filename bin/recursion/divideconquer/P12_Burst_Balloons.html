P12 — Burst Balloons

Hard • LC #312 • Pattern: Interval Pivot on the LAST Balloon to Burst

📝 The Problem

Maximise the coins earned bursting balloons. Bursting balloon i scores nums[left] · nums[i] · nums[right] where left/right are current neighbours.

📚 Jargon Buster

Last-Burst Trick
Pick which balloon bursts LAST in each interval — its neighbours are then permanent (the interval boundaries).
Pad with 1s
Treat indices −1 and n as virtual 1s to simplify boundary multiplication.

🌟 In Layman's Terms

Decide which balloon will be popped LAST in [i, j]. Its two neighbours are fixed (positions just outside the interval). The two sides become independent sub-problems.

⚡ The Aha Moment

Choosing the FIRST to burst makes neighbours unknown. Choosing the LAST makes neighbours known ⇒ subproblems become independent.

🔧 Algorithm

  1. Pad nums with 1 on both ends.
  2. solve(i, j) = max over k in (i, j): solve(i, k) + nums[i]·nums[k]·nums[j] + solve(k, j).
  3. Memoise by (i, j).

☕ Java Solution (Top-Down Memo)

private int[] padded; private int[][] memo;
public int maxCoins(int[] nums) {
    int n = nums.length;
    padded = new int[n + 2];
    padded[0] = padded[n + 1] = 1;
    for (int i = 0; i < n; i++) padded[i + 1] = nums[i];
    memo = new int[n + 2][n + 2];
    return solve(0, n + 1);
}
private int solve(int i, int j) {
    if (j - i < 2) return 0;
    if (memo[i][j] != 0) return memo[i][j];
    int best = 0;
    for (int k = i + 1; k < j; k++) {
        best = Math.max(best, solve(i, k) + padded[i] * padded[k] * padded[j] + solve(k, j));
    }
    return memo[i][j] = best;
}

⏳ Complexity

Time
O(n³)
Space
O(n²)

📈 D&C Pattern

Last/Final-Action Pivot: When subproblems would otherwise interact, picking the LAST action often decouples them.
Key Insight: Reversing the decision direction (last-out instead of first-out) is a common interval-DP trick.
