P19 — Longest Common Prefix

Easy • LC #14 • Pattern: Vertical Column Scan

📝 The Problem

Find the longest string that is a prefix of every string in the input array.

Example: ["flower","flow","flight"] → "fl"

📚 Jargon Buster

Common prefix
A starting substring shared by every string in the list.
Vertical scan
Iterate over column indices (character position) and, for each column, check that every string agrees on that character.
Two pointers (loose sense)
Outer pointer = column index; inner pointer = string index.

🌟 In Layman's Terms

Line up the strings vertically. Walk down column 0, then column 1, …. Each column, every string must agree on that character. The first column with disagreement is where the common prefix ends.

⚡ The Aha Moment

Compared with "match the first against each other," vertical scan stops at the first column with disagreement — potentially much earlier than reading any single string to its end.

🔧 Algorithm

  1. For col = 0..(len of strs[0] - 1):
    • For each string s: if col == s.length() or s[col] != strs[0][col], return strs[0].substring(0, col).
  2. Return strs[0].

☕ Java Solution

public String longestCommonPrefix(String[] strs) {
    if (strs.length == 0) return "";
    for (int col = 0; col < strs[0].length(); col++) {
        char c = strs[0].charAt(col);
        for (int k = 1; k < strs.length; k++) {
            if (col == strs[k].length() || strs[k].charAt(col) != c) {
                return strs[0].substring(0, col);
            }
        }
    }
    return strs[0];
}

⏳ Complexity

Time
O(N · L)
Space
O(1)

N = # strings, L = length of common prefix.

📈 Two Pointer Pattern

Vertical Scan: An outer column pointer combined with an inner row pointer. Stops at the first disagreement.
Key Insight: Column-major iteration short-circuits naturally. You never need to read characters beyond the prefix length.
