P10 — Reverse Words in a String

Medium • LC #151 • Pattern: Right-to-Left Token Walk

📝 The Problem

Reverse the order of words in a string. Trim leading/trailing spaces and collapse multiple spaces to single ones.

Example: " the sky is blue " → "blue is sky the"

📚 Jargon Buster

Word order vs Character order
Here we reverse word order but keep each word's internal characters as-is. (P09 was the opposite.)
Token walk
Walk right-to-left; whenever you hit the right edge of a word, extract it and append to the result.
Alternative: reverse-whole-then-reverse-each-word
Reverse the entire string, then reverse each word in place. Also works.

🌟 In Layman's Terms

Walk backwards from the end. Each time you finish a word, append it to the result with a single space. Skip extra spaces. When you're done, you've built the answer.

⚡ The Aha Moment

Going right-to-left makes "reverse word order" trivial — each word naturally lands in the result in reverse order.

🔧 Algorithm

  1. i = n − 1. While i ≥ 0: skip spaces; find word [j..i]; append; i = j − 1.
  2. Strip trailing space.

☕ Java Solution

public String reverseWords(String s) {
    StringBuilder sb = new StringBuilder();
    int i = s.length() - 1;
    while (i >= 0) {
        while (i >= 0 && s.charAt(i) == ' ') i--;
        if (i < 0) break;
        int j = i;
        while (i >= 0 && s.charAt(i) != ' ') i--;
        sb.append(s, i + 1, j + 1).append(' ');
    }
    if (sb.length() > 0) sb.setLength(sb.length() - 1);
    return sb.toString();
}

⏳ Complexity

Time
O(n)
Space
O(n) for output

📈 Two Pointer Pattern

Right-to-Left Token Walk: A scanning pointer (i) finds word right-edges; a second pointer (j) marks word left-edges. Append in scan order → reversed word order in output.
Key Insight: Direction matters. Reversing word order is one right-to-left pass, no in-place reversal needed.
