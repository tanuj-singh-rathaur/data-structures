P17 — Shortest Distance to a Character

Easy • LC #821 • Pattern: Left Sweep + Right Sweep

📝 The Problem

For each index i, return the distance to the closest occurrence of character c in s.

Example: s = "loveleetcode", c = 'e' → [3,2,1,0,1,0,0,1,2,2,1,0]

📚 Jargon Buster

Closest occurrence
The minimum over distances to a c on either side of i.
Left sweep
Walk left-to-right tracking the most recent c seen. res[i] = i − lastSeen.
Right sweep
Walk right-to-left tracking the most recent c. Update each res[i] to min(res[i], lastSeen − i).
Initial sentinel
Before sweeping, no c has been seen. Use a "far away" sentinel (e.g., −n on left, +2n on right) so distances are large until the first hit.

🌟 In Layman's Terms

One sweep records the distance to the nearest c on the left. Another sweep records the distance to the nearest c on the right. The answer per index is the minimum.

⚡ The Aha Moment

Two independent sweeps replace a quadratic "for each i, scan for closest c". Each sweep is O(n) and only needs one scalar (last-seen position).

🔧 Algorithm

  1. Left sweep: prev = -n. For i = 0..n-1: if s[i] == c, prev = i; res[i] = i - prev.
  2. Right sweep: prev = 2n. For i = n-1..0: if s[i] == c, prev = i; res[i] = min(res[i], prev - i).

☕ Java Solution

public int[] shortestToChar(String s, char c) {
    int n = s.length();
    int[] res = new int[n];
    int prev = -n;
    for (int i = 0; i < n; i++) {
        if (s.charAt(i) == c) prev = i;
        res[i] = i - prev;
    }
    prev = 2 * n;
    for (int i = n - 1; i >= 0; i--) {
        if (s.charAt(i) == c) prev = i;
        res[i] = Math.min(res[i], prev - i);
    }
    return res;
}

⏳ Complexity

Time
O(n)
Space
O(n) for output

📈 Two Pointer Pattern

Two-Pass Sweep: Two single-pointer passes — one each direction — cover both sides. Same idea as left-right prefix sums on arrays.
Key Insight: Distance is bidirectional but can be split into "to my left" and "to my right" sweeps. Each side is O(n); combined remains O(n).
