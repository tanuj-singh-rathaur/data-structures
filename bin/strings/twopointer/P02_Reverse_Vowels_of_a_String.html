P02 — Reverse Vowels of a String

Easy • LC #345 • Pattern: Opposite Ends + Selective Swap

📝 The Problem

Reverse only the vowels of a string, leaving consonants and other characters in place.

Example: "hello" → "holle"

📚 Jargon Buster

Vowel
a, e, i, o, u (both upper and lower case in this problem).
Selective swap
Two pointers move inward, but they only swap when both are sitting on vowels. Otherwise they each skip ahead independently.
In-place
Java strings are immutable, so convert to char[] and swap inside.

🌟 In Layman's Terms

One finger on the leftmost vowel, one on the rightmost. Swap them. Slide both inward, looking for the next pair of vowels. Stop when the fingers meet.

⚡ The Aha Moment

Two pointers don't need to move in lockstep. Skip non-vowels with each pointer independently until both are on a vowel; then swap and step inward.

🔧 Algorithm

  1. Convert to char[].
  2. L = 0, R = n − 1. While L < R:
    • Move L right while arr[L] isn't a vowel.
    • Move R left while arr[R] isn't a vowel.
    • If L < R: swap; L++; R--.
  3. Return new String(arr).

☕ Java Solution

public String reverseVowels(String s) {
    char[] a = s.toCharArray();
    int L = 0, R = a.length - 1;
    String V = "aeiouAEIOU";
    while (L < R) {
        while (L < R && V.indexOf(a[L]) < 0) L++;
        while (L < R && V.indexOf(a[R]) < 0) R--;
        char t = a[L]; a[L] = a[R]; a[R] = t;
        L++; R--;
    }
    return new String(a);
}

⏳ Complexity

Time
O(n)
Space
O(n) for char[]

📈 Two Pointer Pattern

Opposite Ends + Selective Action: Same skeleton as Valid Palindrome — pointers converge from both sides — but action (swap) only fires when both sides match a criterion.
Key Insight: The pointer-skip pattern decouples scanning from action. Use it whenever “only certain characters count.”
