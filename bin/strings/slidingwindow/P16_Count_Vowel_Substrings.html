P16 — Count Vowel Substrings of a String

Easy • LC #2062 • Pattern: atMost(5) − atMost(4) on Vowel Runs

📝 The Problem

Count substrings consisting entirely of vowels that contain all five distinct vowels (a, e, i, o, u).

Example: "aeiouu" → 2

📚 Jargon Buster

Vowel-only runs
Split s at every consonant. The answer is the sum over each pure-vowel run.
exactly-5 = atMost(5) − atMost(4)
Within a vowel run, count substrings with ≤ 5 distinct vowels minus those with ≤ 4. The difference is substrings with all 5.
Why this works
Inside a vowel-only stretch, "exactly 5 distinct vowels" is the only way to contain all five.

🌟 In Layman's Terms

Slice the string at consonants. For each pure-vowel segment, count substrings with all 5 vowels using the at-most-K subtraction trick.

⚡ The Aha Moment

The exactly-K = atMost(K) − atMost(K−1) identity from arrays applies here too, just over vowel runs.

🔧 Algorithm

  1. For each maximal vowel-only segment: total += atMost(5) − atMost(4) on that segment.

☕ Java Solution

public int countVowelSubstrings(String word) {
    return countAtMost(word, 5) - countAtMost(word, 4);
}
private int countAtMost(String s, int K) {
    Map<Character, Integer> cnt = new HashMap<>();
    int L = 0, total = 0;
    for (int R = 0; R < s.length(); R++) {
        char c = s.charAt(R);
        if ("aeiou".indexOf(c) < 0) { cnt.clear(); L = R + 1; continue; }
        cnt.merge(c, 1, Integer::sum);
        while (cnt.size() > K) {
            char lc = s.charAt(L++);
            cnt.merge(lc, -1, Integer::sum);
            if (cnt.get(lc) == 0) cnt.remove(lc);
        }
        total += R - L + 1;
    }
    return total;
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Sliding Window Pattern

At-Most-K Trick: Whenever you want exactly K of something, compute atMost(K) − atMost(K-1). The atMost helper is a stock variable-window template.
Key Insight: Resetting the window at every consonant correctly isolates vowel runs — no need for an outer loop over segments.
