P20 — Maximum Number of Occurrences of a Substring

Medium • LC #1297 • Pattern: Only minSize Matters + Frequency Map

📝 The Problem

Given s, integers maxLetters, minSize, maxSize, return the maximum number of occurrences (among any substring of length in [minSize, maxSize]) that satisfies: distinct chars ≤ maxLetters.

Example: s = "aababcaab", maxLetters = 2, minSize = 3, maxSize = 4 → 2

📚 Jargon Buster

Only minSize matters
Any longer winner contains a minSize winner with ≥ same occurrences. So just count minSize-length substrings.
Frequency tally of substrings
HashMap from minSize substring to occurrence count. Update as the window slides.
Distinct ≤ maxLetters
Filter: only valid substrings (≤ maxLetters distinct chars) count.

🌟 In Layman's Terms

You don't need to try every length. Just look at length = minSize. Slide that fixed window, check the distinct-char count, tally each substring, return the highest tally.

⚡ The Aha Moment

If a length-k substring is a winner, its first minSize chars are also a winner (same constraints, no fewer occurrences). So minSize is the only length to examine.

🔧 Algorithm

  1. Slide a window of size minSize. Maintain a distinct-char count.
  2. If distinct ≤ maxLetters: tally substring in a HashMap.
  3. Return max value in HashMap (0 if empty).

☕ Java Solution

public int maxFreq(String s, int maxLetters, int minSize, int maxSize) {
    Map<String, Integer> freq = new HashMap<>();
    int[] cnt = new int[26];
    int distinct = 0;
    int K = minSize;
    for (int i = 0; i < Math.min(K, s.length()); i++) {
        if (cnt[s.charAt(i) - 'a']++ == 0) distinct++;
    }
    if (s.length() >= K && distinct <= maxLetters) {
        freq.merge(s.substring(0, K), 1, Integer::sum);
    }
    for (int r = K; r < s.length(); r++) {
        if (cnt[s.charAt(r) - 'a']++ == 0) distinct++;
        if (--cnt[s.charAt(r - K) - 'a'] == 0) distinct--;
        if (distinct <= maxLetters) {
            freq.merge(s.substring(r - K + 1, r + 1), 1, Integer::sum);
        }
    }
    int best = 0;
    for (int v : freq.values()) best = Math.max(best, v);
    return best;
}

⏳ Complexity

Time
O(n · minSize)
Space
O(n · minSize)

📈 Sliding Window Pattern

Fixed Window + Frequency Tally: Ignore maxSize entirely; minSize is sufficient. The constraint window is fixed; the answer comes from a HashMap tally.
Key Insight: When you see a range like [minSize, maxSize], check whether the smallest works just as well. Often it does — and the range hint becomes a red herring.
