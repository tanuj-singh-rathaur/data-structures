P06 — Substring with Concatenation of All Words

Hard • LC #30 • Pattern: Fixed Window of Words + Frequency

📝 The Problem

Given s and a list words where each word has the same length, find all starting indices where s contains a concatenation of every word in words exactly once, in any order.

Example: s = "barfoothefoobarman", words = ["foo","bar"] → [0, 9]

📚 Jargon Buster

Word grain
The "unit" of the window is one word (length w) instead of one character. Slide by w per step.
Total window length
w · words.length. The fixed window covers all required words.
Per-offset pass
The window can start at any of the first w offsets (0, 1, ..., w-1). Run the sliding loop once for each offset.
Frequency match on words
HashMap of word -> count, just like char freq but per-word.

🌟 In Layman's Terms

Pretend each word is a single character of an "alphabet of words." The window length is fixed at w · n. Slide by one word at a time. Compare word counts inside the window with the required word counts.

⚡ The Aha Moment

You only need to try w starting offsets (0..w-1). Within each offset, the window can slide by full words — never by a character — giving O(n) per offset.

🔧 Algorithm

  1. Build need HashMap from words.
  2. For offset = 0..w-1: slide a window over s in steps of w; maintain a word-count map; add when window matches.

☕ Java Solution

public List<Integer> findSubstring(String s, String[] words) {
    List<Integer> res = new ArrayList<>();
    int w = words[0].length(), n = words.length, total = w * n;
    if (s.length() < total) return res;
    Map<String, Integer> need = new HashMap<>();
    for (String word : words) need.merge(word, 1, Integer::sum);
    for (int off = 0; off < w; off++) {
        Map<String, Integer> win = new HashMap<>();
        int L = off, count = 0;
        for (int R = off; R + w <= s.length(); R += w) {
            String wd = s.substring(R, R + w);
            if (need.containsKey(wd)) {
                win.merge(wd, 1, Integer::sum);
                count++;
                while (win.get(wd) > need.get(wd)) {
                    String left = s.substring(L, L + w);
                    win.merge(left, -1, Integer::sum);
                    L += w;
                    count--;
                }
                if (count == n) res.add(L);
            } else {
                win.clear();
                count = 0;
                L = R + w;
            }
        }
    }
    return res;
}

⏳ Complexity

Time
O(n · w)
Space
O(N · w)

N = # words.

📈 Sliding Window Pattern

Word-Grain Window: The "character" of the alphabet is a fixed-length word. Sliding by w instead of 1 makes the inner loop linear; w outer offsets cover every possible alignment.
Key Insight: Don't restart the window from scratch each step. Maintain the word-count map incrementally and shrink with L when a word overflows its allowance — just like Have/Need in P05.
