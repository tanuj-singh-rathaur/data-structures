P09 — Maximum Number of Vowels in a Substring of Given Length

Medium • LC #1456 • Pattern: Fixed-Size Window with Counter

📝 The Problem

Return the max number of vowels in any substring of length K.

Example: s = "abciiidef", K = 3 → 3 ("iii")

📚 Jargon Buster

Vowel score
1 if the char is a vowel, else 0. Sum over the window = vowel count.
Slide updates
On each step: maybe add 1 (new char vowel), maybe subtract 1 (leaving char vowel).

🌟 In Layman's Terms

Treat each character as 0 or 1 (vowel?). Find the max sum over any window of length K.

⚡ The Aha Moment

Same template as "max sum subarray of size K" on arrays. Vowel-count is just a particular metric.

🔧 Algorithm

  1. Count vowels in first K-char window. Set best = that.
  2. For R = K..n-1: add s[R] if vowel; remove s[R-K] if vowel; update best.

☕ Java Solution

public int maxVowels(String s, int K) {
    int cur = 0;
    for (int i = 0; i < K; i++) if (isVowel(s.charAt(i))) cur++;
    int best = cur;
    for (int r = K; r < s.length(); r++) {
        if (isVowel(s.charAt(r))) cur++;
        if (isVowel(s.charAt(r - K))) cur--;
        best = Math.max(best, cur);
    }
    return best;
}
private boolean isVowel(char c) {
    return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
}

⏳ Complexity

Time
O(n)
Space
O(1)

📈 Sliding Window Pattern

Fixed Window with Counter: Any per-element binary metric (vowel / not, capital / not, digit / not) plugs into the same fixed-window template.
Key Insight: The fixed-window template is metric-agnostic. Swap in whatever scoring function fits the problem.
