P07 — Min Cost to Make at Least One Valid Path

Hard • LC #1368

Pattern (0-1 BFS)

Deque<int[]> dq = new ArrayDeque<>();
dq.offerFirst(new int[]{0,0,0});
while (!dq.isEmpty()) {
    int[] c = dq.pollFirst();
    int r=c[0], col=c[1], cost=c[2];
    if (seen[r][col]) continue; seen[r][col] = true;
    for (4 dirs) {
        int w = (dir == grid[r][col] ? 0 : 1);    // free if direction matches the arrow
        if (w == 0) dq.offerFirst(...); else dq.offerLast(...);
    }
}
Insight: 0-1 BFS replaces a heap with a deque — same correctness as Dijkstra, O(V+E) instead of O(E log V).
