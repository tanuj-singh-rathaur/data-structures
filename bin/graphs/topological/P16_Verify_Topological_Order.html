P16 — Verify Topological Order

Easy

Java

int[] pos = new int[n];
for (int i=0;i<n;i++) pos[order[i]] = i;
for (int u=0;u<n;u++) for (int v : adj.get(u))
    if (pos[u] >= pos[v]) return false;
return true;
Insight: Single edge scan suffices — for every directed edge, source must appear before destination.
