P19 — Process Restricted Friend Requests

Hard • LC #2076

Pattern

for (int[] req : requests) {
    int ra = find(req[0]), rb = find(req[1]);
    boolean ok = (ra == rb);
    if (!ok) {
        ok = true;
        for (int[] r : restrictions) {
            int rx = find(r[0]), ry = find(r[1]);
            if ((rx==ra && ry==rb) || (rx==rb && ry==ra)) { ok = false; break; }
        }
        if (ok) union(req[0], req[1]);
    }
    answer.add(ok);
}
Insight: Each request: tentatively check that merging two roots wouldn't fuse a forbidden pair. Restrictions list is short, so O(req × restr) is fine.
