Pattern

// Need at least (n-1) edges total — if edges.length < n-1 ⇒ -1.
// extras = count of edges whose union returned false.
// Answer = components - 1 (always achievable since extras ≥ components - 1 when edges.length ≥ n-1).
Insight: To connect k components into one you need exactly k-1 bridge moves; spare cables provide them.
