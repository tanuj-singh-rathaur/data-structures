P13 — Regions Cut By Slashes

Medium • LC #959

Pattern

// Split each cell into 4 triangles: 0=top, 1=right, 2=bottom, 3=left.
// '/' isolates {0,3} from {1,2}.
// '\' isolates {0,1} from {2,3}.
// Space merges all 4. Plus: bottom of cell unions with top of cell below;
//   right of cell unions with left of cell to the right.
// Answer = components.
Insight: Sub-divide each cell into "drawable pieces" and let DSU count enclosed regions.
