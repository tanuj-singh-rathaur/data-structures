P07 — Flood Fill

Easy • LC #733

Java

void dfs(int[][] g, int r, int c, int old, int neu) {
    if (r<0||c<0||r>=g.length||c>=g[0].length||g[r][c]!=old) return;
    g[r][c] = neu;
    dfs(g,r+1,c,old,neu); dfs(g,r-1,c,old,neu); dfs(g,r,c+1,old,neu); dfs(g,r,c-1,old,neu);
}
Insight: Guard for old == neu before starting — otherwise the colour check itself becomes infinite recursion's culprit.
